# 삼성전자·SK하이닉스: 다음 날 시작과 종가 방향

2026-11-04. 사용자 지시대로 비용·손익·매매수익 계산 없이 방향만 분석했다.
과거 탐색 실험이며 현재 시점의 실시간 예측이나 모델 승격이 아니다.

## 목표 정의

관측일 t 종가 뒤 이용할 입력을 만들고 다음 KRX 거래일 t+1을 예측한다.

| 출력 | 판정 기준 | 50점의 의미 |
|---|---|---|
| 상승 출발 확률 | O[t+1]>C[t] | 상승/하락 출발의 균형 |
| 상승 마감 확률 | C[t+1]>C[t] | 전일 종가 대비 상승/하락 마감의 균형 |
| 출발 방향 유지 확률 | sign(O[t+1]-C[t])=sign(C[t+1]-C[t]) | 유지/반전의 균형. 상승 점수가 아님 |
| 출발 방향 추가 진행 확률 | sign(C[t+1]-O[t+1])=sign(O[t+1]-C[t]) | 시가에서 같은 방향으로 추가 진행/그 외의 균형 |

예: 전일100 → 다음시가105 → 다음종가102이면 상승출발·상승마감·상방유지이나,
시가 대비 장중 하락이므로 추가상승은 아니다. 전일100→시가95→종가90이면 하방유지·추가하락이다.
일봉은 장중에 한 번도 반전하지 않았다는 사실을 입증하지 않는다. 유지란 종가의 최종 위치다.
시가 이후 첫5/30분 방향을 뜻하는 연구가 아니다. 그 목표에는 분봉이 필요하다.

## 데이터와 방법

- 새로 두 종목의 네이버 차트 일봉을 기존 수집 함수로 읽었다: 각 1,921일, 2019-01-02~2026-10-30.
- 기존 가격대 수급 파일의 181일과 OHLC는 181일 모두 일치. 마지막 날 거래량만 소폭 수정됐다.
- 가격은 네이버 차트 기준으로 유지했다. KRX 종가와 제공처 가격의 시장범위·조정 정의는
  독립 확정하지 못했고, 배당/분할이 갭 목표에 영향을 줄 수 있어 연구 자료로 제한한다.
- 입력: 각 종목 자체 가격 통제6개 + 기존 KOSPI200 옵션 수급, 시장 거래금액,
  정규장 최근월물 체인 거래량/OI/IV. 두 종목 자체 콜풋/현물 수급을 추가한 실험은 아니다.
- 종목별 별도 학습. 가격만/기존 옵션/거래금액·참여율/거래량 추가/전체혼합의 5개 후보.
- 20개 시간순 분기, 분리된 직전6개월 확률 보정, 구간 label 경계 제거, 학습구간 정규화.
- 동가 출발 또는 동가 마감은 FLAT로 보존하고 공통 이진 모델 표본에서 제외했다.
  따라서 이 확률은 모든 거래일의 무조건 확률이 아니라 비동가 표본의 탐색 추정이다.
- 삼성전자 원본공통1665→비동가1472→평가942일, 하이닉스1665→1484→평가951일.
  평가 목표일은 각각 2022-01-04/01-05~2026-10-22. 체인 원본 결측/만기롤이 있어 날짜는 불연속이다.
- 다음 날 시가·종가는 결과 라벨에만 쓴다. 예측 입력에는 넣지 않았다.
- 2종목×4목표×4추가후보×2기준=64개 Brier 차이에 블록 bootstrap·Holm 보정.
  전향 신규 구간을 확보하기 전까지 확정된 적중률로 쓰지 않는다.

## 표시 방향

종목별로 '출발 상방확률 / 마감 상방확률 / 종가 유지확률 / 추가진행확률'을 별도 표시하는 계약.
상방확률50 초과/미만은 상방/하방 경향이며 50은 균형이다. 실제 FLAT와 확률50은 다르다.
유지확률70점을 상승확률70점으로 표시하지 않는다. 서로 다른 확률 머리의 값을 곱해
'상승출발 후 상승마감'의 결합확률로 계산하지 않는다. 결합확률은 별도 일관된 모델이 필요하다.
0기울기 보정은 최근빈도만 반영하므로 중립/보류 상태를 함께 둔다.
종목 고유 현물 수급과 자체 옵션 체인은 다음 추가 후보이며, 현 결과의 입력에 포함됐다고 하지 않는다.
