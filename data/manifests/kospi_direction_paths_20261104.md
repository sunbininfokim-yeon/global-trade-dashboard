# 유가증권시장 KOSPI 지수: 다음 날 시작·종가 방향

2026-11-04. 비용/손익 없이 방향만 분석한 과거 탐색 실험이다.
대상은 시가총액 가중 KOSPI 지수이며 전종목 동일가중 수익률이나 상승종목 비율을 분석한 결과는 아니다.

## 대상과 입력

- 가격: 네이버 차트 KOSPI 일봉1921일, 2019-01-02~2026-10-30, 별도 스냅샷으로 보존.
- 기존 공개 KS11 종가180일과 대조: 179일 일치. 10/30은 기존5668.26/새자료5730.74로 다르다.
  차이 원인은 확정하지 않았다. 이번 최종 평가목표는10/22이므로 해당 차이는 평가 결과에 영향 없다.
- 입력: KOSPI 자체 가격6변수 + KOSPI200 콜/풋 수급·시장 거래금액·보관 최근월물 정규장
  체인 거래량/OI/IV. 옵션 자료의 범위가 KOSPI 모든 종목 자체 옵션을 뜻하지는 않는다.
- 공통 원본1665행, 동가출발2행 제외1663행, 시간순 평가1047일/20분기.
  평가 관측일2022-01-03~2026-10-21, 마지막 목표일2026-10-22.
- 다음거래일 시가·종가는 라벨에만 사용. 6개월 분리 보정/학습경계 제거/학습구간 정규화.
- 동가 출발·마감은 FLAT로 별도 감사하며 이진 비교에서는 제외한다. 따라서 조건부 비동가 표본의 연구다.

## 무엇을 예측했는가

1. 시작 상방: 다음시가 > 전일종가.
2. 마감 상방: 다음종가 > 전일종가.
3. 방향 유지: 시작과 마감이 전일종가의 같은 쪽.
4. 추가 진행: 시가→종가가 시작 방향과 같은 방향. 시종가 동가는 추가진행 아님.

예: 전일100→시가105→종가102는 상방유지이지만 추가진행은 아니다.
유지는 최종종가의 위치이며 장중 내내 같은 방향이었다는 뜻이 아니다.
각 확률의50점은 해당 사건의 균형점이며 유지확률을 상방확률로 표시하지 않는다.

## 전체 현물 수급은 왜 이번 입력에 없는가

주식 범위가 명시된 공개 kospi_index_levels는180일(2026-02-03~10-30)로 짧아
기존 학습250일+분리보정60일 조건에 못 미친다.
private 고정 커밋3a27fa4의 오래된 12008 표본은 security_scope=stock이 없어 ETF/ETN 제외를 확인하지 못했다.
특히2026-10-02 예시의 시장총매수15,981,136,000,000원, 총매도15,981,000,000원으로
약1000배의 불일치가 있어 해당 행을 사용하지 않았다. 전시장 매수·매도는 대응해야 한다.
이 결함은 해당 과거 표본에서 확인한 것으로 최신 전체 자료가 같은 오류라고 단정하지 않는다.
근거 해시: `kospi_cash_scope_audit_20261104.json`.

별도 kospi_stock_investor 이름의 hive도 확인했으나 실제 예시 product=ticker_cash/화면12009로
개별주 수급이었다. 이름만 보고 이를 시장 전체 합계로 대체하지 않았다.
최신 private tree b5159495774a6bdf79a96fa4bc05dd258713393c에는
명시된 krx_12008_kospi_stock_investor 전용 경로가 없었다. 기존 다른 경로의 최신 값 전체를 감사한 것은 아니다.
