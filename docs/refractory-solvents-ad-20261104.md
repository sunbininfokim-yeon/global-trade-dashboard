# 조선내화·후성코퍼레이션 내화재/용제 연결 · 2026-11-04

사용자 요청: 조선내화 내화재와 후성코퍼레이션의 중국산 초산에틸 등 용제 관련 반덤핑 품목 추가.

## 구현

산업→품목→기업 선택에 조선내화·후성코퍼레이션 2개 프로필과 7개 품목을 추가했습니다. 기존 한국 AD5 사건 계산과 다른 회사 프로필을 유지합니다. 내화재·세라믹 분야를 별도로 추가하고 용제는 화학 소재에 둡니다. 프로필에는 기업 공식 제품 근거만 넣으며 원산지·제품 단가·물량·원가·재무를 임의로 채우지 않았습니다.

후성은 무역회사 제품 취급 프로필이며 (주)후성 제조사와 구분합니다. 동일 도메인의 후성HDS 표기와 법인 승계는 추가 확인 대상입니다. 조선내화는 한국 본사·중국 생산법인·실제 수출자를 구분하며 관계사라는 이유만으로 동일 법인 또는 해당 세율을 확정하지 않습니다.

## 수입국별 관련 사건

원산지와 수입국은 각각 저장합니다. 미국의 기존 사건 확인과 별도로 `수입국별 관련 사건` 블록에서 중국산→한국, 중국산→미국, 한국산→미국을 명시합니다. 현재 원산지와 다르면 참고 자료임을 표시하고 확인 단계의 불은 켜지 않습니다. 원산지 변경 버튼은 AD 화면에서만 제공합니다. 기업 화면에는 작동하지 않는 버튼 대신 원산지 입력 안내를 표시합니다.

기존 미국 계산기는 `import_country`가 명시적으로 미국 이외인 경우 계산을 거부합니다. 한국 수입 사건의 계산·법적 부과 모델을 구현했다고 주장하지 않습니다. 모든 신규 사건의 `rate_pct`는 null, `calculation_ready`는 false입니다. 기존 국가 관세·제재 파일 또는 별도 세율표에 값을 복제하지 않았습니다.

### 중국산 마그카본 벽돌 → 미국

- [2026-16051, 2026-08-06](https://www.govinfo.gov/content/pkg/FR-2026-08-06/html/2026-16051.htm): 2024-09-01~2025-08-31 연례재심 철회. 재심 대상 거래 부재에 따른 것이며 AD 명령 철회·0% 판정이 아닙니다. 공고의 Cash Deposit Requirements는 예치율 변경 없음을 명시합니다.
- [2026-22523, 2026-11-04](https://www.govinfo.gov/content/pkg/FR-2026-11-04/html/2026-22523.htm): A-570-954와 멕시코 A-201-837의 제3차 일몰 최종결과. 이번 연결은 중국산 A-570-954만 대상으로 합니다. 일몰에서의 재발 가능성 마진을 현금예치율·조선내화 세율로 사용하지 않습니다.
- [2026-22529, 2026-11-04](https://www.govinfo.gov/content/pkg/FR-2026-11-04/html/2026-22529.htm): C-570-955의 제3차 CVD 일몰 최종결과. AD와 별도 제도이며 일몰 보조금률을 계산에 사용하지 않습니다.
- 절차 표시는 해당 상무부 일몰 최종결과만 확인으로 둡니다. 같은 차수 ITC 결과·명령 유지/철회는 이번에 확인하지 않아 미확인입니다. 일반적인 확정 대기와 구분합니다.
- 성분·결합·형상·생산국·실제 제조/수출 법인의 대상 범위와 현행 예치 지침이 필요합니다. 고알루미나·부정형·원료 MgO 등 내화재 전체에 확대하지 않습니다.

당일 GovInfo 2건은 브라우징 검색 도구에서 조회 오류였지만 일반 공식 HTTPS 원문 요청으로 HTML 본문을 직접 받아 확인했습니다. 접근 거부를 우회한 요청이 아니며 검색 스니펫만으로 확인 완료한 것이 아닙니다. 참고용 원문 SHA256:

### 중국산 초산에틸 → 한국

[무역위원회 진행 목록](https://www.ktc.go.kr/proInvestList.do)의 `구제23-2026-6호`, 개시일2026-08-18, 진행단계 `조사실행`을 11/04 확인했습니다. 목록의 개시일을 공고 발행일이나 세율 발효일로 바꾸지 않았습니다.

개시만 확인으로 표시하고 예비판정·잠정조치·최종판정·부과/가격약속은 미확인으로 둡니다. 세부 개시공고·대상 순도/HS·제소인·대상 공급자·제조/수출자·현재 세율·과거 조치와의 관계는 추가 확인이 필요합니다. 후성이 제소인/피소기업이거나 특정 중국 공급자와 거래한다는 사실은 확인하지 않았습니다. 과거 2019년 등 다른 차수 세율을 현재 조사에 복사하지 않았습니다.

### 한국산 아세톤 → 미국

[2026-11549, 2026-06-09](https://www.govinfo.gov/content/pkg/FR-2026-06-09/html/2026-11549.htm)는 A-580-899, POR2024-03-01~2025-02-28의 최종결과입니다. 개별조사 제조/수출자는 Kumho P&B Chemicals, Inc.입니다. 이 공고에서 확인한 제조사의 마진·예치 조건을 후성의 고유 세율 또는 중국산 아세톤의 세율로 사용하지 않습니다. 기업별 적용·현재 세그먼트 전수검토는 미완료입니다.

## 상태와 한계

- ‘제품 취급 확인’과 ‘정부 조사 확인’을 분리했습니다. 사건이 미확인인 경우 정부 판정 대기·면제·0%로 표시하지 않습니다.
- 새 품목의 HS/HTS·MFN·탄력성·세계 시장 비중·거래액은 임의로 넣지 않았습니다. 실제 사양·거래·시장자료가 필요합니다.
- 추가 공고는 이번 선별 확인의 정적 근거입니다. 기존 13개 미국 사건의 자동 수집 범위와 월1회 예약은 변경하지 않았습니다. 한국 KTC 자동 수집·변경 알림은 이번에 구현하지 않았습니다.
- 미국 관세 단일 원본 통합, 기존 보류된 일본 열연/한국 OCTG 해결, DB·메일·배포는 이번 범위 밖입니다.

## 검증

관련 Node135개·소유권15개 통과. 실제 mount 이벤트로 산업/기업 선택, 중국산 전환, 한국 수입 사건 표시, 기업 화면 연결을 검증했습니다. 수입국/원산지/제품/법인 격리, 신규 세율 null, 일몰과 명령 유지·재심 철회의 차이, 원산지 불일치 시 단계 미표시를 검사합니다. 기존 테스트의 고정 제품·기업 수는 새 등록 수에 맞게 수정했습니다.

실제 브라우저 렌더링/라이브 UI는 미검증이며 과거 브라우저 보안 거부를 다른 surface로 우회하지 않았습니다. 최신 main `8c0939a6d` 기반 전용 worktree에서 작업했고 사용자 변경/이전 worktree의 삭제된 .venv 등을 복구하거나 포함하지 않았습니다. 병합·배포는 별도 승인 대상입니다.
