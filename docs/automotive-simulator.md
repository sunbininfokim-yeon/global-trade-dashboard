# 자동차·부품 시뮬레이터

확인일: 2026-10-12. 기존 자동차/기아 하나의 경로를 자동차·부품 독립 산업과 8개 품목으로 나눴다. 전체 산업 선택은 22개 품목, 기업 목록은 40개 프로필이다. 반덤핑 사건은 기존 5개/33개 법인 그대로이며, 자동차 기업의 미확인을 AD 0%로 바꾸지 않는다.

부품은 제조사 공식 제품·생산거점 자료로 후보를 연결한다. 관보의 AD 대상 기업 목록으로 표현하지 않는다. 현대자동차는 현대제철·현대스틸파이프·HD현대일렉트릭과 별도 프로필이다. 새로운 3개 회사는 재무 미수록(`financial:null`)·거래 단가/물량/원가/원산지 공란이며, 기존 기아의 전사 재무도 제품 손익에 자동 대입하지 않는다.

## 공식 자료와 적용 조건

- 제품군: [현대자동차 동력원·SUV 소개](https://www.hyundai.com/eu/en/models/suv-cars.html), [현대 PHEV 소개](https://www.hyundai.com/eu/en/models/hybrid-cars/plug-in-hybrid.html), [기아 HEV/PHEV/EV](https://www.kia.com/us/en/ev).
- 부품군: [현대모비스 공식 사업·제품](https://www.mobis.com/en/aboutus/aboutus.do), [HL만도 공식 제동·조향·현가 생산거점](https://www.hlmando.com/en/hl-mando/global-network.do). 국가별 생산거점의 존재를 특정 거래의 원산지 판정으로 사용하지 않는다.
- 신규 완성차 3종의 기본 관세: USITC 공개 HTS `reststop/search?keyword=8703`에서 위 세 HTS8의 Column 1 General **2.5%**와 서로 다른 동력원 정의를 확인. 화면의 품목별 원문 링크로 다시 확인 가능하다. [HEV](https://hts.usitc.gov/search?query=8703.40.00) / [PHEV](https://hts.usitc.gov/search?query=8703.60.00) / [BEV](https://hts.usitc.gov/search?query=8703.80.00).
- 한국·일본 완성차의 조건부 232 경로: [한국 2025-21940 Part A](https://www.govinfo.gov/content/pkg/FR-2025-12-04/pdf/2025-21940.pdf), [일본 2025-17908](https://www.govinfo.gov/content/pkg/FR-2025-09-16/pdf/2025-17908.pdf). 현행 HTS [9903.94.61](https://hts.usitc.gov/search?query=9903.94.61), [9903.94.41](https://hts.usitc.gov/search?query=9903.94.41)의 대상국 승용차/경트럭·Column 1 15% 미만 조건과 **15%** 항목을 10/12 재확인. Note 33(b)의 적용 제품·원산지 조건에 맞는 완성차만 선택한다. [공식 승용차 HTS 열거 예시](https://www.govinfo.gov/content/pkg/FR-2025-06-30/pdf/2025-12060.pdf)는 HEV/PHEV/BEV 세 분류를 구분한다. 영국 쿼터 경로를 이 도구에 추가했다는 뜻은 아니다.
- 위 합산 경로에 일반관세 2.5%를 다시 더하지 않는다. 232와 AD/CVD는 별개이며 실제 제품의 별도 추가세·예외는 확인이 필요하다. 중국·캐나다·멕시코·독일 등의 미검증 조합은 출처와 현행 총 세율 직접 입력이 필요하다.

신규 분류 확인일 `classification_checked_on=2026-10-12`를 국가/기업 JSON에 기록한다. 다른 품목의 정책 검토일(10/11), 공급국 통계(2025), AD 예치율 확인일을 함께 갱신하지 않는다. 새 3종의 DataWeb 공급국 순위는 아직 수록하지 않았으며 가솔린 통계를 복사하지 않는다.

## 탄력성·계산

신규 3종은 기존 자동차의 넓은 문헌 대용값 σ=7.58와 η=-0.82를 사용하되 차종 전용 추정치 미확보를 표시한다. σ의 범위는 승용차·경트럭, η는 신차 총수요 문헌 검토 범위 중간값이다. HEV/BEV별 현재 실측값이나 권장 단일값으로 소개하지 않는다. 각 값의 개별 출처·범위·확인 시점은 국가 탭과 JSON에 보존한다. 부품 4종에는 이 값을 복사하지 않고 σ=4/η=-1을 사용자 가정으로 둔다.

국가 탭은 품목 선택 → 공급국·구매액·관세 조건 → 비교 관세 → 계산으로 사용한다. 기업 탭은 실제 기업 → 품목 → 제품 원산지 → 거래·원가 → 가격 대응 가정 → 계산이다. 미국 현지 생산은 미국 원산지로 구분하고 한국산 수입관세를 자동 적용하지 않는다. 반덤핑 탭에서는 자동차·부품을 선택해 후보·공식 제품 출처와 AD 미확인을 확인한 뒤 ‘기업·품목 손익 분석’으로 이동한다. 확인하지 않은 AD 예치액·재심·소송 단계는 표시하지 않는다.

로컬 검토와 PR #528 범위이며 운영 배포·DB·상시 수집·메일·유료 AI 호출은 포함하지 않는다.


## 미확인 자료 확인 후속

제동·조향·현가 대표 사양의 HTS와 한국·일본 지정 부품 조건부 경로를 추가 확인했다. AD/CVD는 한국 활성 사건 51개 제품명을 검토한 제한된 결과이며, 직접 대응 사건 미발견을 0%로 바꾸지 않는다. 관련 유압실린더 조사와 OCTG 사건·과거 최종 마진은 현재 예치율과 분리했다. 국가/기업/반덤핑 화면에 접힌 공식 자료 확인 결과와 원문 링크, JSON에 확인 근거를 보존한다. [51개 사건·분류·관세·남은 조건](policy-product-verification-20261012.md).
