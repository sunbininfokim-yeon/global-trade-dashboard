# 미국 주가 요인 전망의 독립 저장과 전향 채점

11월 23일 07:52 KST 실행은 미국장 요인을 세 자산 모두 계산했지만 15007 콜·풋 결측 때문에 통합 전망이 비었다. 원래 실행의 입력 아티팩트를 로컬에서 같은 시각으로 재현했다. 해당 스냅샷에서 콜·풋 모두 11월 16~20일에 유효한 값이 없었고, 원자료 저장소에서 11월 18일·20일 자료는 11월 23일 17:59 KST에 처음 올라왔다. 실행 요약의 성공 표시와 달리 상세 로그에는 비공개 원자료 저장소의 기본 브랜치 조회가 GitHub `Not Found`로 실패했고 재시도한 기록이 있다. 현재 워크플로에서 사용하는 `GH_DISPATCH_TOKEN`의 해당 저장소 읽기 권한을 확인해야 한다.

- 기존 아침 실행기는 미국 가격을 국내 가격 및 KRX 15007 처리와 독립적으로 수집한다. 원본으로 해소되지 않은 날짜와 읽을 수 없는 원자료는 시도 기록에 남긴다.
- 미국장 입력이 08:30 이전에 확인되면 당일 첫 미국 요인 결과를 `data/forecasts/us_kr_direction/<date>/us_price/<model_id>/first.json`에 보존한다. 동일 날짜 재실행은 첫 기록을 재사용한다. 과거 재생은 이 경로에 쓰지 않는다.
- 종가 이후 기존 전향 채점기가 `us_price_forward`를 별도로 집계한다. v1이 없는 날도 채점하고, 상승·하락 포착률, 놓친 하락일 수, 하락 경고 적중률과 Brier를 기록한다. 기록은 개장 전 생성의 증거다. 실제 공개 페이지에서 확인했는지는 별도 검증이 필요하다.
- 기존 Actions가 이미 공개 JSON과 전체 예측 기록 폴더를 저장하고, 기존 채점 결과를 커밋한다. 동결 모델, 원래 v1 원장, 배포 설정과 UI는 기존 소유 규칙을 따른다.

## Claude 화면 및 운영 연결

`market-microstructure.js`의 `msFactorSection`은 현재 `msDirectionView`가 통합 전망 결측을 반환하면 미국 요인도 감춘다. 미국 요인은 `doc.target_date`, KST 거래일, `factors.us_price.status`, `as_of === expected_source_date` 및 `generated_at <= forecast_cutoff_KST`를 기준으로 독립 표시할 수 있다. 홈에는 통합 전망이 비었을 때만 별도로 **미국 주가 기준**을 붙여 미국 요인의 시가·종가 방향을 보여준다. 날짜가 지났거나 오늘 입력이 없으면 자료 없음으로 표시한다. 회귀검증에는 통합 `cards: []`, 미국 요인 세 카드 사용 가능, 과거 대상일의 요인 미표시 사례를 포함한다.
