# 코스피 시가 갭 크기와 시가·종가 반전

시가 갭 크기 엔진은 전일 종가 대비 당일 시가의 절대 수익률을 예측한다. 반전 엔진은 전일 종가를 기준으로 시가와 종가의 방향이 엇갈릴 확률을 추정한다. 갭 상승 뒤 전일 종가 아래에서 마감하는 경우와 갭 하락 뒤 전일 종가 위에서 마감하는 경우를 모두 반전으로 계산한다. 전일 종가와 동일한 시가 또는 종가는 학습 표본에서 제외한다.

| 시점 | 결과 | 학습 입력 | 순차 검증 Brier |
|---|---|---|---|
| 07:00 KST | 예상 절대 갭의 중앙값, 임계치 초과 확률 | 국내 과거 가격, 미국 시장 마감 수익률 절댓값 | #1112 크기 검증 표 |
| 07:00 KST | 반전·유지 확률 | 과거 분기별로 재현한 예상 절대 갭을 3구간으로 나눈 뒤 각 구간의 반전율 학습 | 0.1980 → 0.1954, 2,275일 |
| 10:00 KST 이후 첫 시간봉 확정 시 | 반전·유지, 전일 종가 대비 종가 상승·하락 확률 | 실제 시가 갭의 크기·방향과 첫 60분 움직임의 로지스틱 학습 | 0.1687 → 0.1366, 451일 |

Brier 점수는 낮을수록 좋다. 개장 전 기준 모델은 과거 전체 반전율이다. 첫 시간봉 검증의 기준 모델은 실제 시가 갭의 크기와 방향을 쓴다. 각 검증은 이전 분기까지의 정보만 사용해 다음 분기를 예측했다. 학습 종료일은 2026-11-20이다. 크기 모델과 반전 모델의 아티팩트와 버전 ID는 각각 별도다. 배포 후 일상 실행 단계는 고정된 값으로 추론한다.

개장 전 반전 모델의 구간 경계는 매 학습 시점의 최근 126개 재현 추정값으로 설정한다. 배포용 모델의 경계는 0.877%, 1.097%다. 이 고정 경계에 포함되는 과거 날짜 수는 낮음 2,311일, 중간 131일, 높음 130일이다. 표본 내 비율·구간 경계를 장기간 그대로 사용하면 최근 시장 변동에 따라 한쪽으로 쏠릴 수 있다. 확률의 실시간 교정 수준은 향후 실제 발행 기록으로 평가한다.

## 실행과 연결

- 크기 출력은 기존 `kr_gap_size_shadow.py`에서 받는다. 반전 출력은 `kr_gap_reversal_shadow.py`의 별도 JSON을 사용한다.
- `record --stage preopen --target YYYY-MM-DD --gap-forecast <동일 날짜의 실제 크기 예측 JSON>`을 크기 출력 직후 실행한다. 08:30 KST 이내의 실제 실행 시각, 동결된 크기 모델 ID, 한국·미국 자료 기준일, 당일 KOSPI 갭 추정값을 확인한다.
- `record --stage first_hour --target YYYY-MM-DD --daily <야후 ^KS11 일봉 JSON> --hourly <야후 ^KS11 시간봉 JSON>`으로 첫 시간봉 모델을 실행한다. 야후 응답에서 10시 봉이 시작되면 09시 시작 봉이 닫힌 것으로 확인하며 10시 이후 봉의 가격은 입력에서 제외한다. 전일을 끝으로 하는 21개 거래일 종가와 당일 첫 시간봉만 읽는다. 지연 개장일과 불완전한 가격에서는 예측을 보류한다.
- 결과는 `data/forecasts/kr_gap_reversal_shadow/<target>/<model>/<stage>/first.json`에 실제 생성 시각과 함께 저장한다. 과거 테스트는 `replay --as-of ... --output ...`으로 별도 경로에 기록한다.
- 재현 사례는 11/23 07:00 예상 갭 2.47%, 반전 16.2%와 11/24 10:00 첫 시간봉 반전 0.45%다. 11/24 야후 일봉 종가가 누락돼 후자의 당일 정오답은 확인하지 못했다. 확정적인 방향 라벨로 UI에 내보내기 전에 실제 발행과 확률 보정을 검증한다.
