# 개장 전 입력별 전망 JSON — Claude 인계

공개 `us_kr_direction_v1.json`의 `factors`를 사용한다. 홈의 `cards`는 기존 통합 모델이다. 요소별 확률은 서로 더하지 않는다. 시가와 종가는 각각 전일 종가 대비이고 보합 확률은 제공하지 않는다.

| 키 | 고정 입력 | 대상 |
| --- | --- | --- |
| `options` | KOSPI200 외국인 콜·풋 순매수 비중의 60일 순위와 5일 평균 | KOSPI, 삼성전자, SK하이닉스 |
| `foreign_stock_flow` | 해당 종목 외국인·기타외국인 현물 순매수대금의 시장 매수대금 대비 비율 및 5일 평균 | 삼성전자, SK하이닉스 |
| `us_price` | QQQ·SPY·SMH·MU·NVDA·AMD 종가 수익률, VIX 수준·변화 | KOSPI, 삼성전자, SK하이닉스 |

세 묶음에 국내 가격 통제를 넣지 않았다. 미국 묶음의 `label_ko`에는 VIX를 명시했다. 각 `cards`에는 `status`와 시가·종가 점수가 있다. 결측은 카드 `unavailable`과 확률 `null`로 표현한다. 묶음의 `partial`은 일부 종목만 유효함을 뜻한다. `as_of`는 유효한 관측일, `expected_source_date`는 요구한 거래일이다. 점수가 있어도 `validation.skill`이 `none`이면 기존 관측 패널과 과거 방향 정보 없음만 표시한다.

학습은 `train_us_kr_factors.py`의 별도 명령으로만 한다. 확장 학습·직전 6개월 보정·다음 분기 평가의 경계를 분기 시작 + 달력 3개월로 설정했다. `n`은 유효 종목×목표×거래일의 수이고 `base_rate`는 해당 표본의 실제 상승 비율이다. `brier_base`는 분기별 직전 보정기간 상승 빈도를 같은 평가일에 적용한 값이다. `balanced_hit`은 실제 상승·하락일을 각각 맞힌 비율의 평균이다. 종목·목표별 값은 `validation.by_ticker`에 있다. 같은 날짜의 확률 오차를 묶은 블록 재표집과 세 묶음 Holm 보정으로 skill을 판정했다. 점수는 과거 시간순 재현이다.

아침 실행기는 고정 파일 `models/shadow/us_kr_factors_20261108_v1.json`을 읽는다. 기존 KRX 15007 체크아웃에 있는 12009의 해당 월만 읽고, sparse checkout으로 작업 트리에 없으면 같은 체크아웃의 Git 객체를 조회한다. 별도 정규화 디렉터리는 `--stock-flow-root`로 줄 수 있다. 5거래일 창의 누락이나 지연을 대체하지 않는다. 기존 워크플로가 당일 홈 발행 후 재시도를 생략하는 제약은 적용된다.

11월 9일 예시는 실제 11월 6일 원천을 사용해 기존 공개 스냅샷에 `factors`만 추가했다. 삼성전자와 SK하이닉스 12009는 이 예시에서 모두 unavailable이다. 요인 계산을 공개 표시 단계에만 두었고 v1 첫 예측·시도·수정 기록은 변경하지 않았다.
