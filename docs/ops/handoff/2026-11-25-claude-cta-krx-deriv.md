# 인수인계 2026-11-25 — claude → (새 세션) CTA 추세 수급을 KRX 파생 수급에 붙이기

매크로 모니터 세션에서 넘기는 작업이다. 사용자가 "CTA는 KRX 파생 수급 데이터에서 진행하자"고 정했고,
**다른 세션에서** 진행한다. 아래는 조사·시험까지 끝난 상태이며 **코드·데이터는 아직 아무것도 커밋되지 않았다.**

## 0. 시작 전에

- 전용 워크트리, `claude/<주제>` 브랜치(예: `claude/cta-krx-deriv`). main 직접 push·force-push 금지.
- 배포 전에 화면을 실제 숫자로 설명하고 사용자의 명시적 "배포"를 기다린다(머지 = 배포).
- 커밋 전에 무엇을 해냈는지와 파일 목록을 먼저 말한다.
- 유료 데이터 금지. 키·이메일을 코드·로그·커밋에 쓰지 않는다.
- UI 큰 편집은 재실행 가능한 패치 스크립트로 하고 `grep` 으로 반영을 확인한다(CLAUDE.md).

## 1. 배경 — 사용자가 리버스 엔지니어링하려는 것

GS의 CTA 포지셔닝 차트(텔레그램 채널 글에 실린 것, 2026년 9월 초 시점 자료).
- 원자재(브렌트·WTI·금·구리)는 순롱 $bn, 미 국채(2·5·10·30년)는 DV01 $mn/bp.
- 회색 'Simulated Realized Flows'는 실제 포지션이 아니라, 가격 추세로 CTA 포지션을 **모델로 추정한 값**.
- 오른쪽은 1개월 조건부 전망. Flat, Up Small, Up Big, Down Small, Down Big 다섯 경로에서 CTA가 사고팔 양.
- 글의 요지:
  - 일방향 수급을 뒤집는 '리버설 스레숄드'가 9월에 몰려 있다.
  - 포지션 PnL의 상·하방 스큐가 중요하다.
  - 바이백·FOMC 같은 이벤트는 '시간가치'가 줄어드는 이벤트 팩터다.

**CTA**는 선물로 추세를 따라가는 시스템 펀드(매니지드 퓨처스)다.
- 1·3·6·12개월 수익률로 방향을 정하고, 변동성 목표로 크기를 정한다.
- 규칙이 기계적이라 가격만으로 포지션과 뒤집힘 가격을 역산할 수 있다.

## 2. 이미 검증한 모델 (프로토타입)

```
LB = (20, 60, 125, 250)                 # ~1m, 3m, 6m, 12m 거래일
vol = 최근 60일 일간 로그수익률 표준편차
s_k = clip( ln(P_t / P_{t-k}) / (vol * sqrt(k)), -1, +1 )
signal = mean(s_k)                      # -1 최대 숏 … +1 최대 롱
뒤집힘 가격(내일 기준) = P_{t+1-k}       # 각 룩백의 기준가 = 그 가격을 넘으면 s_k 부호가 바뀜
시나리오: 1개월 σ = vol*sqrt(21); 21거래일 동안 가격을 exp(m*σ*d/21) 로 직선 이동,
          m = 0(보합), ±1(소폭), ±2.5(대폭); 매일 signal 재계산
```

## 3. 만들 것 (사용자에게 제안한 범위)

**위치:** 시장미시구조 → KRX 파생 수급 화면에 'CTA 추세' 블록 추가.
- UI: `New for anti/market-microstructure.js`
- 빌더: `New for anti/scripts/market_microstructure/build_krx_deriv_flow.py`

**블록 구성**
1. 코스피200 선물 추세 신호: 전체 값과 1·3·6·12개월 각각, 뒤집힘 가격, 현재가 대비 거리(%와 σ 배수).
2. **스레숄드 달력**: 앞으로 각 룩백의 기준가가 어떻게 바뀌는지. 원글의 "스레숄드가 9월에 몰려 있다"를 매일 자동 판정.
   - 방법: 향후 N일의 기준가 `P_{t+d-k}`를 현재가와 비교해 현재가 ±x% 안으로 들어오는 날짜를 표시.
3. **다섯 경로 1개월 예상 신호 차트**: GS 차트와 같은 모양. 단위는 신호(-1~+1). 운용자산 규모를 모르므로 원화 금액은 쓰지 않는다.
4. **실측 비교**: 외국인 선물 순매수(누적 또는 60일 합)를 나란히 그리고, 상관(0.36)을 적는다. 기관·개인 계좌도 데이터에 있다.

**이벤트**: FOMC·한은·옵션 만기·바이백 날짜를 차트에 겹칠지는 사용자와 상의.
- 한은 일정: `cb_policy_v1.json` KOR `schedule`
- 미국 바이백 일정: 매크로 USA `ust_buybacks.buybacks.calendar`

**구현 메모**
- 신호 계산은 빌더(Python)에서 하고 결과만 JSON에 싣는다. 브라우저에서 2019년부터 다시 계산하지 말 것.
- 산출 위치: `krx_deriv_flow_v1.json`에 `cta` 블록을 추가하거나 별도 파일 `krx_cta_v1.json`. 기존 화면을 깨지 않게 선택.
- 테스트: `New for anti/scripts/market_microstructure/tests/`에 신호·뒤집힘 가격·시나리오 경계값.
- 최근월물 종가는 롤오버일에 월물이 바뀐다. 2019년 이후 32번이고 지수선물이라 갭은 작다. 보정 여부를 결정하고 적어 둘 것.
- 종가가 빈 날이 있다(`close` None 5일, 마지막 값은 11/6). 결측은 채우지 말고 관측일만 쓴다(이 폴더 규칙).
