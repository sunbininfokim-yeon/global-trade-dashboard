46개 저장 시계열에는 공개 관측이 없는 국가도 unsupported/null로 포함된다.
7개 계약 테스트, JS 검사, 실제 원본 수집 및 로컬 가스 화면·Rehden 이력을 확인했다.
Actions가 매일 한국 09:35 수집하고 기존 Cloudflare 배포 작업이 공개 JSON SHA256을 검사한다.
키는 기존 GitHub secrets를 사용한다. 원본 작업 트리는 수정하지 않았다.
