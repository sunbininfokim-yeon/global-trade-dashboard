1. 기존 주간 수집기는 전국 공개 API를 한 번 읽는다. 네트워크 호출을 104번 늘리지 않는다.
2. 매회 현재 `usa_election_ratings_review_v1.json`과 `elections_board_v1.json`을 대조해 104석과 같은 **기준**으로 대상을 재계산한다. 대상 수는 Cook·현직/이력이 바뀌면 달라지며 104를 고정하지 않는다.
3. 하원 우선 대상은 `collection_priority.order=0`. 내부에서는 기존 요청 주 → Cook → 한국기업 소재지 우선순위를 보존한다. 상원·주지사 기존 발견 경로는 유지.

5. 알려진 기관/원문 도메인·검토 대진·기간·모집단·표본 검사에 맞는 새 조사는 기존 자동 편입 경로로 들어온다. 미등록 원문·새 후보·정파 조사·변경된 개별 원문은 검토 대기. 공개 API 밖 모든 발표를 자동 발견하는 서비스는 아니다.
6. 원문 기반 메타데이터 정정은 ID·URL·기관·날짜·표본·후보/수치·의뢰자 등의 원 API 지문을 모두 묶는다. 표본/모집단/조사 날짜만 명시된 원문 값으로 정정하며 원 값을 보존한다. 응답이 바뀌면 정정 재검토. 후보 이름·지지도는 이 경로로 정정하지 않는다.
