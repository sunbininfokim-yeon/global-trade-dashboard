# 2026-11-17 Claude → Codex: 옵션 수급 재설계 연구 + v2 그림자 모델

## 한 줄

현재 v1의 옵션 입력 4개는 방향 예측에 기여가 없다. 하지만 사용자는 **옵션 수급이 유의하다**고 보고,
"우리가 반영하지 못한 무엇인가"가 있다고 판단한다. Codex는 옵션 신호를 **다시 정의해서** 이 판단을 검증한다.
그동안 공개 카드는 v1 그대로 두고, 옵션을 뺀 v2는 v1 옆에서 그림자로 기록한다(이번 PR).

## 1. 지금 옵션이 어떻게 들어가 있나 (v1, 동결)

`option_direction_model.option_features()`:

- 원천: `derivatives_board_v1.json` → `detailed_15007` → `options_call`, `options_put`
  (KOSPI200 옵션 전체 합계. 행사가와 만기 구분 없음)
- 값: **외국인 순매수 대금(KRW) ÷ 시장 전체 매수대금**, 콜과 풋 각각
- 입력 4개: 직전 60거래일 대비 당일 순위(`call_rank60`, `put_rank60`), 최근 5일 평균(`call_mean5`, `put_mean5`)
- 18개 입력 중 계수 비중은 2~15%다. 검증에서는 균형 적중률이 ≈50%였다(Codex 수정판 수치).

## 2. 왜 "옵션이 무의미"가 아니라 "측정이 틀렸을 수 있다"인가

대금 기준 순매수에는 서로 반대 방향의 포지션이 한 숫자로 섞여 상쇄된다.

| 섞이는 것 | 방향 의미 |
|---|---|
| 콜 매수 vs 콜 매도(순매수 음수) | 상승 베팅 vs 상승 제한·커버드콜 |
| OTM 풋 매도(순매수 음수) | **상승·횡보** 베팅인데, 수치상으로는 "풋 순매도"로만 보인다 |
| 깊은 ITM 1계약 vs 먼 OTM 수백 계약 | 대금은 비슷해도 델타 노출은 전혀 다르다 |
| 신규 진입 vs 청산 | 같은 순매수라도 의미가 반대다 |
| 만기 당일·주간 옵션 | 만기 정리 매매가 방향 신호를 덮는다 |

## 3. 검증할 가설 (우선순위 순)

데이터는 무료 원천만 쓴다. 15007·12009는 krx-month-paste에 있다. 없는 항목은 "필요 자료"로 보고한다.

1. **델타 가중 순노출**
   - 행사가별 순매수 × 델타(BS, 당일 IV 또는 VKOSPI 근사)를 콜·풋에 걸쳐 합친다.
   - "외국인 순델타"가 한 숫자로 나온다. 행사가별 자료가 없으면, 그 자료가 필요하다는 것 자체를 결과로 적는다.
2. **선물과 합산**
   - KOSPI200 선물과 미니선물의 외국인 순매수를 옵션 순델타와 합쳐 **총 방향 노출**을 만든다.
   - 한국 시장에서 외국인 선물 순매수는 잘 알려진 단기 신호다. 이것이 빠져 있다.
3. **잔차 검정**
   - 옵션 신호가 미국 기반 확률로 **설명되지 않는 부분**을 맞히는지 본다.
   - 방법: v2 확률의 logit에 옵션 신호를 더해 Brier가 줄어드는지 확인한다.
   - 18개 입력에 선형으로 섞으면 작은 효과는 정규화에 묻힌다.
4. **조건부 효과**
   - 미국 신호가 약한 날(|p−0.5|<0.05)에만 옵션이 의미 있는지 본다.
   - 만기 주, 고변동성(VKOSPI 상위 분위)에서도 따로 본다.
5. **목표와 시차 변경**
   - 다음날 시가·종가 대신 다음날 시가→종가(장중)를 쓴다. `call_intraday_v1` tracker가 추적 중이고, 연구 당시 ≈+5bp, t≈1.9였다.
   - 2~5일 누적 수익률도 본다.
   - 사용자의 가설은 **"작지만 꾸준한 방향(52% 카지노)"**이다. 평가 지표는 적중률보다 **비용 차감 후 bp와 Newey-West t**를 우선한다.
6. **개별 종목**
   - 삼성전자·SK하이닉스 주식옵션과 주식선물의 외국인 순매수 → 해당 종목 방향.
   - 12009(종목별 투자자 주식 순매수)와도 결합해 본다.

## 4. 규칙

- 가설과 판정 기준은 데이터를 보기 전에 문서에 고정한다. 여러 비교는 Holm으로 보정한다. 검증은 walk-forward(확장 창)로 한다.
- 손대지 말 것: v1 모델 파일, `implementation_sha256`, first/attempt 기록, `call_intraday_v1` RULE과 장부.
- 통과한 가설은 **새 그림자 family**로 추가해 전향 기록부터 쌓는다. 공개 카드 교체는 사용자가 확정한다.
- 결과는 `docs/ops/handoff/<날짜>-codex-to-claude-options-*.md`로 넘긴다.
