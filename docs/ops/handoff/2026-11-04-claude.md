# 2026-11-04 Claude 인수인계

## 국가별 인사 명단 (Cursor #819~#852 병합 후)

- `build_personnel_public.py`가 나라별 최신 `config/<iso3>_personnel_<날짜>.json` 30개를 `public/data/personnel/<ISO3>.json`과 `index.json`으로 낸다.
  - 검증 항목: schema와 country가 파일 이름과 맞는지, as_of가 있는지, URL이 http(s)인지.
- 사용자 지시(11-04)에 따라 별도 '인사 명단' 블록은 두지 않는다. 기존 우측 블록에 끼워 넣는다.
  - 대통령제 나라는 '대통령실' 블록이 새로 생긴다.
  - 의원내각제 나라는 '총리실' 블록이 새로 생긴다.
  - 이원집정부제 나라는 '대통령실'·'총리실'이 각각 생기고, 기존 '행정부' 블록에도 명단이 붙는다.
  - 왕정은 '왕실' 블록이 생긴다. 이란은 기존 '최고지도자·권력기관' 블록에 넣는다.
  - 의회 명단은 기존 '의회' 블록 뒤에 붙는다.
  - 지방 명단이 있으면 '지방자치단체' 블록이 새로 생긴다.
  - 정당 성향(orientation)은 기존 '정당' 블록에 붙는다.
- 갈래 분류는 `personnel-roster.js`의 `CATEGORY_OF`와 `HOIST`가 맡는다. 블록 배치는 `country-shell.js`의 `personnelSectionOf`가 정한다.
  - `HOIST`: 영국 executive.prime_minister, 독일 government.chancellor처럼 행정부 묶음 안에 든 총리를 총리실 블록으로 꺼낸다.
- 화면은 범용 렌더러 `personnel-roster.js`가 그린다. 나라마다 스키마가 달라서다.
  - name이 있는 객체는 사람 한 줄로 그린다.
  - 정당·교섭단체 의석은 막대로 그린다.
  - 숫자 맵은 칩으로 그린다.
  - 근거 자료는 접어 둔다.
- 남은 일:
  - 영문 키 일부(근거 메모류)가 한국어로 안 옮겨져 있다. `LABELS`에 더하거나, Cursor가 원본에 `label_ko`를 넣는 방식으로 정리한다.
  - 명단을 갱신하면 builder를 다시 돌린다. `--check`가 테스트에 걸려 있다.
