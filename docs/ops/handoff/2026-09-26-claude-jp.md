- `boj_etf_holdings`(ETF 잔고 + 시장 내 BOJ 비중 통합 카드)는 **비중에 무료 출처가 없어** 실제 ETF 잔고만 남기고 비중 성분을 뺐다 — 실측 옆에 만든 값을 두지 않으려고.
- 각 나라 카드 옆 배지 집계(`data_status_summary`)가 실측으로 바뀐 뒤에도 옛 숫자로 남아 있었다(미국 27 demo → 실제 4). 미국·일본 wire 가 이제 다시 센다.
- **e-Stat appId**: 계정 1번 칸에 이미 있었고(로컬 `~/.config/estat.env` 600 에만 저장), 사용자 요청으로 2번 칸에도 새로 발급(이름 "ChokePoint Monitor macro", URL 은 대시보드 공개 주소 — localhost/사설 IP 는 등록 불가).
  **키 위치**: 로컬 `~/.config/estat.env`(600) + GitHub 시크릿 `ESTAT_APP_ID`(사용자가 2026-09-26 등록; Cloudflare 에도 넣었지만 워커는 e-Stat 을 부르지 않으므로 불필요 — 지워도 된다).
  워크플로가 시크릿으로 카탈로그를 조회해 매일 최신 파일을 읽고 `config/jp_estat_series_v1.json`(2010년 이후, 키 없음)에 남긴다. 시크릿이 없거나 조회 실패 시 그 캐시를 읽어 카드를 유지한다.
  e-Stat **DB**(getStatsList)에는 후생노동성 최근 월별 표가 없고(2021-10 갱신본만), **데이터 카탈로그**(getDataCatalog)에 최신 엑셀 파일이 올라온다. 이용 약관상 크레딧 표시를 두 카드의 `note_ko`에 넣었다.
- **남은 합성 13개와 이유**: PMI(`ism_mfg` `pmi_services_jp`)·`sovereign_cds_5y` = 유료 라이선스.
  `topix` = 무료 피드 없음(야후에 지수 심볼이 없고 TOPIX ETF 는 다른 양). `nikkei_vi` = 닛케이가 CSV 를 공개하지만 파일에 "무단 복제·유통 금지" 고지가 있어 쓰지 않음. stooq 는 봇 확인 페이지(우회하지 않음).
  `foreign_equity_flow` = JPX 주간 투자자별 매매동향 엑셀(`stock_val_1_*.xls`)은 받을 수 있으나 이용 약관 페이지를 못 찾아 재게시 가능 여부를 확인 못 함 — 사용자 판단 필요. `shunto_wage` = 렌고 집계 페이지를 찾지 못함(연 1회 값). `fx_intervention` = MOF 가 상세를 분기마다 갱신해서 "개입 없음"과 "아직 미반영"을 구분할 수 없음.
  `boj_jgb_share` `boj_etf_share` = 분모(JGB 발행잔액·ETF 시장 시총) 출처 없음. `boj_jgb_ops` `boj_jgb_purchase_*` = 총매입액은 회차별 공고문에만 있고, BS01 월간 변화는 순증감이라 정의가 다름. `shunto_wage` = 연 1회 렌고 집계(스크레이핑 필요).
