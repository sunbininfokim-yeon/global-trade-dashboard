## 일본 fixture_synth 39개 중 18개를 공개 관측값으로 교체

`macro_monitor/jp_public_series.py`, `wire_jp_public_series.py`, `tests/test_jp_public_series.py`. 워크플로는 새로 만들지 않고
`us_public_series_refresh.yml`(이름을 "Refresh public series (USA/JPN)"로 바꿈, deploy.yml 목록도 같이) 안에서 미국 뒤에 돈다 —
워크플로 하나가 끝날 때마다 배포가 한 번 뜨므로 나라별로 나누면 배포만 늘어난다.

**합성이 맞는지 확인**: 교체 전 카드는 전부 `fixture_synth`(엔진이 기준값 주변에서 시드 고정 랜덤워크를 만든 것)였고, 실제 값과 크게 어긋났다 —
BOJ 총자산 데모 756T vs 실제 644.7T, JGB 10년 데모 1.15% vs 실제 3.07%, 콜금리 0.48% vs 0.98%, 외환보유액 1,230B vs 1,083B, 엔 IMM 순포지션 −85K vs +72K.
(ETF 37.2T vs 37.0T, J-REIT +680B vs 651B 는 우연히 가까웠다.)

- `boj_etf_holdings`(ETF 잔고 + 시장 내 BOJ 비중 통합 카드)는 **비중에 무료 출처가 없어** 실제 ETF 잔고만 남기고 비중 성분을 뺐다 — 실측 옆에 만든 값을 두지 않으려고.
- 각 나라 카드 옆 배지 집계(`data_status_summary`)가 실측으로 바뀐 뒤에도 옛 숫자로 남아 있었다(미국 27 demo → 실제 4). 미국·일본 wire 가 이제 다시 센다.
- **남은 합성 18개와 이유**: PMI(`ism_mfg` `pmi_services_jp`)·`sovereign_cds_5y` = 유료 라이선스. 전국/근원/도쿄 CPI·`real_wage_yoy`·`job_applicant_ratio` = e-Stat API(무료 appId 발급 필요, 시크릿에 없음).
  `topix` `nikkei_vi` `foreign_equity_flow` = 무료 피드를 못 찾음(야후에 `^TOPX` 없음). `fx_intervention` = MOF 가 상세를 분기마다 갱신해서 "개입 없음"과 "아직 미반영"을 구분할 수 없음.
  `boj_jgb_share` `boj_etf_share` = 분모(JGB 발행잔액·ETF 시장 시총) 출처 없음. `boj_jgb_ops` `boj_jgb_purchase_*` = 총매입액은 회차별 공고문에만 있고, BS01 월간 변화는 순증감이라 정의가 다름. `shunto_wage` = 연 1회 렌고 집계(스크레이핑 필요).
