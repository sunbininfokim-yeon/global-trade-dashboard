### Goal / summary
`/api/macro-monitor?country=<ISO3>`를 19개국 전부 호출해서 `quality`/`data_status`가
`fixture_synth`/`demo`인 지표를 집계했다. **미국만 61%(36/59) 실데이터, 나머지
18개국은 전부 13~24%.** T32(cursor)/T33(claude)로 나눠서 진행한다.

### 발견한 것

- 여러 국가에 동시에 걸리는 demo 지표: `sovereign_cds_5y`(19개국 전부, 무료 소스
  없음 — 자동화 보류 권장), `gdp_yoy`(19개국 전부, **미국 포함**), `current_account`
  (18개국), `gdp_qoq`/`gdp`(14개국), `cpi_yoy`(14개국), `bond_10y`(12개국).
- 미국조차 `nfp`(FRED PAYEMS로 쉽게 가능), `gdpnow`(CME 급 공식 API 없음, 스크레이핑
  필요), `fedwatch`(무료 API 없음)가 demo. `fed_ust_holdings`류는 `build_soma_maturity.py`가
  이미 실데이터를 만드는데 인디케이터에 안 붙어 있음(wire 누락).
- 부수 발견: **`japan_growth_refresh.yml`이 2026-08-24부터 `openpyxl` 누락으로
  전부 실패**하고 있었다 — [PR #356](https://github.com/sunbininfokim-yeon/global-trade-dashboard/pull/356)로
  고침. capex_gdp_ratio/net_funding_demand/gdp_gap이 한 달 넘게 정체돼 있었다.
- 워크트리 `.worktrees/macro-refresh-cpi`(브랜치 `cursor/macro-refresh-cpi`)에
  Cursor가 이미 작업 중이던 `peer_macro.py`(비-미국 국채10년물·ECB정책금리·주가지수)를
  발견 — 테스트 통과, 완성도 높음. CPI/GDP/각국 정책금리는 "FRED OECD 미러가
  2023~2025년에 멈춰 있다"는 이유로 의도적으로 제외한 상태.
