## 현재 운영 확인

#769는 병합 없이 닫혔고 Claude 인수 #774는 병합됐다. 공개 배포의 view.mjs와 금액 JSON도 읽어 확인했다.
기존 기본 선택은 FY2027 정부안이었다. FY2026 총세입/총세출/적자는 존재했지만 의무·재량/계정 분류가 없어 세출 본문이 빈 안내로 끝났다.
FY2026 실적은 세입 5.40332675896081조, 세출 7.39579998331323조, 적자 1.99247322435242조 USD다.
FY2027 표시 세출 8.09286조는 OMB 정부안 PBD 계정 합계이고 세입은 세입표, 적자는 두 수치 차이로 계산한 연간 추정이다. CR 허용액이나 의회 확정액이 아니다.

## 변경

- 상단에 FY2027 임시예산의 일반 기간 10/1–12/11, P.L.119-103 §106(3), 조기 종료/예외, 임시인 절차적 이유를 표시한다. GovInfo 원문을 11/5 다시 받아 검토 해시가 일치함을 확인했다.
- 의회 진행은 CRFB 11/3 집계(하원3/12·상원0/12), 협상 쟁점은 10/21 분석·10/27 보도·11/3 분석 등 각 날짜를 표시한다. 11/5 검토가 모든 입장이나 표결의 11/5 새 발생을 뜻하지 않는다.
- 쟁점은 재량지출 총액/국방-비국방 배분, 국방 자금의 정규·추경·예산조정 경로, 의회 자금의 행정부 집행·전용, 연말 패키지/연장 선택이다. 실제 CR에서 일단 조치한 OMB 규칙·DHS 전용·예외 배정은 미해결과 구분한다.
- 정부·의회 공식 자료, 당사자 입장, 보도, 외부 분석의 출처를 구분한다. Cole/DeLauro 원문 직접 접근은 403이어서 검색에 노출된 본문으로 확인한 상태를 기록했다. 외부 전망을 확정 사실로 쓰지 않았다.
- 현재 운영 근거와 선택한 연도 금액을 별개 영역으로 표시하고 최신 완료 FY인 2026을 기본 선택한다. FY2027은 정부안·연간 추정으로 표기하고 회계기간·합산/차이 산식을 설명한다.
- FY2026 세출에 Treasury 표6의 부처·조정항목 31개(관측30·미확인1)를 금액/증가액/증가율 순으로 연결했다. 음수·null을 보존한다. 비교 기준은 같은 MTS 발표본의 FY2025 전체 기간이다.
- 완료 FY의 표6 내용을 `annual.budget.agency_actuals`에 보존했다. 10월 보고서로 live FYTD가 FY2027로 넘어가도 FY2026 상세를 잃지 않는다. 의무·재량/계정 분류는 미연결 그대로다.
- 기존 36개월 자료와 금액을 공식 수집기로 다시 검증했다. 금액 개정은 0건이다. 맥락 JSON은 별도 builder로 생성하므로 일일 금액 갱신이 해설 검토 날짜를 자동 연장하지 않는다. 11/12 이후 또는 CR 기한 후는 재확인 필요다.
