## 결과와 연결 경로

기존 `/policy/us/budget` 화면과 예산 예약을 보강했다. #758 시안을 다시 적용하거나 새 예약을 추가하지 않는다.

- OMB 공식 XLSX 6종에서 최근 5개 완료 FY·의무/재량/이자·정부안을 재생성한다. Treasury 표 1·3·6은 최근 36개월과 누계를 검증한다.
- 동일 PBD에서 분야별과 별개인 **부처 → 산하기관 → 계정** 보기를 만든다. FY2022–2025 실적, FY2027 정부안에 연결한다. FY2026 실제 계정·성격별 자료는 미확인이며 추정치로 채우지 않는다.
- 지출액·증가액·증가율 정렬을 같은 계정 트리에 적용한다. OMB 기관/국/계정에 Treasury 기관·CGAC 코드까지 포함해 충돌을 방지한다. 같은 계정번호 977120의 재무부 기관 75/16은 별개다.
- `funding_review.json`의 검토된 법률·CBO 표를 `funding.py`가 확인한다. 현재 검토 범위는 FY2027 CR P.L.119-103과 §101의 12개 기존 세출법 참조, 관련 CBO 초안 표다. 모든 세출법·재정효과의 전수 수집이 아니다.
- GovInfo 원문에서 의회·법률·법안번호·제정일·제목·§106 일반 기한·§101 참조를 확인한다. 검토 해시가 바뀌면 재검토로 남긴다. 12월 11일은 조기 종료·조항별 예외가 있는 일반 기한이며 모든 사업의 현재 효력 판정이 아니다.
- CBO는 8월 2일 위원회 초안에 대한 8월 5일 표다. 확정법과 버전 일치는 미검증이다. 연간 환산 재량 BA/outlays와 별도 B–D 의무지출·세입·적자 영향을 분리한다. February 2026 baseline과 원래 누계 기간을 유지하고 전체 예산/MTS와 합산하지 않는다.
- `policy.js`의 법안 상세에 재정 근거 버튼만 추가한다. `finance.mjs`는 Congress/type/number 전체가 일치하는 검토 자료를 찾는다. 버튼을 누를 때만 자료 묶음을 읽으며 이탈 후 늦은 응답은 무시한다. 실제 운영 DB의 해당 법안 유무·검색 연결은 이번 검증에 포함하지 않았다.

## 갱신·출처 상태

연간/월별/법률 근거를 동일 `budget_live_v1.json`에 넣는다. 두 게시 산출물 계약은 그대로다.
핵심 금액 수집·합계 검증 실패는 마지막 정상 금액을 보존하고 실패 기록만 게시한다.
법률 보조 출처 실패는 별도 상태로 남긴다. 금액 수집 성공을 법률 전수 확인 성공으로 표시하지 않는다.

11월 1일 GovInfo CR 원문은 재확인됐다. NARA 법률 목록은 502, CBO 직접 다운로드는 403이었다.
목록 실패 시 후보 0건을 표시하지 않으며 이전 후보를 보존한다. CBO는 공식 문서의 텍스트·표를 검토한 날짜/버전의 스냅샷이며 직접 PDF 해시 검증이나 시각 검증을 완료했다고 주장하지 않는다.
CBO 자동 재시도는 11월 8일 이후, 그다음 시도부터 최소 7일 간격이다. 새 PDF를 받더라도 수치 검토 전 기존 표를 자동 승격하지 않는다.
공개 금액 묶음은 약 5 MB(비압축)이며 부처 계정의 여러 연도를 포함한다. API 키·유료 AI·Supabase는 필요 없다.
