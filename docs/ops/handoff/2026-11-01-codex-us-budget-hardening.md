## 결과

- 공식 OMB XLSX 6종에서 최근 5개 완료 FY 실적·의무/재량 분류·국방 계정·정부안을 재생성한다.
- 공식 페이지의 링크에서 FY/발표본을 찾고 같은 발표본만 사용한다. 새 FY의 불완전 공개·레이아웃 변경은 실패로 남긴다.
- Treasury 표 1·3·6을 묶어 최신 월별·누계·세입·기관·조달을 검증한다. 같은 기준일의 수정도 확인하며 큰 수정은 합계 검증 후 이력에 남긴다.
- 정부안(outlays), 미수집인 의회 확정 예산권한(null), Treasury 집행 실적을 구분한다. FY2026 실제 성격별 분류는 계속 미확인이다.
- 원본 데이터·출처·개념 구분을 한 파일에 저장해 연간/월별 파일의 교체 시점 불일치를 피한다.
- 실패는 마지막 정상 금액을 보존하고 별도 실패 기록을 게시한다. 화면에는 확인 시각·마지막 성공·자료 기준월·실패/지연을 표시한다.
- 기존 예약 이름과 deploy 연결은 유지한다. main 전용 게시 job 외에는 읽기 권한만 사용한다. 브랜치 실행은 운영 DB·main 데이터 쓰기와 무관하다.

## 검증

Python 27개 + Node 12개 = 39개 통과. actionlint 1.7.12 검사·YAML 파싱·git diff --check 통과.
Treasury API와 공식 OMB 엑셀의 실제 수집으로 FY2022–2026 및 FY2027 정부안을 재생성했고,
같은 발표본의 기존 검토 수치·국방 계정 합계와 일치했다. 원본 캐시·시크릿·회원정보는 포함하지 않는다.
브라우저에서 정상 갱신·수집 실패·새 묶음 503 시 보관 자료 대체, FY2026 분류 미확인 처리를 확인했다.

**기존 공통 검사 문제:** `python3 tools/ops/check_deploy_chain.py`는 변경 전 main에서도
`US election polls weekly`의 남은 연결 1건 때문에 실패한다. 예산 workflow는 기존 이름으로 정상 연결되어 있다.
이번 PR에서 선거 workflow·공통 deploy.yml은 변경하지 않았다. 공통 검사 문제를 예산 코드 오류와 구분해 검토한다.
