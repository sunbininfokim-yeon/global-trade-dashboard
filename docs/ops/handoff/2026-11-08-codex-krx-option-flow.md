## Codex KOSPI 재검증

Claude가 사용한 Naver KOSPI, Yahoo 미국 가격·VIX, KRX 15007 공개 보드 JSON 스냅샷에서 독립 재계산했다. Claude 표의 KOSPI 시가·종가 결과를 재현한 뒤 분기 경계 오류를 확인했다. 분기 시작은 1·4·7·10월이었으나 pandas `QuarterBegin(1)`의 기본 시작월은 3월이라 평가 종료가 3·6·9·12월 1일로 잡혔다. 그 결과 매 분기의 마지막 달이 평가에서 빠졌다.

수정 재검증은 분기 시작에 달력 3개월을 더하고, KRX·미국 직전 세션과 정확한 60개 직전 KRX 세션을 적용했다. 학습·직전 6개월 보정·다음 분기 평가를 분리했다. 비교 모델은 같은 목표일을 사용했다. 기간 2021-01-04~2026-11-06, 시가 1,430일, 종가 1,432일, 장중 1,431일. 각 목표의 보합은 이진 확률 검증에서 별도 제외했다. 방향 기준은 상승 확률 50% 초과이며 균형 적중률은 실제 상승·하락 각각의 재현율 평균이다.

## 상승·하락별 건수와 운영 변경안

동일한 과거 원천에서 수정한 분기로 재학습했다. 운영에 고정된 v1 계수의 실시간 성적은 별도다. 각 목표의 보합을 제외하고 확률 50%를 분류 기준으로 썼다. 표에 포함된 모델에서 정확히 50%인 예측은 없었다.

시가 미국 모델은 실제 하락 592일 중 368일을 맞혔다. 같은 368일을 모델이 하락으로 예측한 476일로 나누면 하락 예측의 적중률은 77.31%다. 옵션 단독은 시가 상승을 1,424/1,430일에 예측했고 전체 적중률은 58.46%였다. 항상 상승 기준은 58.60%다.

v1 구성 대비 옵션 제외·절단의 시가 하락 재현율 차이는 +1.69%p이며, 짝지은 5일 블록 95% 구간은 −0.17~+3.75%p다. 종가는 +0.91%p, 구간은 −1.22~+3.10%p다. 방향별 개선에는 불확실성이 남는다. KOSPI 시가 v1 구성의 85% 이상 확률 구간은 상승 평균 93.3%와 실제 89.3%(326/365), 하락 평균 94.0%와 실제 89.0%(154/173)로 양쪽 모두 과신이 관찰됐다. 종가의 같은 구간은 각각 46일과 25일이다.

1. 홈은 기존 공개 JSON의 `up_probability`와 `down_probability`를 시가·종가 각각 나란히 표시한다. 비교 기준은 둘 다 전일 종가다. 50/50은 방향 중립이고, 보합은 별도 확률을 추정하지 않는다.
2. 전향 평가에 방향별 실제 건수, 예측 건수, 맞힌 건수, 재현율과 예측 적중률, 균형 적중률을 추가한다. Brier와 확률 구간별 검증을 유지한다. 중립, 참조용 기저율, 결측은 각 상태의 건수로 보고한다.
3. KOSPI 전용 옵션 제외·절단 후보를 별도 고정 버전으로 생성해 v1과 미국만 기준에 같은 날짜로 전향 비교한다. 후보 추론은 필요한 국내 가격과 미국 입력만 읽도록 구성한다. 현재 옵션 제외 비교는 v1에서 이미 만든 특징을 받아 계산하므로, 15007 결측 때문에 v1이 멈추면 함께 멈춘다. 새 후보의 운영 교체는 전향 결과로 판단한다.

## 실제 미국 지수와 가설별 양방향 검증

2026-11-08 추가 검증. FRED에서 S&P 500(`SP500`), 나스닥 종합(`NASDAQCOM`), 나스닥100(`NASDAQ100`), 필라델피아 반도체(`NASDAQSOX`) 종가를 확보했다. 미국 세션은 한국 목표 거래일 개장 전에 이미 끝난 정확한 직전 세션을 썼다. FRED 종가는 과거 연구에 사용했으며, 당시 아침 마감 시각까지 제공됐는지는 확인하지 못했다. 원본 지수 파일은 연구 결과물에 포함하지 않았다.

KOSPI 시가 1,430일, 종가 1,432일, 장중 1,431일. 2021-01-04~2026-11-06. 확장 학습과 직전 6개월 보정 후 다음 3개월을 평가했다. 입력군마다 목표별 같은 날짜를 사용했다. 정확히 50%인 예측은 중립이고 방향을 맞힌 건수에는 넣지 않았다. 확률 오차 비교에는 50%도 포함했다. KOSPI 48개 및 개별주 12개 Brier 비교는 각각 Holm 보정했다. 시간 의존성을 고려해 같은 날짜를 짝지은 5거래일 블록으로 10,000회 재표집했다. 방향 차이 구간은 기술용 미보정 구간이다.

- **미국 마감**은 4개 실제 지수 단독과 기존 미국 입력 모두 시가·종가에서 최근 빈도 기준 대비 Brier 개선이 보정 후 남았다. 개별 지수 간 우위와 장중 Brier 개선은 확인되지 않았다. SOX의 조합 추가는 시가 Brier −.00337, 보정 p≈.63이다.
- **15007 수급과 거래활동**은 부호 있는 외국인 수급과 시장 거래대금 활동을 분리했다. 옵션 단독 시가 99.5% / 0.3%, 종가 69.1% / 31.6%. 국내 가격+미국에 외국인 콜·풋을 추가해도 개선되지 않았다. 콜+풋 총 거래대금과 풋/콜 거래대금 비율의 과거 60거래일 순위를 추가해도 확률 오차가 개선되지 않았다.
- **국내 가격과 절단**은 각각 별도로 비교했다. 국내 가격을 미국 입력에 더하는 효과와 ±3 표준편차 절단을 적용하는 효과 모두 보정 기준을 통과하지 않았다. 기존 미국 단독과의 개선 차이도 불확실하다.
- **콜 장중 규칙**은 기존 등록 규칙의 과거 재현이다. 상승 485/933(52.0%), 하락 498/951(52.4%), 균형 52.2%, 95% 블록 구간 49.98~54.42%. 별도 전향 추적 대상으로 유지한다.
- **월요일 분리**는 기존 시험 결과를 양방향으로 다시 집계했다. KOSPI 월요일 공통→분리 보정의 시가 상승 84.5→86.9%, 하락 52.1→43.8%. 종가 상승 85.7→83.1%, 하락 47.3→43.6%. 기각 결정을 유지한다.
- **만기일**은 KRX 규칙과 검토한 휴장일로 월물·분기 동시만기를 계산했다. 역사 계약 원장과 전수 대조하지 않은 달력 기준 시험이다. 미국 입력에 추가해도 양방향 확률 오차 개선을 확인하지 못했다. 동시만기 23일의 장중 상승/하락은 14/9일이며 평균 절대 시가→종가 변동은 .76%였다. 비만기일은 .84%였다. 종가 단일가 변동은 일봉으로 검증하지 않았다.
- **개별주 현물 외국인 수급**은 KRX 12009의 외국인과 기타외국인 순매수대금을 합산하고 시장 거래대금으로 나눴다. 파생 수급과 구분했다. 삼성전자 시가에서 전일 수급을 추가하면 상승 79.1→80.3%, 하락 65.4→66.4%, Brier .17785→.17217(1,286일, 양 종목 합산 12개 보정 p≈.0066). 5일 평균 입력도 삼성 시가 Brier를 개선했다. 상승·하락 재현율 개선의 개별 95% 구간은 0을 포함한다. SK하이닉스 및 두 종목의 종가·장중은 보정 기준을 통과하지 않았다. 15009 개별 옵션 활동은 이번 검증에 쓸 일별 원본이 확인되지 않았다.

전체 지표, 효과 구간, 비교별 표본, 입력·구현 SHA-256은 `data/manifests/kospi_direction_hypotheses_20261108.json`에 기록했다. 검증 재실행에서 핵심 결과가 일치했다. 이 검증의 자료는 과거 스냅샷이고 운영 모델·화면·예측 원장은 수정하지 않았다.

## 별도 전향 비교 실행기

`us_kr_hypothesis_shadow.py`와 고정 모델 `models/shadow/us_kr_hypotheses_20261108_v1.json`을 추가했다. 월요일을 포함해 모든 거래일에 같은 보정을 적용한다. 기존 공개 JSON과 운영 v1에는 연결하지 않았다.

| 비교 | 고정 후보 | 기준 |
| --- | --- | --- |
| KOSPI | 실제 S&P 500·나스닥100·SOX 지수 종가 | S&P 500·나스닥100 조합, 기존 미국 8개 입력 구성 |
| 삼성전자 | 국내 가격·미국 입력 + 전일 KRX 12009 외국인 현물 순매수 비율 | 같은 국내 가격·미국 입력 구성 |

각 자산의 비교군은 동일한 날짜로 학습과 확률 보정을 했다. 학습 상한은 2026-11-06이며, 마지막 유효 정답은 KOSPI 11-06, 삼성전자 10-30이다. 확률은 시가와 종가 각각 전일 종가 기준의 상승·하락을 제공한다. 보합 확률은 별도로 추정하지 않는다.

저장소 루트에서 실행한다. 기존 `requirements-us-kr-preopen.txt`의 런타임을 사용한다.

```bash
MM='New for anti/scripts/market_microstructure'
MODEL="$MM/models/shadow/us_kr_hypotheses_20261108_v1.json"
python "$MM/us_kr_hypothesis_shadow.py" predict \
  --target YYYY-MM-DD --model "$MODEL" --live \
  --flow-root krx-month-paste/data/normalized/krx_12009_stock_investor

python "$MM/us_kr_hypothesis_shadow.py" score \
  --model "$MODEL" --snapshot /path/to/closed-kr-bars.json
```

- 아침 실행은 실제 미국 지수의 Yahoo 기호 `^GSPC`, `^NDX`, `^SOX`와 기존 미국 가격을 조회한다. 학습의 지수 원천은 FRED 종가 스냅샷이다. `--flow-root` 아래에서 `year=YYYY/month=MM/part.jsonl.gz`의 정확한 전일 삼성전자 행을 사용한다. KOSPI는 15007 및 삼성 원본 결측과 독립이다.
- 아침 08:30 KST까지 생성한 최초 정상 예측을 `data/forecasts/us_kr_hypothesis_shadow/<목표일>/<모델 ID>/<후보>/first.json`에 보존한다. 빠진 후보는 정확한 값이 도착하면 마감 시각까지 별도로 기록할 수 있다. `predict --snapshot … --replay` 결과는 이 원장에 들어가지 않는다.
- 결과 입력은 `{"collected_at":"<timezone-aware timestamp>","kr":{"KOSPI":[{"date":"…","open":…,"close":…}],"005930":[…]}}` 형식이다. 대상일과 직전 거래일의 같은 출처 가격이 필요하다. 채점기는 장 마감 후 수집한 결과와 같은 날짜의 최초 예측만 맞춰 상승·하락 성적, 균형 적중률, Brier 차이를 계산한다. 운영 연결 시 기존 장마감 수집 자료를 이 입력 형태로 넘긴다.
- 2026-11-09 대상은 11-08 16:02 KST에 실제 가격으로 KOSPI 3개 비교군 및 삼성전자 가격·미국 기준을 기록했다. 삼성전자 수급 후보는 11-06 원본이 없어 비어 있다. 확인한 비공개 백업의 10월 파일은 열렸고 11월 파일 경로는 404였다. Cursor가 먼저 보강할 것은 2026-11-06 삼성전자 12009의 시장 전체 매수대금, 외국인·기타외국인 순매수대금, 관측 상태와 수집 시각이다. 이미 알려진 10월 값으로 대신하지 않는다.

자동 실행에 연결하려면 Claude가 기존 아침 워크플로와 분리된 연구 단계로 이 명령을 호출하고, 12009 정규화 디렉터리를 체크아웃 목록에 추가한다. 장 마감 단계는 날짜가 맞는 결과 스냅샷을 넘긴다. 현재는 로컬 최초 기록으로 검증했으며, 11-09 정답은 아직 발생하지 않았다.

## 자동 실행 연결안

Claude의 운영 워크플로 검토용 파일을 준비했다.

1. `integration/us_kr_hypothesis_preopen.job.proposed.yml`의 `hypothesis_shadow` job을 기존 `.github/workflows/us_kr_direction_preopen.yml`의 `jobs` 아래에 추가한다. 기존 Worker dispatch와 GitHub 스케줄을 사용한다. 홈 예측이 먼저 생성되어도 연구 후보가 빠져 있으면 마감 시각 전까지 재시도한다. 다섯 후보 모두 처음 기록이 있으면 실행을 건너뛴다.
2. `integration/us_kr_hypothesis_forward.steps.proposed.yml`의 두 step을 기존 `.github/workflows/us_kr_direction_forward.yml`의 `evaluate` job에서 기존 결과 커밋 뒤, 마지막 보고 앞에 추가한다. 기존 `outcome_prices.json`을 그대로 읽어 새 예측과 동일 거래일에서 채점한다. 기존 스냅샷에서 일부 종목이 결측이어도 사용 가능한 짝은 채점한다.
3. 아침 결과는 `data/forecasts/us_kr_hypothesis_shadow/`, 마감 성적은 `data/observations/us_kr_hypothesis_shadow/`에 따로 커밋한다. 삼성 12009 체크아웃에 실패하면 KOSPI와 삼성 가격 기준 후보를 계속 기록한다. 백업에 11월 파일이 들어오면 정확한 원천 거래일의 삼성 행으로만 수급 후보를 계산한다.

11월 9일 최초 기록 4개는 11월 8일 16:02 KST에 생성한 연구 기록이다. 마감 결과와 비교하려면 이 파일을 원래 시각·모델 ID 그대로 보존한다. 월요일 별도 보정 설정은 없다.
