## 홍콩 총수출 — 실데이터로 (`export_public_series.py`)

어제 "홍콩 통계처 API 403"이라고 적었던 건 **틀렸다** — 싱가포르 SingStat 때와 같은 실수(헤더 문제)였다. 다시 찔러보니 `censtatd.gov.hk`가 표 410-50001(대외상품무역)의 **월별 원계열 CSV를 키 없이, 쿼리스트링도 없이** 그대로 낸다:

```
https://www.censtatd.gov.hk/data/MDT_104_410-50001_VAL_TX_Raw_M_hkd_d.csv
```

`VAL_TX` = 총수출(자국산 수출 + 중계무역), HK$ 백만, 1952년부터. `trade_yoy`(수출입 합계 YoY, 합성 데모) → **`export_hk`**(총수출 금액, 십억 홍콩달러)로 교체. 2026-08 HK$667.9B. 개념이 바뀐다는 점(수출입 합계 YoY → 수출만 금액)을 카드 설명에 적었다 — 이스라엘 때와 같은 처리.

CSV에 연간 합계 행이 월별 행 사이에 섞여 있다(`MM` 칸이 빈 행) — `parse_hkg_csv`가 그 행을 건너뛴다.

## 베트남 수출 카드 제거 — `remove_unsourced_cards.py`

사용자 지시: "베트남은 안되면 빼자". 한 번 더 확인:
- GSO(통계총국) 도메인 `gso.gov.vn`이 **DNS부터 안 잡힌다**(주소가 바뀌었거나 죽음).
- 관세총국(`customs.gov.vn`)은 접속은 되는데 브라우저로 열면 **빈 화면**.
- FRED/OECD MEI(이스라엘에 썼던 경로)에는 베트남 상품수출 시리즈가 없다 — 검색해보면 "미국→베트남 수출"과 IMF 지역전망 성장률(전망치 섞임, "추정 금지" 원칙에 안 맞음)뿐.

무료 출처가 없다고 결론짓고 `export_yoy_vn`(합성 데모)을 아예 뺐다. 새 함수 `us_public_series.remove_indicator()`(indicators·categories·headlines에서 모두 제거, 멱등)와 재실행 가능한 스크립트 `remove_unsourced_cards.py`. 일일 워크플로에도 추가해서(멱등이라 안전) 나중에 다른 갱신기가 실수로 이 카드를 되살리는 일이 없게 했다.

## 태국 API — 찾았다, 시리즈까지 확정. 아직 미구현(태국은 팩에 나라 자체가 없음)

**태국은행(BOT) 레거시 통계 포털**(`app.bot.or.th/BTWS_STAT/statistics/BOTWEBSTAT.aspx`) — 키 없이 열린다. 처음 잡았던 `reportID=748`(EC_XT_009_S2, 품목별 수출)은 **2021-12에서 멈춘 사실상 폐기된 표**였는데, 검색으로 그 후속 표를 찾았다:

- **`reportID=979`(EC_XT_009_S3, "Total Value and Quantity of Exports Classified by Product Group (US\$)")** — 2026-08-31 갱신, 2026-07까지 있음. 90번 행 **"Total Exports (Customs basis)"**가 월별 통관 기준 총수출(백만 달러) — 한국·홍콩에 쓴 것과 같은 개념. 2026-07 = \$34,789.13M.
- **BOT API 포털**(`apiportal.bot.or.th`)은 이번에도 연결 자체가 안 됐다 — 그쪽은 확인 못 함. 대신 **레거시 포털을 그냥 스크레이프하면 키 없이 된다**: 최초 GET으로 세션 쿠키 + `__VIEWSTATE`/`__VIEWSTATEGENERATOR`/`__EVENTVALIDATION`을 받고, 기간을 넓혀 `drpFromMonth`/`drpFromYear`/`drpToMonth`/`drpToYear`/`btnSubmit`을 채운 POST를 한 번 더 보내면(순수 ASP.NET WebForms 포스트백, 로그인 아님) 표 전체가 HTML로 돌아온다. `<th>JUL 2026 </th>` 형식의 헤더 행과 `Total Exports (Customs basis)` 행의 `<td>` 들을 정규식으로 짝지으면 된다 — 오늘 curl로 실제 검증 완료(2016-01~2026-07, 127개월 값 전부 받음).
- **아직 안 붙인 이유**: 태국은 지금 팩에 나라 자체가 없다(어제 인도네시아·태국을 "새 나라로 만들자"고 했을 때 나온 것과 같은 문제) — 이 카드 하나 붙이자고 태국을 통째로 새로 만들 수는 없다. 태국을 나라로 만들 때 첫 실데이터 카드로 바로 쓸 수 있게 소스는 확정해 뒀다.

## 대만 — 여전히 보류 (이번엔 손 안 댐)

어제 찾은 대로: 관세청·통계청 사이트는 Cloudflare 봇 차단(키로 못 풂). 중앙은행 통계DB(`cpx.cbc.gov.tw`)는 완전 공개·키 없이 국제수지 기준 "상품-수입(수출)" 시리즈를 내는데 **분기 단위**라 다른 나라와 개념·주기가 다르다. 실제 쿼리 API(기간·항목 선택 후 값을 받는 엔드포인트)는 트리·범위 선택 API까지만 찾았고 데이터를 뽑는 엔드포인트는 아직 못 찾음. 사용자 확인 필요: 분기·국제수지 기준으로 타협할지.
