## Visible behavior

- National governor card separates 36 elections from14 non-election states. Its expandable50-state list gives each state's election/incumbent status, original source link and navigation into that state's election screen. Retirement/primary defeat keep secondary270toWin attribution; term-limit law is separately linked where reviewed. Missing/future/identity-conflicting context is not turned into a ballot claim.
- State governor matchup now receives the same reviewed state roster used for the other offices, even with no poll API observations. This fixes the previous governor call that omitted the roster/state arguments. It does not add or certify nominees in the UI.
- Candidate comparison shows current officials and this ballot, then the latest admitted support percentages with sources, campaign fundraising/cash and general-election independent support/opposition spending. Remaining parties/write-ins are expandable. A third-party/independent incumbent stays first rather than being folded with other nominees. Closed elections still hide active polling under the existing rules.
- Campaign cards show individual contributions, gross receipts, cash and disbursements, with candidate-original FEC link and bulk source. Report coverage end and actual collection date are different labels. Candidate contributions/loans, other loans, debts and transfers are expandable; transfers' double-count risk and the two-year file scope are preserved. Missing/conflicting data stays missing. Governor campaign fundraising explicitly remains unconnected to state disclosure and receives no federal money.
- Biographies show only the state-packet profile joined to the exact nominee. Each verified/self-reported field carries its original URL, review day and attribution. Age uses the current day and verified exact birthday. Unknown military service and ethnicity stay unknown. The first actual biographies depend on OH #636; this UI does not claim national biography coverage.
- Poll cards, including accumulated state observations, show `source_quality.review_sources` as checked original documents in addition to the provider-record URL and methodology URL. This exposes BGSU's available university release while keeping the inaccessible PDF pointer clearly labeled as the provider-recorded source. Major-only primary verification does not silently cover minor-candidate API percentages; those values receive a visible unchecked label. Source review dates and disclosure limitations are retained.
- Finance-service passes the existing index's source health/provenance into display contracts. Independent-spending links distinguish FEC disclosure search, the candidate-master source and the collection API; these are source lineage/search, not a fabricated individual filing URL. CA/NY/WA public disclosure routes are linked only for the corresponding state. Amounts and classification calculations are unchanged.
