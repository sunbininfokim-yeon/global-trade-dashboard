## 반복 수집 경로

`poll_primary_supplements.py`와 `config/usa_polls/primary_supplements_2026.json`을 주별/전국 기존 수집기에 연결했다. Quinnipiac 특정 검토 발표 PDF와 방법PDF의 지문을 매번 실제 공개 요청으로 재확인한다. 새 API 조사가 이 파동과 일치하면1회만 쓰고 원래 API ID를 영수증에 남긴다. 수치·표본·의뢰자가 충돌하면 임의값을 고르지 않고 수집을 실패시켜 기존 보드를 보존한다. PDF 오류/변경은 원문 관측/원래 날짜를 참고 전용으로 이월하고 우세 집계에서 뺀다. API 건수24와 원문 보완1 및 원래 API 응답 지문을 구분한다.

이 보완 목록은 **검토된 발표1건**에 한정된다. 새 Quinnipiac 발표 URL을 자동 탐색·자동 승인하는 기능은 없다. 새로운 파동은 기존 등록기관/원문 도메인·대진·기간·표본 검사를 통과하는 API 응답에서 자동 발견되며 원문 대조 등급은 자동 부여하지 않는다. PA4건은 raw metadata 지문으로 의뢰자/숫자/기간 변경 시 재검토를 요구한다. 기관 정확도 등급을 부여하지 않는다.
