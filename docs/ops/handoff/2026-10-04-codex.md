## KOSPI 종목 universe의 불완전 수집 성공 처리 제거 (T31)

branch: `codex/kospi-universe-failure` · base: `d96d90b8` (main)

10/1 [Market microstructure daily 실행 36796661306](https://github.com/sunbininfokim-yeon/global-trade-dashboard/actions/runs/36796661306)은
`--universe both --top 10 --pool 100`인데 `observed tickers=2`, `Universe n=2`를 저장하고 성공했다.
기존 코드가 빈 FDR KOSPI 목록을 하이닉스·삼성전자로 대체하고 시총 목록을 `observed`로 만들었다.
고변동 선별도 목록/가격 실패 때 시총 목록을 대체로 반환했다.

수정:

- 빈 목록, 조회 예외, 필수 열 누락, 유효 보통주 수 부족은 `KospiUniverseError`.
- 고변동 pool 전체의 가격 표본을 확보하지 못하면 순위를 발행하지 않고 오류를 반환.
  확보한 일부만으로 전체 pool의 변동성 상위를 단정하지 않는다.
- `both`의 시총·고변동 순위는 동일 목록을 한 번 조회해서 공유한다.
- CLI는 universe 오류 시 JSON·Markdown을 쓰기 전에 exit 1.
  기존 데이터와 그 관측일을 그대로 보존하며 명시적인 오류 로그와 Actions annotation을 남긴다.
- 명시적인 `--tickers`는 사용자가 지정한 custom 목록으로 계속 허용.

조회가 None/empty일 때 2종목 fallback 금지, 부족/잘못된 목록, 불완전 가격 pool,
정상 순위·1회 목록 조회, custom 목록, CLI 실패 시 기존 JSON·Markdown 보존을 검증한다.
실제 FDR 재수집과 공개 JSON 재생성은 실행하지 않았다.
