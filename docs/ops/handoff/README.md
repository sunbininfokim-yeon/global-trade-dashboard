# 인수인계 — 에이전트별 파일

**한 파일에 두 에이전트가 쓰지 않는다.** 이 디렉터리가 존재하는 이유가 그것이다.

```
docs/ops/handoff/YYYY-MM-DD-<agent>.md
```

예: `2026-08-07-claude.md`, `2026-08-07-cursor.md`

## 왜 나눴나

2026-08-07 에 이 저장소에서 실제로 일어난 일:

- 두 세션이 `HANDOFF_2026-08-07.md` 하나를 동시에 편집했다. 한쪽이 커밋하면서
  다른 쪽의 미커밋 내용이 사라졌다.
- 같은 날 `app.js` 에서 같은 일이 두 번 더 일어났다. 한쪽의 진행 중 수정이
  다른 쪽 커밋에 통째로 딸려 들어갔고, 그중 하나는 폐기하려던 코드였다.

규율로는 막지 못한다. 두 사람이 같은 파일에 쓰는 **구조 자체**를 없애야 한다.
파일이 다르면 충돌은 물리적으로 불가능하다.

`git` 은 같은 파일의 인접한 줄을 자동 병합해 주지 않고, 워크트리를 나눠도
파일이 하나면 결국 한 지점에서 만난다. `CODEOWNERS` 도 도움이 안 된다 —
PR 만 보고 로컬 쓰기는 못 막으며, 이 저장소에서는 모든 경로가 같은 계정이라
에이전트 구분 자체가 없다.

## 규칙

1. **자기 이름이 붙은 파일에만 쓴다.** 남의 파일은 읽기만 한다.
2. 이어붙이되 남의 줄은 고치지 않는다.
3. 날짜가 바뀌면 새 파일. 같은 날 이어서 작업하면 같은 파일에 섹션 추가.
4. 다른 에이전트에게 넘길 내용은 **자기 파일에 적고**, 상대가 읽어 가게 한다.

`TASKS.md` 는 아직 공유 파일이다. 각자 **자기 owner 행만** 고친다.
