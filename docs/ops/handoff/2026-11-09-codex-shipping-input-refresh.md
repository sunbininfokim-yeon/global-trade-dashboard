## 선대

2026-01-01 세계 등록 선대, 100 GT 이상, UNCTADstat `US.MerchantFleet`의
천 DWT 값을 사용했다. [UNCTAD 발간 달력](https://unctadstat.unctad.org/release-calendar)은
2026년 선종별 표 공개를 확인한다. 공식 CSV 직접 접속이 403을 반환해,
2026-09-05에 해당 표를 가져온 [Piri Reis 대학교 GOMD 공개 사본](https://gomd.pirireis.edu.tr/sources.php?category=maritime_economy)에서
동일한 출처 ID 및 원본 식별자의 World/WLD 2026년 행 5개를 조회했다.

| 항목 | 원본 천 DWT | 모델 DWT |
|---|---:|---:|
| 세계 합계 | 2,528,787.569 | 2,528,787,569 |
| 벌크선 | 1,067,305.758 | 1,067,305,758 |
| 유조선 | 683,403.818 | 683,403,818 |
| 컨테이너선 | 388,530.831 | 388,530,831 |
| 일반화물선 | 91,806.967 | 91,806,967 |
| 기타(합계에서 네 선종 차감) | 297,740.195 | 297,740,195 |

활성 입력은 `config/fleet_baseline.json`이며, 조회 URL·시리즈 코드·원본 식별자·단위를
파일 안에 보존했다. 2025년 보고서 기준은 비교용으로 남겼다. LNG·LPG 합계의 별도
2025년 출처와 LNG 전용 세계 DWT 미확인 상태는 유지한다.

기존 관측과 Comtrade 입력을 유지한 검증 빌드에서 호르무즈 80%·28일 가정의
추가 필요 DWT는 74,167,773으로 동일했다. 세계 유조선 선대 대비 비율은
11.072428% → 10.852701%로 바뀌었다. 수에즈 100%·28일은 추가 DWT 동일,
관련 선대 대비 0.260913% → 0.252438%였다. 비교는 분모 업데이트이며 예측 정확도 평가가 아니다.

## 요청 한도

[11월 7일 KST 실패](https://github.com/sunbininfokim-yeon/global-trade-dashboard/actions/runs/42311969172)는
ArcGIS가 60초를 안내했으나 기존 코드가 1·2초 후 재요청해 9개 해협이 모두 실패했다.
HTTP 429의 Retry-After(초/HTTP 날짜)와 ArcGIS JSON 429의 안내 시간을 지원한다.
안내가 없으면 60초, 클라이언트당 누적 대기 한도 180초, 페이지당 최대 3회다.
서버가 요구한 시간을 줄여 보내지 않으며, 한도 소진 시 같은 수집기의 나머지 호출을 중단한다.
#737의 불완전 게시 차단을 유지한다.

## Comtrade 2025 확인

무료 미리보기에서 중국의 브라질산 대두 수입(HS1201)은 2025년 해상 코드 2100을
요청했지만 응답은 전체 운송 코드 0만 반환했다. 호주의 대중국 철광석 수출(HS260111)과
한국의 사우디산 원유 수입(HS2709) 표본은 HTTP 429로 확인되지 않았다.
이는 2025년 해상 자료의 부재를 증명하지 않는다. 구독 키가 활성화된 상세 쿼리에서
같은 품목·방향·운송 범위와 각 항로의 커버리지를 비교하기 전까지 21개 항로의 2024년
입력을 보존한다. 기존 실행은 `COMTRADE_SUBSCRIPTION_KEY` 미사용으로 갱신을 건너뛰었다.

## 검증과 게시 경계

- Python 185개, Node UI 17개, 스키마 4종과 golden 계약 통과.
- 임시 산출물에서 봉쇄 1,140건·환경 567건, 회계/단조성 오류 0건.
- 수정 수집기로 PortWatch 9곳 각각 730개 행 실제 조회. 최신 관측일 2026-11-01,
  후퇴 0건. 429 재현은 회귀 테스트로 검증했다.
- 오프라인 계산 검증 산출물은 임시 폴더에만 기록했다. UI, 워크플로, 공개 JSON은
  변경하지 않았다. 병합 후 기존 자동 실행의 성공 시점에 신규 기준이 재생성된다.
