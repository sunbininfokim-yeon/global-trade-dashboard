## 구현

- 메뉴 2개(우라늄 두 계열) 추가, 기존 망간 메뉴는 `망간광·정광`으로 명확화.
- 연간 API 요청과 결과 HS를 고정. 신규 계열은 다른 HS/방향 행을 거부. 나미비아·니제르 연간 조회/국가 코드 보완. 조회국/미러 범위이지 세계 전수 자료가 아니다.
- 국가 카드 연간/월별 전환과 세 계열 매핑 추가. 다른 화합물·부모 호·페로망간으로 채우지 않는다.
- 상대국별 월별 part가 있으면 기존 금액/중량·비중/순위 렌더러에 연결. 총량 파일이 없어도 정확한 HS의 양자 part를 찾는다. 없으면 미확보 안내만 표시하며 총량을 상대국에 배분하지 않는다.
- 우라늄 기존 HS 매칭의 `2844` 포괄 매칭 제거. 우라늄/망간 제품은 더 넓은 상위 호로 추정하지 않는다.
- 자동화 `PRIORITY_COMMODITIES`에 망간·우라늄광 추가. 천연우라늄은 종전부터 등록. 기존 27국·3배치, 호출 상한, 인증·일정·배포 경로는 변경하지 않는다. 기존 수집기가 다음 실행에서 새 HS를 요청하고, 관측 월 확보 후 기존 양자 대기열/수출통제 재대조를 따른다.
- 브라질 NCM 수집기에 2602 추가. 구 보드에 없는 계열이 `supplemental_commodities`로 이동해도 UI는 명시적 HS bridge만 받아 연결한다.
- 해당 품목은 `observedOnly`: 헤더 모의 날짜와 이미 대기 중인 모의 콜백 차단. 보크사이트도 종전 보호 유지. 다른 품목의 기존 동작은 변경하지 않는다.
- 새 계열 실시간 월별 집계: 공식 0 보존, 다른 HS/통계 세부범위 제외, 충돌 총계는 큰 값을 고르지 않고 보류. 자료 미확보를 0/미신고로 단정하지 않는다.
- 모바일 CSS는 보크사이트/망간/우라늄 해당 화면만 확장.
