대상: 개장 전 방향 모델 `us_kr_preopen_20261022_v1` (#868)과 그 입력 세 축.
사용자 가설: ① 외국인 콜·풋 수급 → 유가증권 방향, ② 미국 주가 → 한국 파급, ③ 둘의 복합 전망.
사용자 관점(중요): 옵션은 **움직임 폭이 아주 작더라도 52% 같은 꾸준한 방향 우위**가 있는지가 핵심이다.

Claude 의 독립 재구성 검증 결과를 넘긴다. 스크립트는 저장소 밖에 있었다. 재현할 때는 아래 정의를 따른다.

## 1. 독립 재구성 (방법)

- 원천: Naver 일봉(KOSPI·005930·000660, 2018~), Yahoo 일봉(QQQ·SPY·^VIX·SMH·MU·NVDA·AMD),
  공개 보드 `detailed_15007` 콜·풋(2019-01-02~2026-11-06, 1,926일).
- 특징: v1 의 18개와 같은 정의. 옵션 비율 = 외국인 `net_krw` / 시장 `buy_krw`.
  `rank60` 은 직전 60일 중 순위, `mean5` 는 5일 평균.
  미국 = 대상일 이전 마지막 미국 세션 수익률(VIX 는 수준 로그도 포함).
- 라벨: 시가 > 전일 종가, 종가 > 전일 종가. 보합은 각 목표에서 제외.
- 재현 확인: 11/9 공개값을 같은 방식으로 다시 계산했다.
  KOSPI 시작 94→94, 마감 78→77 / 삼성 72→71, 66→63 / 하이닉스 90→86, 62→56.
- 평가: 2021Q1~2026Q4, 분기마다 재학습했다. v1 과 같은 구조로, 기저 로지스틱(C=1)을
  학습하고 직전 6개월로 단조 sigmoid 보정을 한 뒤 다음 분기를 예측했다.
  종목·목표마다 약 890~960일이다.

## 4. 작은 우위 검증 (사용자 가설: 52% 카지노)

규칙: 신호가 자기 직전 60일 중앙값보다 크면 +1, 작으면 −1. 단위는 하루 bp, Newey-West t(5 lags).
미국 영향을 뺀 값(`_res`)은 연 단위로 확장하며 학습한 OLS 의 표본 밖 잔차를 썼다.

| 신호 → 결과 | 평균 | t | 적중 |
|---|---|---|---|
| K200 콜 순매수 → KOSPI 다음 날 시가→종가 | **+4.9bp** | **1.94** | 52.1% |
| K200 콜 순매수 → 삼성 다음 날 시가→종가 | +6.8bp | 1.88 | 49.7% |
| K200 풋, 콜−풋 → 모든 결과 | — | \|t\| < 1.4 | — |
| 삼성 주식 외국인 순매수(12009) → 다음 날 시가 갭 | +12.7bp | 3.10 | 47.7% |
| 같은 신호 → 장중(시가→종가) | −10.4bp | −2.63 | 44.5% |
| 하닉 주식 외국인 순매수 → 다음 날 시가 갭 | +14.3bp | 2.56 | 47.0% |
| 같은 신호, 미국 영향 제거 후 갭 (5일 평균) | +7.5~8.3bp | 1.96~2.19 | 52% |

- 이 표는 약 65개 시험 중 일부다. 어느 것도 다중 비교를 통과하지 못한다.
- 주식 외국인 순매수는 다음 날 **갭을 띄우고 장중에 되돌린다.** 종가 기준으로는 0 이고,
  주식 비용(매도세 0.15~0.18%)보다 작다.
- K200 콜 → 다음 날 장중이 유일한 후보다. 선물 왕복 비용(약 2bp)을 빼도 남을 수 있는 크기다.

## 6. 요청 — 입력별 전망 출력 (사용자 화면 요청, 2026-11-08)

사용자가 요청한 화면 배치는 다음과 같다. UI 는 Claude 가 구현한다.

| 화면 | 보여줄 것 | 필요한 출력 |
|---|---|---|
| 홈 | **최종 통합 전망** (우리가 고려하는 모든 힘) | 현행 `cards` 그대로 (v2 교체 시 그 모델) |
| 시장 미시구조 › 파생 수급 | **옵션 수급에 따른 힘** | 옵션 묶음 전망 |
| 가격대별 체결 | **외국인이 거래하면 나오는 값** | 주식 외국인 순매수 묶음 전망 |
| 해외-국내 선행 | **미국 주가에 따른 예측값** | 미국 묶음 전망 |

`US_KR_INDIVIDUAL_COMBINED_UI_CONTRACT.md` 의 원칙(관측 / 입력별 / 통합 구분, 없는 확률 금지)을 따른다.
공개 JSON `us_kr_direction_v1.json` 에 다음을 **추가 필드**로 넣어 달라. 기존 필드는 바꾸지 않는다.

```
factors: {
  options:            { label_ko, model_id, inputs:[...], cards:[{ticker, scores:{opening_up, closing_up}}],
                        validation:{period, n, hit, base_rate, brier, brier_base, skill:"none|weak|yes"} },
  foreign_stock_flow: { ...같은 구조, 삼성·하닉만 (KOSPI 는 없으면 생략) },
  us_price:           { ...같은 구조 }
}
```

- 각 묶음은 고정 모델로 만들고 매일 추론만 한다(재학습하지 않는다).
- 국내 가격 통제를 넣었다면 이름에 그것을 밝힌다(계약 문서 원칙).
- **`validation.skill` 은 필수다.** 옵션·외국인 수급 묶음은 위 결과대로라면 `none` 이다.
  - UI 는 `none` 인 묶음의 확률을 크게 보여주지 않는다.
  - 대신 관측값(오늘 콜·풋 순매수 순위, 외국인 순매수)과 "과거 검증상 방향 정보 없음"을 표시한다.
  - `call_intraday_v1` 추적 현황(n, 평균 bp, t)은 Claude 가 원장에서 직접 읽는다.
- 미국 묶음은 VIX 포함 여부를 이름에 반영한다.
