# 같은 조사 파동의 초기 양자/다자 문항 분리

- Codex, 공용 기반 `codex/poll-question-scope-20261021`. 주별 packet 없는 공용 수집기 변경이며 MS의 실제 자료는 후속 독립 PR로 분리한다.
- 동일 기관·기간·모집단의 다른 초기 문항이 서로 다른 값을 갖는 경우, exact API ID/fingerprint·원문 레코드 fingerprint·명시적 양자/다자 문항·같은 wave_id·실제 원문 문서 URL/지문·검토일을 전부 묶은 유한 승인을 허용한다. 양자 후보는 다자 후보의 엄격한 부분집합이어야 한다.
- 값/표본/의뢰자/ID 변경은 같은 승인으로 통과하지 않는다. 미래 검토·다른 문서·정보 제공 후 문항·모르는 후보도 거부한다. 기존 RCV 문항 계약은 그대로다.
- transport에서 문항을 분리해도 normalize의 전체 후보 비교와 signal 적격은 완화하지 않는다. 기존 required_candidates 검증을 유지한다. 이 목록이 주요 후보만 포함할 수도 있으므로 실제 제3후보 누락은 해당 주의 명시적 제외 입력으로 보류해야 한다. 최신 7/14일 신호나2개 독립 조사로 만들지 않는다.
- 집중32개 통과: 새 계약6·기존 충돌 복구·AK9문항 계약. 문서 장애는 기존 값/날짜를 참고로 보존하고 실제 미검토 충돌은 격리한다.
- UI·workflow·전국 생성 JSON·주별 입력 수정 없음. 병합·배포·운영 workflow dispatch 없음.

공용 수집기 후속 작업은 기존 Codex 수집 복구 담당 범위이며 이 전용 문서에 기록한다. 중앙 TASKS에 별도 선두 행을 추가하지 않는다. #649/#656과 시험 통합에서 같은 선두 삽입 충돌을 확인해 이번 PR의 TASKS 변경을 제거했다. 주별 변경은 여전히 독립 PR에만 둔다.
