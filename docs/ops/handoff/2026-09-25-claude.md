## FOMC 의사록 (claude/fomc-minutes)

- `macro_monitor/fomc_collect/minutes.py` + `build_fomc_minutes.py` → `config/fomc_minutes_v1.json`(13개 회의).
  의사록 URL은 `fomcminutes<YYYYMMDD>.htm`; 아직 안 나온 회의는 404를 조용히 건너뛰고, 파싱 실패는 저장하지 않고 보고만 한다.
- 공개일은 연준 캘린더 페이지의 "(Released Month DD, YYYY)"를 그대로 읽는다. 결정일+21일이 보통이지만
  2025-12-10→12-30처럼 아닌 경우가 있어 계산하지 않는다. 미공개 회의의 공개일은 `pending.expected_release`(결정일+21일)로
  **예상**임을 `basis`와 화면 문구에 밝혀 둔다.
- 표결 명단 출처 우선순위: 결정문 명시 > 의사록(찬성·반대 수와 반대자 성이 결정문 표결과 모두 맞을 때만) > 로스터 추정(`roster_inferred`).
  9월 16일 회의는 의사록이 10/7쯤 나오면 자동으로 `minutes` 출처로 올라간다.
- 의사록 문장은 원문 그대로, 첫머리의 참가자 수 표현(Almost all/Many/Several/Some/A few)으로만 묶는다. 점수·매파/비둘기 판정 없음.
  "Participants/Members ..."로 시작하는 수량 표현 없는 문장은 별도 그룹.
- 파서 함정: 소제목이 본문과 같은 `<p>` 안에서 `<strong>…</strong><br>`로 붙어 있고, 닫는 따옴표 뒤에서 문장이 끊긴다
  (`…price stability." Almost all members…`), 표결 명단이 세미콜론+직함 형식/반대자 복수 절 형식으로 회의마다 다르다. 테스트 15개.
- 워크플로 `fomc_collect_refresh.yml`: 문구 → SEP → **의사록** → 조립 순.

## T-bill 발행량 → QRA 만기별 탭 (claude/tbill-issuance)

- 소스(무키): FiscalData `auctions_query`(security_type=Bill; `offering_amt`=공시된 경매 규모, `total_accepted`는 경매 후에만 채워짐)
  + `mspd_table_1`(시장성 T-bill 발행잔액, 월말). `macro_monitor/qra/tbill.py`, `refresh_tbill_in_pack.py`
  → `public/data/tbill_issuance_v1.json` + 팩 `qra_issuance.components`(kind:"bill" 행)/`qra_issuance.tbill`/TGA 미러.
- 창(window)은 엔진 파일의 TBAC 분기 라벨(`AUGUST 2026-OCTOBER 2026 QUARTER`)에서 읽는다. 못 읽으면 추정하지 않고 실패.
- **분기 미완을 숨기지 않는다.** 경매는 약 1주 전에 공시되므로 진행 중인 분기는 "공시분"만 합산되고, 화면·노트에
  "8/1~9/29 공시분 · 분기 미완"과 결과 확정 회수를 적는다. 분기가 끝나고 전 경매에 결과가 붙어야 `complete: true`.
- **총 경매 규모이지 순발행이 아니다.** 대부분 만기 도래분 차환이라 쿠폰(분기 $954B) 대비 $4,574B(54회)로 4배 이상이다.
  한 축에 그리면 쿠폰 막대가 사라져서 UI는 T-bill을 별도 블록(자체 척도 + 자체 노트)으로 분리했다.
  참고 문장으로 발행잔액(8/31 $7,248B)과 전월말 대비 변화만 붙인다(MSPD 잔액 차이이지 순발행 추정이 아님).
- `refresh_qra_quarters_in_pack.py`는 쿠폰으로 components를 리셋한 뒤 저장된 T-bill 파일을 다시 붙인다(네트워크 없음).
  저장 파일이 다른 분기 것이면 분기를 섞지 않고 T-bill 행을 뺀다. `qra_refresh.yml`은 새 분기 시작 시 `refresh_tbill_in_pack.py`를 한 번 더 돌린다.
- 워크플로 `tbill_issuance_refresh.yml`: 금 21:30 UTC(토 06:30 KST) 주 1회 + 수동. `pip install pytest beautifulsoup4 pypdf`
  (`qra/__init__`이 파서를 import해서 pytest만으로는 수집 실패 — 깨끗한 venv에서 확인).
- 남은 것: `build_macro_monitor.py` 전체 재빌드는 T-bill 행을 붙이지 않는다(워크플로는 전체 재빌드를 안 씀).
  전체 재빌드를 돌렸다면 `refresh_tbill_in_pack.py`를 이어서 실행할 것. TGA 쪽 `maturity_components`는 데이터만 맞춰 두었고 UI에서 렌더하지 않는다.
- 새벽 5시 예약 실행(`qra-tbill-issuance`)은 Bash 한 번 호출 뒤 멈춰서(권한 프롬프트로 추정) 아무것도 만들지 못했다. 직접 진행함.
