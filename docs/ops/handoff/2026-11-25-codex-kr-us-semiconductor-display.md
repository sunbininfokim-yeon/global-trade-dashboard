# 한국 반도체 → 미국 개장 전망 화면 표기안

시장 미시구조의 **해외-국내 선행** 탭(`uskr`)에서 미국→한국 전망 카드 바로 아래에 **한국 반도체 → 미국 개장 전망**을 배치한다. 먼저 마이크론(MU), 다음에 샌디스크(SNDK)를 표시한다. 섹션 설명은 **「오늘 밤 미국 시가가 전 거래일 종가보다 오를지, 내릴지 봅니다.」**로 한다. 조회하는 날짜가 과거면 「오늘 밤」을 빼고 대상 미국 거래일을 표시한다.

| 항목 | 마이크론 · MU | 샌디스크 · SNDK |
|---|---|---|
| 입력 설명 | SK하이닉스의 코스피 대비 움직임 | 삼성전자·SK하이닉스의 코스피 대비 움직임 |
| 공통 입력 설명 | 미국 전 거래일 가격, 한국 당일 코스피 | 미국 전 거래일 가격, 한국 당일 코스피 |
| 과거 검증 문구 | 2016~2026년 2,531거래일 · 상승 출발일 83% 포착 · 하락 출발일 44% 포착 | 2026년 211거래일 · 연구 중 |
| 모델 준비 상태 | 하이닉스 후보 계수 학습 완료. 운영 출력용 연결 필요 | 두 종목 모델의 과거 비교 완료. 동결 모델과 운영 출력 필요 |

마이크론 수치는 하이닉스 단독 후보의 미국 시가 방향 검증 결과다. 검증 문구는 카드에 연결한 모델 버전의 결과를 쓴다. 샌디스크는 2026-01-02~2026-11-24 미국장 211일에서 Brier가 0.2158에서 0.1849로 개선됐다. 이 값은 개장 확률이 생기기 전에도 검증 정보로 표시할 수 있다.

## 카드 예시

> **마이크론 · MU**
>
> **상승 출발 63%　│　하락 출발 37%**
>
> 11월 23일 미국장 · 11월 23일 16:00 KST 기준 · 과거 재현
>
> SK하이닉스의 코스피 대비 움직임 반영
>
> **실제 시가 +16.18%** · 전 거래일 종가 대비
>
> 과거 검증 · 상승 출발일 83% 포착 · 하락 출발일 44% 포착

위 마이크론 수치는 11월 20일까지 학습한 후보로 계산한 11월 23일 과거 재현이다. 상승·하락 확률을 같은 글자 크기와 같은 폭으로 배치한다. 화면에서는 상승 확률을 정수 %로 반올림하고 하락은 100에서 그 값을 빼서 표시한다. 실제 방향과 채점은 반올림 전 값으로 판정한다. 정확히 50%인 예측은 방향 보류로 표시한다.

접이식 **종목별 검증**에는 엔비디아·SOX·AMD·브로드컴·TSMC ADR을 **「한국 종목을 추가한 효과 미확인」**, 웨스턴디지털을 **「개선 가능성 · 표본 축적 중」**, 창신메모리를 **「상하이 상장 · 이력 수집 중」**으로 표시한다.

## 발행과 개장 후 표시

각 카드의 키는 **미국 거래일(뉴욕 현지 날짜) + 종목 + 모델 ID**다. 발행은 한국장 마감과 당일 종가 확인 후, 해당 미국 정규장 개장 전이다. 양국 거래일과 미국 서머타임은 거래소 일정으로 판정한다. 카드에는 거래일을 미국 현지 날짜로, 발행 시각을 KST로 표시한다. 자료가 먼저 확인된 종목부터 독립적으로 표시할 수 있다.

| 상태 | 카드 표시 |
|---|---|
| 실제 개장 전 발행 완료 | 상승·하락 확률, 대상 미국 거래일, 발행 시각, 입력 요약 |
| 모델 또는 당일 입력 미도착 | 「전망 준비 중」 또는 「입력 미도착」. 사유와 기준일을 함께 표시 |
| 미국 휴장 또는 한국 당일 거래 없음 | 「미국 휴장」 또는 「한국장 휴장 · 오늘 전망 없음」 |
| 미국 개장 후 시가 미확정 | 기존 확률과 「실제 시가 확인 중」 |
| 실제 시가 확정 | 발행 확률과 함께 **전 거래일 종가 대비 실제 시가 등락률** 표시. 정확히 0이면 「보합」 |
| 과거 재현 | 「과거 재현」 배지를 붙인 이력 카드. 실시간 발행 집계와 별도 |

최초 발행 확률은 보존하고 미국 정규장 시가가 확인되면 실제 등락률을 별도 결과로 연결한다. 미국 전일 종가와 시가는 같은 가격 기준을 쓴다. 새 미국 거래일의 전망이 비어 있으면 이전 값은 날짜가 표시된 이력에서 볼 수 있다.

## 연결에 필요한 데이터

아래 키는 화면 연결 제안이다. #1121의 원본은 종목별 `results.<ticker>.opening.up/down`과 `as_of`, `target_date`를 제공한다. 발행기는 실제 발행에서 `as_of`를 `issued_at`으로 옮기고, 과거 재현에서는 당시 추론 기준 시각을 `as_of`에 유지한다. 카드의 실제값은 거래일·종목으로 조인하고 성적은 모델 ID별로 집계한다.

| 필드 | 의미 |
|---|---|
| `ticker`, `model_id`, `target_date` | 대문자 미국 티커, 고정 모델 버전, 대상 미국 거래일 |
| `status`, `issued_at`, `as_of` | 발행·재현·결측·휴장 상태와 시간대 포함 시각. 결측이나 재현에서 실제 발행 시각은 null |
| `probability_up`, `probability_down` | 개장 방향 확률 0~1. 값이 없으면 둘 다 null |
| `actual_open_return` | 정규장 시가 ÷ 전 미국 거래일 종가 − 1. 확인 전에는 null |
| `validation` | 해당 모델의 기간·표본 수·상승 및 하락 재현율. 보합을 제외한 방향별 실측일이 분모 |

UI와 정기 발행은 Claude가 연결한다. 엔진과 모델 근거는 [연구 PR #1121](https://github.com/sunbininfokim-yeon/global-trade-dashboard/pull/1121)에 있다.
