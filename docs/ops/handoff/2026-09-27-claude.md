- 월간 지표가 진행 중인 달(예: CCSI 9월)이면 `asof` 는 월말이 아니라 **실행일**(미래 날짜 방지 — 라이브 카드 기준일 수정과 같은 원칙).
- **`bok_base_rate` 는 일부러 안 건드렸다.** 라이브 오버레이가 매 실행 BOK 100대 지표로 최신값을 `live_latest` 로 덮어써서, 두 쓰기가 카드를 번갈아 바꾼다. `claude/live-asof-fix` 머지 후 오버레이에 "ECOS 로 채운 카드는 건드리지 않음" 가드를 넣으면 기준금리 이력도 실측으로 바꿀 수 있다.
- **캐시**: `config/kr_ecos_series_v1.json`(2014년 이후, 키 없음). 키가 있으면(로컬, 또는 GitHub 시크릿 `ECOS_API_KEY` 를 넣으면 Actions) 실시간으로 읽고 캐시를 갱신, 없으면 캐시를 읽는다 → **시크릿을 넣기 전에는 Actions 가 새 달로 못 넘어간다.** 로컬 실행:
  `cd "New for anti/scripts/macro_monitor" && set -a && . ~/.config/ecos.env && set +a && python3 wire_kr_public_series.py`
- 워크플로 이름이 "Refresh public series (USA/JPN/KOR)"로 바뀌어 `deploy.yml` 의 `workflow_run` 목록도 같이 고쳤다(둘이 같은 커밋으로 머지돼야 배포 트리거가 유지된다).
- 죽은 `kosis_probe.yml`(기본 브랜치에 없어 실행 못 함)은 지웠다. `kosis.py`(클라이언트)·`kosis_probe.py` 는 남겨 뒀다.
