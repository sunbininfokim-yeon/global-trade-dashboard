## 구현

- 원자재 → 금속·광물 → **보크사이트 (알루미늄광)**, 독립 경로 `/bauxite`.
- 분류·별칭·연간 Comtrade 설정·상품 프로필·월별 id를 `bauxite` / HS2606으로 연결.
- 알루미나(HS281820)·알루미늄 금속(HS7601)을 포함하지 않는 범위를 명시. 알루미늄 메뉴/조회는 기존 HS7601 유지.
- 연간 지도 요청은 보크사이트에 한해 기니324·자메이카388을 포함한 명시적 국가 목록 사용. 기존 Worker 기본 universe나 다른 품목 요청 범위는 바꾸지 않는다. 기존 on-demand 조회/캐시를 사용하며 새 Worker warm-up 항목은 추가하지 않았다.
- 기니가 GeoJSON 로딩 전에도 GIN으로 식별되도록 app.js fallback 한 항목만 추가했다. 국가 좌표를 새로 추측해 넣지 않고 기존 지도 registry를 사용한다.
- 연간 국가 카드에서 기존 월별 수출·수입 계열로 전환. 관측 월·단위·원천/보류 표시는 기존 계약 유지. 가격/생산량/세계 총량/최대 수출국/뉴스를 임의 생성하지 않는다.
- 월별 목적국/공급국 자료가 없으면 미확보 안내. 총량을 배분하거나 연간 상대국 비중을 월별 비중으로 대체하지 않는다. 지도 노선은 연간임을 계속 표시한다.
- 모바일 390px에서 기존 32vw 패널이 기간 버튼을 잘라내는 것을 시각적으로 확인해 **보크사이트가 활성일 때만** 위 카드/아래 지도 배치로 보정했다. 다른 상품 CSS는 유지.
- data.js·app.js·trade-monthly.js·style.css 캐시 버전 갱신. 소유권 예외는 정확한 브랜치와 UI 5파일만 허용하며 app.js 변경은 위 한 항목뿐이다.

## 운영 경계

Worker·workflow·Secrets·수집 대상/원천 데이터는 수정하지 않았다. 대량 수집/작업 dispatch·병합·배포는 실행하지 않는다. 기존 월별 파이프라인은 이미 HS2606을 포함한다. 실제 최신 월·상대국별 확보 여부는 수집 결과에 따라 달라진다.
