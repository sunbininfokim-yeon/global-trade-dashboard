# 유럽 주요 10개국 정치 화면 점검 (2026-11-24, Claude)

대상: 영국, 프랑스, 독일, 스페인, 이탈리아, 폴란드, 포르투갈, 헝가리, 그리스, 스위스.
점검한 항목은 세 가지입니다.
- **정당 성향:** 계파 분석이 아니라 좌우 위치만 봅니다.
- **국가지도자실:** 대통령실 또는 총리실입니다. 군주는 제외합니다.
- **행정부:** 내각과 부처입니다.

기준 자료는 main의 `public/data/personnel/<ISO3>.json`, `elections_board_v1.json`, `election_records/<ISO3>.json`입니다.

## 0. 점검 중 바로 고친 것
- **스페인:** 2026-10-05 의회가 해산돼 **11-29 조기 총선**이 확정돼 있었습니다(Real Decreto 806/2026). 그런데 선거 블록은 '2027년 무렵'으로 표시하고 있었습니다. 하원과 상원의 다음 선거를 2026-11-29로 고쳤습니다. 출처는 BOCG-15-D-603입니다.
- 이처럼 인사 명단에는 들어온 일정이 선거 일정판(보드)에 빠지는 경우가 또 있을 수 있습니다. 10개국 전체에서 이 차이를 자동으로 잡는 검사가 필요합니다(4절).

**문제의 핵심:** 정당 성향이 표준 칸이 아니라 나라마다 다른 서술문(`orientation.poles`)으로만 들어 있습니다. 그래서 정당 색깔을 일정하게 표시할 수 없습니다. 몇 개 있는 분류도 틀리거나 비어 있습니다.

### 제안: 정당 위치 표준 칸
척도는 7단계 하나에 민족주의 표시를 따로 붙입니다.

| 위치 | 화면 색 | 근거 (EU 국가) |
|---|---|---|
| 극좌 | 진홍 | 유럽의회 The Left 그룹 중 반체제 성향 |
| 좌 | 빨강 | The Left, 녹색당(Greens/EFA) |
| 중도좌 | 분홍 | S&D |
| 중도 | 노랑 | Renew |
| 중도우 | 하늘 | EPP |
| 우 | 파랑 | ECR |
| 극우 | 남색 | Patriots for Europe, ESN |

- **민족주의 표시:** `regional`(지역·분리주의: ERC·Junts·Bildu·PNV·BNG·SNP·Plaid 등) 또는 `national`(국가 민족주의 강조)을 위치와 별도로 붙입니다.
- **근거:** 정당이 소속된 유럽의회 정치그룹(EP 공식 명단)을 1순위 근거로 씁니다. 이것은 인용할 수 있는 객관 자료입니다.
- **스위스와 유럽의회 의석이 없는 정당:** 국내 선관위·연방통계청의 정당군 분류를 쓰고, 없으면 `basis_ko`에 근거를 적습니다.
- **판단을 쓰지 않음:** '포퓰리스트'나 '권위주의' 같은 평가어는 쓰지 않습니다.

```jsonc
// config/party_positions_2026.json (국가별 묶음)
{"ESP": [{"party": "PSOE", "name_ko": "스페인 사회노동당", "position": "centre_left", "nationalist": null,
          "basis": "ep_group", "ep_group": "S&D", "source": "https://www.europarl.europa.eu/meps/en/search/table"},
         {"party": "ERC", "position": "left", "nationalist": "regional", ...}]}
```

**화면:** '정당' 블록의 서술문 위에 정당 칩(색 + 위치)을 한 줄로 보여 줍니다. 선거 블록의 의석표와 연정 줄에도 같은 색을 씁니다.
