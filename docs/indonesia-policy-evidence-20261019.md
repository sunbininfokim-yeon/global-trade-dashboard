# 인도네시아 규정 공백·관계·사업 검토범위·선택 조문

2026-10-19. 병합된 PR #613 이후 최신 main에서 만든 후속 작업이다. 기존 문서 64건을 보존하면서 운영 DB에 새 근거 구조를 적용했다. 검색 API 연결은 후속 PR의 코드이며 사이트 배포는 Claude가 담당한다.

## 구현 범위

- `policy_idn.coverage_items`: 기존 검토 후보 99개 + RKAB 기본령 1개 + 종전 대통령령 참고 2개, 총 102개. 법령 본문 저장 수가 102개로 늘었다는 뜻이 아니다. 상태를 저장값으로 추정하지 않고 실제 최신 버전과 출처 확인을 결합해 `official_text`, `partial_text`, `metadata_only`, `missing`으로 계산한다.
- `policy_idn.review_evidence`: 원문 인용·원문 버전 해시·공식 본문 URL·조문 위치·한국어 검토 설명을 함께 저장한다. 관계 5건, 사업 검토범위 7건, 선택 조문 12건, 총 24건이다. 같은 ID는 불변이며 동일 입력 재실행은 추가하지 않는다.
- `policy_idn.passage_embeddings`: 위 선택 조문 12개의 `gemini-embedding-001`/1536차원/`passage-v1` 벡터. 기존 문서개요 64개와 별도이며 모든 조문을 임베딩한 것이 아니다.

실제 법령은 64건·69버전·129출처 확인으로 유지된다. 102개 목록 중 본문 문서가 있는 것은 64개이고 38개는 문서 행이 없다. 참고용 종전 법령도 38개에 포함되어 전부 현재 반드시 수집해야 하는 규정은 아니다. 현행 법적 효력은 `unverified`이며, 적용성은 `review_relevance`다.

## 핵심 공백

검토자가 지정한 우선순위 1은 20개다. 이 중 원문 8개, 메타데이터만 4개, 미저장 8개다. 우선순위 목록은 전국 규정이나 모든 지방 허가의 전수 목록이 아니다. 0건이나 공백은 규제 없음이 아니다. 이번에는 원문을 새로 내려받지 않았고 기존 원문과 실패 기록을 구조화했다.

품목별 핵심 범주:
- 석탄·니켈·광물: 광업 기본법/개정, 광업 시행령/개정, RKAB 기본령·개정, 로열티 부속서, 수출 정책, 환경·산림·복구.
- 팜유·바이오연료: 기금 운용·재식재 지원, ISPO 기본령과 농장/하류/바이오에너지 시행규정, 무역·환경 조건.
- 지역: 현재 확보된 동칼리만탄·중앙술라웨시 등의 원문을 별도 검토 대상으로 유지한다. 지역별 자료 부재를 중앙 규정으로 대체하지 않는다.

`discovery_url`은 검토 후보를 발견한 근거다. 종전 대통령령 61/2015·44/2020의 경우 후속 대통령령 본문 URL이며, 그 종전 법령 PDF를 확보했다는 뜻이 아니다.

## 검증된 관계와 효력 경계

| 출발 규정 | 관계 대상 | 근거 |
|---|---|---|
| Perpres49/2021 | Perpres10/2021 일부 개정 | Pasal I |
| PP25/2024 | PP96/2021 일부 개정 | Pasal I |
| PP39/2025 | PP96/2021 추가 일부 개정 | Pasal I |
| Perpres132/2024 | 종전 Perpres61/2015 및 개정 체계 폐지 문구 | Pasal33 |
| Perpres16/2025 | 종전 Perpres44/2020 폐지 문구 | Pasal28 |

이는 **저장된 원문에서 관계 문구를 확인한 결과**다. 후속 개정의 부재, 오늘의 최종 효력, 경과조치, 개별 사업 적용성을 확정하지 않는다. 기본령의 조문을 자동으로 덮어써 통합 현행법처럼 제공하지 않는다. 미저장 대상은 `target_stored=false`로 표시하며 문서 행을 가짜로 만들지 않는다.

새 근거 저장은 공식 본문 버전만 허용한다. 인용문이 해당 본문에 실제 존재하고 URL이 그 버전의 본문 출처와 같아야 한다. 메타데이터·다른 URL·식별되지 않은 인용·오래된 버전은 거부한다. 새 관측 본문이 생기면 구버전 근거와 벡터는 활성 결과에서 제외하고 `stale_evidence_count`로 알린다. 원문 정정이 법적 개정이라는 뜻은 아니다.

## 사업 검토범위

사업자 역할, 제품 형태, 허가 종류, 검토사항, 적용지역의 **검토 후보**를 별도로 기록한다. 현재 7개 근거만 검토했으므로 다른 문서의 미분류를 부적용으로 간주하지 않는다.

| 예시 | 구분 |
|---|---|
| PP96/2021 Pasal102 | 광산·제련/정련, IUP·IUPK와 산업 허가 검토. 당시 기본령 문구이므로 개정 체계와 함께 읽음 |
| Perpres16/2025 Pasal2 | 팜유 농장·가공·바이오에너지 사업자 구분 |
| Permenperin35/2025 Pasal2–3 | TKDN/BMP 상품·산업서비스 인증 검토 |
| Permenperin35/2025 Pasal52–54 | 인증 계산·검증 비용 지원 가능성. 예산·별도 절차·개별 수혜 자격 미확인 |
| Perpres10/2021 Pasal3 | 투자 업종 유형. 개정·별도 부속서·KBLI 조건 미확인 |
| 동칼리만탄 Pergub43/2013 Pasal3–4 | 소농 팜유 열매 공공도로 운송 조건. 석탄 전체 운송 규칙으로 확대하지 않음 |
| 중앙술라웨시 Perda1/2026 Pasal2 | IUPK·계약/협정 연장 IUPK의 순이익 관련 지방 수입. 모든 IUP·거래의 보편 로열티로 취급하지 않음 |

사업 검색에서 `region=Sulawesi Tengah&role=miner`는 검토된 중앙 광업 틀과 중앙술라웨시 지역 근거를 함께 반환한다. `region=Kalimantan Timur`에서는 중앙술라웨시 근거가 제외된다. `national_framework`는 검토 범위이며 모든 지역·사업에 대한 법적 적용 확정이 아니다. `specified_regions`만 해당 지역과 일치시킨다. 미확인 지리 범위는 지역 지정 검색에서 제외한다.

## API 및 화면·Claude 배포 인수

| 경로 | 용도 |
|---|---|
| `/api/idn/coverage?topic=coal&priority=1` | 실제 수집 상태·최근 점검 실패와 우선순위 목록 |
| `/api/idn/context/idn-pp-96-2021` | 현재 확보 본문 버전에 연결된 관계·검토범위·선택 조문 |
| `/api/idn/business?role=miner&region=Sulawesi%20Tengah` | 검토된 중앙+해당 지역의 사업 관련 후보 |
| 기존 `/api/idn/search`의 `matched_passages` | 이미 선정된 문서에서 일치한 근거 조문 최대 3개 |

사업자 역할 키: `miner` 광산, `smelter` 제련/정련, `trader` 무역, `plantation` 농장, `bioenergy` 바이오에너지, `manufacturer` 제조, `investor` 투자, `transporter` 운송. 키가 있다는 것과 그 역할의 근거가 충분히 검토됐다는 것은 다르다. 선택 조문·사업 범위가 없는 검색 결과에도 기존 자료가 유지된다.

문서 검색의 순위·전체 건수·품목·상중하류·발행정부 필터·AND 조건은 유지한다. 조문 조회는 선택된 문서 ID를 한 번에 묶어 요청하며 후보를 늘리지 않는다. 질의 벡터가 이미 있으면 조문 순위에도 재사용해 추가 Gemini 호출을 만들지 않는다. 키워드 경로는 계속 무료다. 조문 API 장애는 `passage_annotations_available=false`로 구분하고 검색 문서는 유지한다.

실제 API 확인: `니켈, 국산화율, 금융지원` + 중류 + 모든 조건 일치에서 TKDN 문서는 3/3, Pasal52–54 발췌는 2/3으로 반환된다. 문서의 품목 분류 일치와 조문 본문 일치를 같은 근거로 표시하지 말아야 한다.

전용 화면에는 결과의 선택 조문과 상세창의 관계·사업범위를 연결했다. 공유 내비게이션·미국 화면은 수정하지 않았다. 배포 인수 시 확인할 사항:
1. 기존 결과 카드에 문서 조건 일치 수를 유지하고, 펼치면 조문 조건 일치 수·원문 인용·한국어 검토 설명·공식 링크를 표시한다.
2. 관계는 ‘개정 문구 확인/폐지 문구 확인’과 ‘현행 효력 미확인’을 함께 표시한다. 대상 원문이 없으면 링크를 있는 것처럼 만들지 않는다.
3. 지역 선택의 의미를 ‘발행지역’과 ‘사업 검토지역’으로 구분한다. 기존 발행정부 필터를 조용히 바꾸지 않는다.
4. 사업 검색 0건은 ‘검토된 근거 없음’으로 표시한다. ‘해당 규정 없음’으로 표시하지 않는다.

## 검증·실행·운영 상태

- 마이그레이션 `20261019081717_indonesia_policy_review_evidence.sql`을 운영 적용했다. MD5 `e4a07806c1d892e83181c0c3d964fb44`가 운영 이력과 일치한다. 적용 도구의 첫 요청은 만료되어 스키마·이력을 확인한 뒤 한 번 재시도했고 성공했다.
- Node DB/API/Worker/임베딩 검사 18개, 소유권 검사 14개, 실제 DB 브라우저 검사 3개 통과. 1360/390px에서 가로 넘침·페이지 오류가 없으며 새 근거 API 실패 시 기존 원문이 유지된다. 신규 설치·재실행·불변 근거·가짜 인용/주소 거부·누락 대상·오래된 근거/벡터 제외·중앙/지방 결합·필터 누출 방지·공개 역할 접근 거부·미국 sentinel 보존을 포함한다.
- 운영 DB/API에서 개정 연결, 미저장 종전 법령, 우선순위별 상태, 지역 결합, 조문 증거를 확인했다. 근거 import 재실행은 추가 0건이고 조문/개요 벡터 대기열은 모두 0건이다.
- 선택 발췌 12개의 입력은 총 9,984자다. 기존 개요 64개는 재생성하지 않았다. 실제 과금 토큰·원화는 측정하지 않았다. 캐시는 저장소 밖 `policy-downloads/indonesia-20261019/passage-embedding-cache/`(0700/파일0600)다.
- 사전 백업: `policy-downloads/indonesia-20261019/before-applicability/`의 기존 문서·본문 JSON(0600). 수집 관측 시각과 원문 해시는 변경하지 않았다.
- 보안 점검의 IDN 항목은 의도된 서버 전용 테이블 7개의 RLS 정책 없음 INFO다. anon/authenticated에 테이블·함수 권한을 부여하지 않았다. [점검 설명](https://supabase.com/docs/guides/database/database-linter?lint=0008_rls_enabled_no_policy)
- 공유 Worker·공유 UI·배포 workflow·메일·미국 데이터는 수정하지 않았다. 인도네시아 전용 화면에 선택 조문·사업 검토 근거를 연결했다. 새 API는 기존 IDN dispatch를 사용한다. 상시 수집·발송·과금 질의 활성화도 하지 않았다.

```bash
node scripts/indonesia_policy/import-review.cjs scripts/indonesia_policy/review-pack-20261019.json --env-file /ABS/SUPABASE_ENV
# 미리보기 검토 뒤 --write 추가
node scripts/indonesia_policy/embed-passages.mjs --env-file /ABS/SUPABASE_ENV --limit 30
# 실제 생성은 --gemini-env-file /ABS/GEMINI_ENV --cache-dir /ABS/PRIVATE_CACHE --write 추가
```

재수집으로 새 본문이 생기면 새 해시를 확인해 근거를 다시 검토하고 새 review ID로 추가한다. 구버전 근거를 덮어쓰지 않는다. 다음 공백은 핵심 원문 회복, 명시적 시행일·경과조치 모델, 더 넓은 사업/지역 검토, 검색 평가셋, 자동 변경 감시, 지역/역할 선택용 화면과 Claude 배포다.
