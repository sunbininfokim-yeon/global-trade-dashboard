# 인도네시아 검색 분류와 상품·지역 메일 조건

## 이번 변경

큰 화면(1180px 이상)은 국가 법률 / 대통령 명령·중앙 결정 / 중앙 행정규정·기타 / 지방 조례·규정의 네 열로 표시한다. 지방 발행 여부를 문서 종류보다 먼저 판단하므로 지방 Keputusan을 중앙 결정으로 잘못 옮기지 않는다. 기관 수준이 확인되지 않은 자료는 별도 확인 필요 그룹에 보존한다.

현재 서버가 반환한 한 페이지(최대 20개)를 분류하며 그룹 안에서는 서버의 관련도·날짜 정렬을 유지한다. 제목의 수는 **현재 페이지 건수**다. 그룹별 전체 건수나 독립 페이지네이션은 구현하지 않았다. 태블릿·모바일은 서버 순서 그대로 한 목록을 사용한다. 원문/PDF·상세·번역 도구 링크를 보존한다. 사이트 배포는 Claude 인수 대상이다.

## 메일 조건의 의미

사용자의 상품·사업지역 요청은 공개 검색 필터 변경이 아니라 **메일 구독 대상 조건**이다. 첫 검토 범위는 `coal` + `Kalimantan Timur`다. 특정 기업의 사업 목적·내부 조사 내용은 공개 UI·저장소에 넣지 않는다.

`scripts/indonesia_policy/business-scope.mjs`는 다음 **검토 후보**만 고른다. 발송 적격성 판단기나 운영 메일 연결이 아니다.

- 상품 검토 태그와 지정 상품이 일치해야 한다.
- 중앙정부 자료는 상품 관련 후보에 포함한다. 석탄에 적용될 수 있는 전국 환경 규정도 검토 대상이다.
- 지방 자료는 지정 관할과 일치할 때 포함한다. 다른 주는 제외한다.
- 군·시와 주의 상하 관계가 확인되지 않으면 추정하지 않는다. 행정구역 crosswalk가 필요하다.
- 모든 포함 결과는 `applicability: review_needed`다. 발행기관 관할·일반 주제 태그만으로 해당 사업에 적용된다고 확정하지 않는다.

이번 실제 DB 조회는 석탄 태그 문서 47건 중 중앙 40건·동칼리만탄 지방 5건을 검토 후보로, 다른 주 2건을 제외했다. 광범위한 태그가 붙은 지방 물류 규칙 등 오탐 가능성이 있으므로 **45건의 적용 법규 또는 발송 대상이 확인됐다는 뜻이 아니다.** 회사·개인 구독 데이터는 만들지 않았다.

## 운영 메일 연결은 미구현

2026-10-20 운영 DB 조회 기준 `mailing_outbox.item_kind`는 `bill / executive_order / commodity`, `kind`는 `policy / commodity`만 허용한다. `mailing_preferences`는 기존 정책·원자재 전체 수신 여부만 보관한다. `policy_idn`에 메일 생성 트리거는 없다. 기존 미국 법안 타입으로 인도네시아 규칙을 넣으면 안 된다.

후속 구현은 별도 migration과 검증을 통해 다음 순서로 진행한다.

1. 국가·상품·사업지역·사업 역할을 담은 사용자 전용 IDN 구독과 RLS를 추가한다. 구독 해제·메일 거부도 발송 직전에 재확인한다.
2. 발행 관할과 적용 지역을 분리한다. 검토된 전국 적용 규정과 해당 주·군·시 적용 규정 중 상품 조건도 만족하는 자료를 고른다. 불명확한 대상은 보류한다.
3. 최초 수집은 기준선으로만 저장한다. 이후 신규·개정·폐지·시행 이벤트를 검토된 근거/버전과 연결한다. OCR·공백·해시 변화만으로 법적 변경 알림을 만들지 않는다.
4. IDN 전용 알림 종류·렌더러·구독 적격성 검사를 기존 메일 대기열에 추가한다. 구독+문서+변경 이벤트의 중복 키와 Resend idempotency를 적용한다. 발송 시에는 검토한 변화와 현재 자료 범위·원문 링크를 제공한다.
5. 권한·구독 철회·재시도·중복 실행·같은 문서 다중 상품 매칭·다른 국가 격리 검증 뒤 기존 Resend 발신 경로를 재사용한다.

이 변경에서는 구독 등록·대기열 쓰기·실제 발송·발송 활성화를 하지 않았다. 새 Resend 키는 이 후보 검토에 필요하지 않다.

## 자동 수집 상태

수집·목록 대조·저장·임베딩 CLI는 있지만 이번 점검에서 IDN 법령용 GitHub 예약, Mac LaunchAgent 또는 실행 중인 수집기는 확인되지 않았다. 같은 이름의 인도네시아 작황 예측·중앙은행 정책 워크플로는 법령 수집과 별개다. 현재 자동으로 최신 법령이 DB에 들어온다고 안내하면 안 된다.

다음 연결이 필요하다: 공식 목록 변경 점검 → 신규/변경 후보 → 제한된 공식 원문 수집 → 원자 저장 → 변경된 검색 입력만 임베딩 → 효력/적용범위 검토 → 적격 알림 이벤트. 점검 실패·차단은 기존 자료를 보존하고 미확인으로 기록한다. 사용자가 주기를 정하기 전 임의로 예약을 활성화하지 않는다.

## 검증

- 그룹 분류·메일 검토 후보·기존 API 단위 검사 11개 통과.
- 실제 Supabase를 조회하는 브라우저 검사 5개 통과. 1440/1024/390px의 표시 전환, 페이지 문서 보존, 상세·원문 링크, 검색 오류, 한국어 검색 및 근거 표시를 확인했다.
- 브라우저 검증은 의미검색을 끈 로컬 preview에서 실행했으며 유료 AI 호출·DB 쓰기·메일 발송은 하지 않았다. 원래 hybrid를 강제하던 화면 검사는 키워드 UI 검사로 바로잡았다. 이 결과는 hybrid 검색 검증을 대신하지 않는다.
