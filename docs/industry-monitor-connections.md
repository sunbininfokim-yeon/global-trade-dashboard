# 미연결 산업 공고·근거 연결

구현·일부 원문 재확인: 2026-10-13. PR #528 후속. 공고 모니터를 AD 현금예치 계산 사건 등록 여부에서 분리했다. 기존 5개 AD 계산 사건·33개 법인·세율·단계 데이터는 변경하지 않는다.

## 화면 연결

기존 AD 사건 5개는 기존 공고 발견/검토 목록을 사용한다. 나머지 17품목은 새 `industry-monitor.mjs`의 ‘공식 공고·정책 근거’를 계산기 밖에 표시한다. 자동차 공고가 AD 단계 불을 켜거나 OCTG 마진이 자동 예치율로 변환되는 경로는 없다.

| 대상 | 표시한 공고·근거 | 남은 범위 |
| --- | --- | --- |
| 자동차 완성차4/제동·조향·현가3 | 한국 자동차·부품 232 시행 공고 2025-21940 Part A | 실제 사양·원산지·용도·후속 조치 확인. AD 아님 |
| OCTG | A-580-870 최종결과 2026-19529, POR 2023-09-01~2024-08-31 | 기업별 현행 예치 지침·CVD율·소송·CBP 정산 미확정 |
| 현가 관련 제품 | A-580-923 유압실린더 개시2026-18706/정정2026-19374 | 관련 범위 검토용. 현가장치·HL만도 적용 확정 아님 |
| 차단기·산업용 섬유 | 기존 품목별 관세 정책·HTS·한국 사건 목록 검토·기업 근거 | 개별 공고 목록 미수록 |
| 케이블3/트럭버스 타이어/탄소섬유/아라미드/모터·인버터 | 기존 사건 목록 검토·제조사 자료, 확보한 분류 후보 | 개별 공고 목록·실제 사양별 관세 미확정 |

8개 품목은 선별 공고가 표시되고, 나머지 9품목은 검토 근거만 연결된다. 뒤의 9개에 공고나 사건이 없다고 판정한 것이 아니다. 표의 현가 유압실린더 공고는 현가 품목의 추가 근거이므로 별도 품목 수로 세지 않는다.

## 출처와 시점

- [2025-21940](https://www.govinfo.gov/content/pkg/FR-2025-12-04/pdf/2025-21940.pdf): 2025-12-04 발행. 자동차·부품 Part A의 대상 통관 적용일은 2025-11-01로 별도 표시. 공고 발행일과 통관일을 합치지 않았다. 2026-10-13 원문 해당 부분 재확인. 이 공고 하나로 현재 모든 제품·추가세를 확정하지 않는다.
- [2026-19529](https://www.govinfo.gov/content/pkg/FR-2026-09-24/pdf/2026-19529.pdf): 2026-09-24 공표 OCTG 행정재심 최종결과. 2026-10-13 원문 재확인. 기존 검토에 남긴 cash simple-average 조항의 적용 불명확성 때문에 계산 연결을 보류한다.
- [2026-18706](https://www.govinfo.gov/content/pkg/FR-2026-09-14/pdf/2026-18706.pdf) 및 [2026-19374](https://www.govinfo.gov/content/pkg/FR-2026-09-22/pdf/2026-19374.pdf): 관련 유압실린더 조사 자료. 해당 검토 레코드의 확인일10/12 보존.
- 다른 관세·분류·기업 링크는 기존 검토 자료를 표시한다. 전부10/13에 새로 검증한 자료로 표시하지 않는다. 이번 작업은 최신 전체 공고 자동 수집이 아니다.

원산지가 한국 외이거나 공란인 경우 한국산 공고를 반환하지 않는다. 다른 품목 선택 시 이전 OCTG/자동차 공고가 남지 않으며, 모든 모니터 레코드는 `calculation_enabled:false`다.

## 검증·전달

Node95개·소유권 회귀7개·preview asset map/구문/공백 검사 통과. 신규5개 테스트에서 미연결17품목의 근거 존재, 법적 제도 구분, 날짜 구분, 무근거 세율 미생성, 원산지·제품 격리, 원본 불변을 확인했다. 실제 mount 이벤트 핸들러에 메모리 렌더링 하네스를 연결해 자동차→OCTG→케이블→기존AD의 선택·공고 표시·계산 폼 상태 전환도 검증했다. 브라우저·네트워크 호출 없는 검사다.

전용 preview asset map에 새 모듈을 등록하고 localhost:8773 서버를 재시작했다. 앞선 앱 내 기존 오류 탭 접근이 브라우저 보안 정책으로 거부되어 이번에도 브라우저 우회 경로를 사용하지 않았다. 이번 변경의 실제 브라우저 스모크/스크린샷은 미완료이며, 기존 브라우저 테스트 제목·공고 미수록 문구 기대값만 새 흐름에 맞게 보완했다.

DB·기존 수집기/워크플로·메일·유료 AI·main 병합·운영 배포는 변경하지 않는다.
