# 공고 중심 반덤핑 모니터

구현일: 2026-10-13. 기존 PR #528 후속. 새로운 공고·세율을 조사하거나 법적 적용을 확대한 변경이 아니다. 자료별 기존 확인일을 유지한다.

## 기본 흐름

산업 → 품목 → **품목 전체**가 기본이다. 기업이나 거래 금액·통관일을 입력하지 않아도 수록한 공식 공고, 공표 마진 이력, 재심 대상 기간과 공통 진행 근거를 볼 수 있다. 현재 수록 사건의 대상 원산지는 한국이다. 본사 소재지·선적 항구와 구분하며, 다른 원산지에 한국 자료를 적용하지 않는다. 미수록 국가를 선택할 수 있는 형식적인 목록은 추가하지 않았다.

기업 선택은 선택사항이다. 특정 기업을 누르면 해당 법인의 재심 선정·철회·예치 적용 근거로 좁힌다. ‘품목 전체’로 돌아가면 기업 선택 표시를 해제하고 기업별 철회 기록은 제외한다. 기업을 지정한 선정 이벤트는 전체 보기의 공통 단계에 사용하지 않으며, 특정 기업의 예치율 발효를 전체 품목의 예치율로 표시하지 않는다. 공통 근거 미수록은 실제 절차 미진행을 뜻하지 않는다.

공표 마진 이력과 새 공고 검토 목록은 계산기 밖으로 이동했다. 예비 마진, 최종 마진, 현금예치율, 관세 확정은 기존 구분을 유지한다. 미확인 품목은 품목 차원의 공식 자료 확인 결과를 보여주고 기업을 선택한 경우만 기업 제품 원문·기업 손익 이동 버튼을 제공한다.

## 선택 계산

‘선택 · 예치 부담 계산’을 펼칠 때만 통관일·신고가격·비교 예치율·금리·기간 및 생산자/수출자 조건 확인을 이용한다. 계산용 법인과 참고율을 명시하며 품목 전체의 평균 예치율로 계산하지 않는다. 제품·법인 조건 확인은 계속 필수다. 품목 전체로 돌아가면 계산기를 접되 직접 수정한 값은 보존한다. 기업 손익 화면의 기존 ‘반덤핑 사건 확인’ 이동은 해당 기업으로 좁혀 계산기를 연다.

기본 모니터를 보려는 이용자에게 공장·선적 항구·거래별 생산자/수출자를 필수 입력받지 않는다. 실제 통관 적용은 품목 범위·원산지·법인·날짜·CBP 지침 검토가 필요하며 이 모니터가 자동 판정하지 않는다.

## 검증·범위

- Node90개 및 소유권 회귀7개 통과. 기업별 철회가 사건 전체로 확장되지 않음, 개별조사 선정 이벤트의 전체 보기 제외, 원본 기록 불변 검증 포함.
- 브라우저7종 통과: 신규 모니터, 기존 반덤핑 계산, 입력 안내, 산업·기업 선택, 공식 자료 확인, 22품목/40기업 전수, 기업 손익. 전체 보기·기업별 보기·과거 POR·철회·예치108,000달러 계산·입력 보존·360px·외부 호출 없음 검증.
- 공고 발견 브라우저 테스트는 접힌 계산기 내부 텍스트 확인에서 실패하여 DOM 텍스트 조회와 명시적 계산기 열기로 보완했다. 보완 후 해당 테스트의 브라우저 재실행은 완료하지 못했다. 앱 내 기존 오류 탭 접근이 브라우저 보안 정책에 거부되어 다른 브라우저 경로로 우회하지 않았다. 수정 테스트 구문 검사 통과.
- 검증 화면: `docs/previews/antidumping-monitor-{desktop,mobile}.png`. 기존 공식 확인 화면도 새 배치에 맞게 갱신.
