# 인도네시아 광물·가치사슬·문서개요 검색

2026-10-19. 기존 PR #613 후속. Codex 구현·운영 IDN DB 반영·로컬 검증, Claude 병합/사이트 배포 역할을 유지한다.

후속 수집 결과는 [공식 출처 복구·산업 규정 보고서](indonesia-policy-official-recovery-20261019.md)를 따른다. 아래 63건은 이 문서 최초 검증 시점이며 후속은 64건이다.

## 현재 범위와 경계

- 저장 63문서·68관측 버전·121출처 확인. 원문/부속서 44문서(이전 일부 수집 2건 포함), 메타데이터만 19문서다. 현행 법적 효력은 모두 unverified다.
- 기본 검토 목록 97개 중 63개 저장·34개 미저장이다. 과거 출처 실패 이력은 현재 미수집 문서 수와 다르다. 신규 12건 시도에서 3건 확보, 공식 대체 출처 7건 시도에서 1건 확보했다.
- 인도네시아 전용 schema와 원문·관할·문서 유형을 보존했다. 미국 수집·벡터·메일·공유 사이트 배포를 변경하지 않았다. 상시 수집/임베딩 스케줄을 켜지 않았다.
- IDN 테이블·인덱스 크기는 측정 시점 2,187,264바이트(약 2.09MiB). Supabase 전체 사용량이 아니다.

## UI 보강

기본 화면은 검색창·품목·사업단계·자료 구분이다. 발행정부·지방 발행지역·문서 유형·정렬은 접힌 추가 필터로 옮겼다. 검색 예시와 초기화를 추가했다. 공통 회사/도산 법규가 석탄 전용으로 보이던 대표 배지를 제거했다. 공통 사업법규·업종 공통 제도·품목과 단계, 원문/메타데이터·일부 수집·효력 미확인을 각각 표시한다.

본문 미확보 자료는 카탈로그 메뉴를 원문 발췌처럼 보여주지 않는다. 자료 확인일과 문서 연도를 구분한다. 기존 조건 일치 개수와 제목/본문/분류 근거는 유지하며, 의미 후보는 별도 표기한다. 의미 연관도는 적용성·신뢰도·보조금 자격 판정이 아니다.

품목 필터: 석탄, 니켈, 팜유, 바이오연료 + 보크사이트/알루미늄, 구리, 주석, 코발트, 망간, 철광석/철강, 실리카/석영, 금/은, 희토류. 추가 광물은 주로 기존 광업·투자·환경·공통 사업법규의 관련성을 분류한 단계다. 품목별 전용 규정이나 개별 광산 허가를 전수 확보했다는 뜻이 아니다.

사업단계는 상류(탐사·채굴·재배), 중류(선광·제련·정련·가공), 하류(소재·최종 제품·연료), 별도 거래(수출입·유통)다. `taxonomy.json`의 명시적 ID별 검토 태그를 사용한다. 미분류 문서는 특정 단계 필터에서 제외되므로 0건을 규제 없음으로 해석하지 않는다. 공통 법규의 여러 단계 태그는 각 단계의 검토 관련성이지 의무 확정값이 아니다. 수집/import가 이 태그를 보존한다.

## 정책 근거와 조사 우선순위

‘유망’은 투자 수익률 순위가 아니라 공식 산업정책·자원 자료를 기준으로 한 조사 우선순위다. 자원 존재·매장량·가채성·실제 허가·사업 수익성을 구분한다.

| 분야 | 가치사슬 검토 예시·추가 확인 |
|---|---|
| 보크사이트 | 채굴 → 알루미나 → 알루미늄·제품. 정련 전력·물·잔재물·수출 제한과 입지 검토 |
| 구리 | 채굴·정광 → 제련·정련/캐소드 → 소재·제품. 제련소·판매제품별 허가 검토 |
| 주석·철광석/철강·금/은 | 광업·제련·제조·무역의 해당 단계별 규정. 금속별 원광과 가공제품 구분 |
| 코발트 | 니켈 등과 연계된 부산물 회수·가공 가능성 및 제품 형태 확인. 독립 광산과 동일시하지 않음 |
| 망간·실리카 | 제련·고순도 소재 산업을 검토하되 품위·기술·전력·구매자 조건 별도 확인 |
| 희토류 | 탐사·분리/정련·소재 단계 구분. 자원 목록이나 정책 지정만으로 상업 생산을 확정하지 않음 |

## 실제 임베딩과 검색

현재 문서개요 63개, 모델 `gemini-embedding-001`, 1536차원, `overview-v1`이다. 제목·검토 범위·품목/단계 태그·최대 3000자 원문 발췌를 합쳐 입력 최대 5400자다. 메타데이터 문서는 카탈로그 메뉴를 임베딩하지 않고 제목·검토 범위만 사용한다. 전체 법령이나 전체 조문을 임베딩한 것이 아니며 번역/답변 생성은 없다.

문서 본문 해시와 제목·분류·검토 범위 지문이 현재 입력과 일치하는 벡터만 검색한다. 변경된 원문/분류의 구벡터는 제외하고 다음 실행 대기열에 넣는다. 문서용 RETRIEVAL_DOCUMENT, 질의용 RETRIEVAL_QUERY와 동일 모델·차원을 사용한다. 차원을 줄인 벡터는 정규화한다. 63개로 작으므로 별도 HNSW 인덱스 대신 정확 거리 계산을 사용한다.

기본 키워드 검색은 Gemini를 호출하지 않는다. `mode=hybrid`는 명시적으로 선택한 경우만 질의 벡터를 생성한다. 키워드 일치 또는 개요 유사도 0.60 이상을 후보로 사용하되, 품목·사업단계·발행정부·자료 구분·문서 유형은 엄격히 유지한다. ‘모든 조건 일치’는 키워드 조건이며 의미검색으로 우회하지 않는다. 임계값은 시범값이며 관련도 품질의 보증이 아니다. 실제 검색 평가를 축적해 조정해야 한다.

벡터 생성 후 DB 쓰기 전에 비공개 캐시에 저장한다. 중간 실패 재실행은 현재 DB와 캐시를 확인하여 중복 호출을 줄인다. 이번 개요 입력은 최초 170,682자이며 메타데이터 1건 보정 후 그 문서만 다시 생성했다. 현재 유효 벡터 63개·대기 0개다. 생성량과 원화 청구액/실제 토큰 수는 다르다.

질의 벡터는 서버 인스턴스별 최대 64개·10분 재사용한다. 페이지 이동마다 같은 질의를 재임베딩하지 않는다. 서버 Secret과 `IDN_SEMANTIC_ENABLED=true`가 있어야 의미검색이 가능하며 브라우저에는 키를 전달하지 않는다. 로컬에서 활성화했으며 운영 배포는 하지 않았다. 공개 활성화 전 Claude가 요청량·비용 제한과 비공개 Secret을 준비해야 한다.

## 검증·운영 인수

- Node 14개·Python 수집기 14개·소유권 14개 검증. 벡터 검사에는 신규 설치·재실행, 단계/품목 엄격 필터, 변경된 분류 벡터 제외, 오래된 입력 저장 거부, 미국 sentinel 보존, 공개 역할 접근 거부를 포함한다.
- 실제 Gemini/DB 질의: 보크사이트+제련/중류, 구리+투자/상류, 팜유+인증/하류/대통령령을 확인했다. 관련 결과가 나왔다는 것이 개별 사업의 적용성을 검증한 것은 아니다.
- 브라우저 2개 통합 검증: 1360/390px 넘침 없음·페이지 오류 0, 공통 법규 배지, 새 광물/단계, 개요 의미검색, 본문·링크·페이지·0건/오류 구분.
- Latin 단어는 단어 경계로 검색하여 주석 `tin`이 `kepentingan` 내부에 잘못 일치하는 문제를 막았다. 한국어·문서번호·구문 검색은 기존 문자 일치를 유지한다.
- 비공개 백업 `policy-downloads/indonesia-20261019/before-value-chain/database.json`(0600), 원문/벡터 캐시는 저장소 밖이다.
- 운영 마이그레이션/로컬 MD5: `20261018223817` bcb91b2dd3b4a358a385b4a58e13981e, `20261018223822` ea98dac3b0536b1265e9456dda176c3e, `20261018224504` ec1aa85b1df20791386a1ff44af031bf.
- 보안 검사 IDN 항목은 비공개 테이블 4개의 ‘RLS 정책 없음’ INFO다. 서버 전용이며 anon/authenticated 접근을 의도적으로 거부한다. 공개 정책을 추가하지 않는다. https://supabase.com/docs/guides/database/database-linter?lint=0008_rls_enabled_no_policy

배포 인수: 새 API는 서비스 전용 `public.idn_search_documents_v2`를 사용한다. 기존 RPC도 보존했다. 공유 `_worker.js`·배포 workflow·미국 자료 경로의 추가 수정은 없다. PR 병합과 사이트 배포는 Claude 담당이다. 키워드 검색 배포와 유료 질의 의미검색 공개 활성화는 구분한다. 자격증명을 공개 코드나 채팅에 붙이지 않는다.
