# 반덤핑 공고 발견과 적용 검토 — 2026-10-12

이번 후속은 **공고 발견 → 원문 보관 → 검토 목록**까지다. 계산용 세율·재심 단계의 자동 갱신, 운영 수집 예약, DB·메일·배포는 연결하지 않았다. 유료 AI·API 키 없이 Federal Register 검색 API와 GovInfo 공식 원문을 사용했다.

## 실제 조회 결과

기간은 2026-01-01~2026-10-12, 선별된 5개 사건만 검색했다. 모든 사건에서 목록 페이지 수·결과 건수·문서번호·원문 사건번호를 확인한 후 성공 날짜를 기록했다.

|---|---:|---:|---:|
| A-580-867 변압기 | 4 | 3 | 1 |
| A-580-908 승용차·경트럭 타이어 | 8 | 1 | 7 |

**15건은 새 세율 15개를 뜻하지 않는다.** 예비결과, 재심 개시, 재심 신청 기회, 일몰재심 예고·결과, 철회 공고가 섞여 있다. 기존 수록 8건도 이번 원문과 세율 카탈로그의 일치가 자동 재검증된 상태는 아니므로 `catalogued_not_reconciled`로 표시한다.

생성 자료: `New for anti/policy-simulator/antidumping-discovery-snapshot.mjs`. 원문 SHA-256·검색 범위·사건별 성공일·재검토 상태를 포함한다. 로컬 원문/체크포인트는 `/tmp/chokemonitor-ad-review-20261012-final/`에 있으며 Git에 넣지 않았다. `/tmp`는 장기 보관 장소가 아니므로 계속 운영할 때는 아래처럼 Documents의 전용 상태 디렉터리를 사용한다.

화면은 반덤핑 탭 아래 **새 공고 확인**에서 선택 사건의 최신 5건과 이전 공고를 펼쳐 보여준다. 산업을 바꾸면 목록도 바뀌며 AD 사건이 없는 품목에는 다른 품목의 공고를 붙이지 않는다. 마지막 성공은 한국시간으로 표시한다.

## 강관 21개사 예치율 추가 검토

[2026-08489](https://www.govinfo.gov/content/pkg/FR-2026-05-01/html/2026-08489.htm)의 최종결과 표·Appendix II는 21개사 배정 마진을 0.80%로 확정한다. 그러나 Cash Deposit Requirements (1)은 HSP와 SeAH만 명시하며, 이후 조건은 이전 참여 법인·생산자·all-others에 관한 것이다. 이 문구만으로 비선정 21개사의 미래 통관 예치율을 모두 0.80%로 확정할 수 있다고 판단하지 않았다.

2026년 사건번호 검색에서 발견한 4건 중 별도 정정 공고는 없었다. 검색 누락 가능성과 ACCESS·CBP 지침 미검증은 남아 있다. 따라서 `deposit_rate_pct:null`을 유지한다. 법인별 CBP 예치 지침, 생산자/수출자 조합, 승계·발효 조건을 확인한 다음에만 계산용 예치율을 추가한다. 7.08% all-others도 자동 대입하지 않는다.

## 새로 발견한 타이어 공고의 해석 경계

- [2026-08285](https://www.govinfo.gov/content/pkg/FR-2026-04-29/html/2026-08285.htm): POR 2024-07-01~2025-06-30 재심 요청이 철회되어 재심을 철회한 공고다. 무관세·명령 폐지·CBP 정산 완료로 해석하지 않는다. 해당 POR 통관 당시 예치율을 기준으로 사후 부과하도록 지시할 예정이라는 문구와 실제 수입 건 정산을 구분한다.
- [2026-18185](https://www.govinfo.gov/content/pkg/FR-2026-09-04/html/2026-18185.htm): 다음 POR 2025-07-01~2026-06-30 개시 목록에 Hankook Tire & Technology, Hankook Tire America, Kumho, Nexen Tire America, NEXEN TIRE가 기재된다. 이번 개시만으로 조사기업 선정·새 세율·미국 계열사와 제조사의 동일 취급을 확정하지 않는다.
- [2026-19931](https://www.govinfo.gov/content/pkg/FR-2026-09-30/html/2026-19931.htm): expedited sunset review 공고다. 제목의 Final Results를 연례 행정재심 최종결과로 오인하지 않는다. 원문 SUMMARY에 China라고 적힌 부분과 제목·대상 사건의 Korea 간 불일치도 있어 검토 대상으로 유지한다. 일몰재심 수치를 회사별 미래 예치율로 자동 입력하지 않는다.

현재 계산 카탈로그와 단계는 이번 발견 목록을 import하지 않는다. 자료 확인일도 발견 성공일과 분리하여 기존 통관 조회 상한 2026-10-11을 그대로 유지한다.

## 실행 방법

프로젝트 루트에서:

```bash
node scripts/trade_policy/discover_antidumping_notices.mjs \
  --state-dir "$HOME/Documents/policy-downloads/antidumping-review" \
  --through 2026-10-12
```

기본 시작일은 2026-01-01. 다음번 새 공고/같은 번호의 원문 변경을 확인할 때는 실제 확인 날짜를 `--through`에 넣고 정상 실행한다. `--resume`은 **같은 날짜 범위에서 실패한 사건만** 재개한다. 같은 범위에서 이미 완료된 사건은 재조회하지 않아 API 사용을 줄이지만, 그 사건의 이후 원문 수정도 새로 확인하지 않으므로 정기 점검용 대체 옵션이 아니다.

검토 목록을 로컬 UI에 반영하려면 결과를 확인한 후 같은 명령에 다음 인수를 추가한다:

```bash
--snapshot 'New for anti/policy-simulator/antidumping-discovery-snapshot.mjs'
```

이 인수는 검토 목록만 생성한다. `antidumping-catalog.mjs`, `antidumping-guide.mjs`, Supabase는 수정하지 않는다. 스냅샷 갱신이 사이트 배포나 상시 수집 활성화를 뜻하지 않는다.

## 실패·재개·검토 규칙

- 요청 사이 최소 1.5초, 실행당 최대 80요청, 사건당 최대 2페이지/200검색 결과, 요청당 30초. 모두 순차 실행.
- 403·429는 재시도하지 않고 실행 전체를 중단한다. 최소 4시간과 서버 Retry-After 중 더 늦은 시간을 체크포인트에 기록하며, 그 전 재실행도 거부한다.
- 각 사건의 전체 목록과 원문을 확인한 후에만 성공 워터마크를 저장한다. 중간 실패는 기존 목록·성공일을 보존하고 `failed_preserved`로 표시한다. 다음 사건은 계속 확인할 수 있지만 차단 시에는 멈춘다.
- 한 사건의 일부 원문만 받았을 때는 그 부분을 성공 자료로 승격하지 않는다. 받은 원문은 로컬 캐시에 남을 수 있지만 계산/검토 스냅샷의 성공 상태와 분리된다.
- 같은 문서번호는 중복 행을 만들지 않는다. 본문 해시/정정 메타정보 변경은 `changed_needs_review`, 검색에서 사라진 기존 문서는 삭제하지 않고 `missing_from_search_needs_review`로 보존한다. 페이지 중복·건수 불일치는 불완전 조회로 처리한다.
- 같은 상태 디렉터리에 잠금을 둬 중복 실행을 막는다. 강제 종료로 잠금이 남으면 `running.lock/owner.json`의 PID와 실제 실행 프로세스를 확인한 후에만 잠금을 제거한다. 실행 중 잠금을 지우지 않는다.
- 날짜 범위를 바꾸려면 시작일이 같은지 확인한다. 시작일이 달라지면 별도 디렉터리를 사용하며, 기존 완료 종료일보다 과거 날짜로 체크포인트를 되돌릴 수 없다.
- 신규 후보에는 `legal_effect_verified:false`, `rate_activation_allowed:false`. 회사 매핑·제품 범위·POR·행위 종류·예치 발효 조건·후속 정정/법원/CBP를 확인한 검토자가 별도의 카탈로그 수정과 검증을 수행한다. 원문 검색만으로 승인하지 않는다.

## 검증

Node 76개와 소유권 회귀 7개 통과. 변경된 공고 본문·정정 메타정보, 429 중단/쿨다운, 부분 페이지·원문 오류·체크포인트 보존, 중복·누락·다른 국가 사건·GovInfo 줄바꿈 사건번호·재개·요청 상한을 확인했다. 브라우저 3종(공고 검토, 전체 산업/기업, 입력 안내·단계)과 360px 검증 통과. 화면에서 외부 API·AI 호출 없이 정적 스냅샷만 표시한다.
