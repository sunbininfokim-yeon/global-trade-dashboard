# 국가 관세 시뮬레이터 v1

정책 → 미국의 **의회 | 행정부 | 관세 시뮬레이터**에서 진입한다.
시뮬레이터의 **국가 | 기업** 중 국가 버전의 설명이다. [기업 버전](company-tariff-simulator.md)은
별도의 기업 입력·제품 손익 산식과 국가 평균 반응 연결을 제공한다.
직접 경로는 `/policy/us/simulator`다. 이 PR은 정책 자료 조사·반덤핑 사건 모니터와 독립적이다.

## 무엇을 분석하나

미국의 **동일 품목시장**에서 공급국별 관세를 바꿨을 때 구매가격, 생산자가격,
판매량, 관세 제외 공급자 매출, 관세 포함 구매액 점유율이 어떻게 달라지는지 계산한다.
국가 GDP·고용이나 특정 기업의 이익을 예측하는 거시 모형은 아니다.

단순한 `기존 수입액 × 관세 변화`와 달리, 수출자의 가격 조정, 미국 구매자의
수요 감소, 경쟁 공급국으로의 전환을 함께 풀어낸다. 이 반응은 입력한 탄력성에 의존한다.

구매액·공급탄력성은 **학습용 가정**이다. 관세는 **2026-10-11에 부분 검토한 대표 HTS·원산지·조건별 정책 스냅샷**에서 시작한다. 완전한 현행 세율 서비스나 자동 갱신 수집기가 아니다. 아래 6개 품목은 출처 있는 대체탄력성 시작값을, 그중 3개는 시장 수요탄력성 시작값도 제공한다. 미확보 매개변수는 사용자 가정으로 구분한다. 결과는 계속 조건부 시뮬레이션으로 표시한다.

## 사용 순서

1. 분석 품목의 **대표 HTS·사양**을 읽고 구매액의 기준 연도·기간을 정한다. 이 기간은 관세 검토일과 별개다.
2. 공급국별 관세 포함 구매액(백만 USD)과 공급탄력성을 입력한다. 동일 품목·기간·가격 기준을 사용한다. 최대 8개국이다.
   USITC 2025년 HS6 소비용 수입액 상위 8개국 버튼으로 국가를 추가할 수 있으며 새 행의 구매액은 비워 둔다.
3. 국가별 **현행 관세 조합**을 선택한다. 비교할 관세는 **현재 유지 / 현행 제도의 조건별 조합 / 직접 입력** 중 선택한다.
   ‘직접 입력’을 선택했을 때만 숫자칸이 열린다. 현행 조합 미확인 국가에는 검토한 현행 합산율과 출처를 직접 입력한다.
4. 조건·별도 추가세를 확인하고 대체탄력성 σ, 시장 수요탄력성 η, 자료 메모를 조정해 계산한다.
5. 관심국의 판매량·매출, 미국 품목시장 가격지수, 다른 공급국의 변화와 민감도를 확인한다.
6. 결과 JSON에는 모형 버전·잔차 외에 HTS, 관세 검토일, 조건, 출처, 직접 입력 여부, 탄력성 근거도 남는다.

입력을 바꾸면 이전 결과 표시를 유지하면서 재계산 필요 문구와 흐린 표시를 띄운다.
재계산 전에는 저장할 수 없다. 오류가 나도 이전 정상 결과를 새 결과로 취급하지 않는다.
미입력·공백·범위 오류 또는 현행 관세 미선택이 있으면 폼 순서상 첫 수정 대상에 스크롤하고 포커스를 옮긴다.
접힌 ‘조건·별도 추가세’도 자동으로 펼친다. 입력칸 강조, 바로 아래 오류, `aria-invalid`와 설명 연결을 함께 제공한다.
수정 시 표시를 해제하며 다음 계산에서 남은 오류를 다시 찾는다. 기업 탭에도 같은 동작을 제공한다.
탭 이동 중 입력은 메모리에 보존되며 새로고침 시 초기 입력으로 돌아간다. 최초 진입에는 결과를 미리 계산하지 않는다. 품목·원산지 변경 시 관세 경로와 조건 확인을 초기화한다. 품목 변경 시 탄력성도 새 품목의 문헌값 또는 명시된 사용자 가정으로 초기화한다. 자동 저장·서버 전송은 없다.

### 엔진 회귀검증용 가상 예시 (화면 초기값과 별개)

미국산 50, 한국산 25, 기타국 25백만 달러 구매액, 한국산 관세 0→25%,
σ=4, η=−1, 공급탄력성 1.5/3/3 가정:

| 산출물 | 변화 |
|---|---:|
| 한국산 판매량 | −27.99% |
| 한국 공급자 매출(관세 제외) | −35.46% |
| 한국산 생산자가격 | −10.37% |
| 한국산 미국 구매가격 | +12.04% |
| 미국산 판매량 | +3.51% |
| 기타국 판매량 | +5.57% |
| 미국 품목시장 가격지수 | +4.30% |

이는 실제 한국 변압기 수출 전망이나 실제 적용 관세율이 아니다.
σ를 2/4/6으로 바꿀 때 한국산 판매량 변화는 −21.53/−27.99/−31.36%다.
이 비교는 가정 민감도이며 확률·신뢰구간이 아니다.

## 자료와 가격 기준

- `expenditure`: 미국 구매자가 해당 공급국 제품에 지출한 **관세 포함 기준 구매액**, 백만 USD.
  한국 행의 25는 한국산 해당 품목 구매액 2,500만 달러다. 미국 행은 미국산 제품 구매액이며 미국으로의 수입액이 아니다.
  현재 50/25/25는 실제 산업 통계가 아닌 가상 초기값이다. 구매액 비중은 기준 시장 점유율을 정하고,
  이 일정 탄력성 모형에서 모든 구매액을 같은 비율로 늘리면 금액 결과만 같은 비율로 늘고 변화율은 유지된다.
- `tariff_before`, `tariff_after`: 0~300%, 입력한 **종가세 시나리오**. 미국 국내 공급은 0%로 고정.
- `supply_elasticity`: 0~100. 0은 공급량 고정. `sigma`: 0.1~20. `eta`: −10~−0.05.
- 국가 코드는 3글자, 중복 금지. `ROW`는 입력하지 않은 기타국의 합계다. 새 국가를 분리할 때 ROW에서 빼야 한다.
- 모든 행의 구매액은 양수여야 한다. 0인 행은 제거한다. 신규 공급국의 시장 진입은 모형 범위 밖이다.
- DataWeb의 Customs Value는 관세 전 통관가액이다. 국내 출하·유통 마진·관세·품목 범위를 맞추기 전에
  모형의 구매액에 그대로 주입하지 않는다. 배포 자산에는 공개 공급국 집계만 포함하며 DataWeb 키나 실행 중 API 조회는 없다.
- 정책 카드의 `rate_ko`, 임베딩 검색 결과에서 관세 숫자를 추출하지 않는다.
  숫자는 검토한 HTS 및 정책 조항별 명시적 규칙으로만 구성한다. 사용자는 거래 조건과 별도 추가세를 확인한다.
- AD/CVD 법적 세율·예치/확정액, 종량세·관세할당의 자동 판정은 별도 모듈이다. 아래 명시한 제한된 232/301 경로만 지원한다.

## 관세 정책 조합의 범위

일반관세는 USITC 공식 HTS 공개 API `https://hts.usitc.gov/reststop/search?keyword=<HTS>`에서 2026-10-11 확인했다. 일반세율과 특혜 표기만으로 전체 관세를 확정하지 않는다.

|---|---|---:|---|
| 액체절연 변압기 >10MVA | 8504.23.00 | 1.6% | Annex III 철강 중량 ≥15% 제품의 합산 15% 하한 / 미국산 금속 요건 합산 10% 하한. ≥60MVA 한국산 AD 등 별도 확인 |

| 자동 차단기 1~72.5kV | 8535.21.00.00 | 2.7% | 301 강제노동 일반 경로, 국가별 하한 또는 추가율 구분 |
| 메모리 집적회로 | 8542.32.00 | 0% | 301 강제노동 Annex (b) 품목 예외. 연산 칩·서버 232를 메모리 전체에 적용하지 않음 |

공식 근거:

- [232 금속 2026-04-02 공고 §3·§5·§9](https://www.whitehouse.gov/presidential-actions/2026/04/strengthening-actions-taken-to-adjust-imports-of-aluminum-steel-and-copper-into-the-united-states/) 및 [HTS·함량 부속서](https://www.whitehouse.gov/wp-content/uploads/2026/04/Metals-ANNEXES-I-A-I-B-II-III-IV.pdf).
- [2026-06-01 수정 §4: 미국산 금속 85% 조건](https://www.whitehouse.gov/presidential-actions/2026/06/further-adjusting-the-tariff-regimes-for-imports-of-aluminum-steel-and-copper-into-the-united-states/) 및 [현재 Annex III의 8504.23.00](https://www.whitehouse.gov/wp-content/uploads/2026/06/Annex-III.pdf).
- [CBP 강제노동 301 지침](https://content.govdelivery.com/accounts/USDHSCBP/bulletins/421d887) 및 [국가별 HTS·예외·섬유 쿼터 부속서](https://www.whitehouse.gov/wp-content/uploads/2026/07/ANNEX.pdf), 2026-07-24 시행.
- 한국 [2025-21940 Part A](https://www.govinfo.gov/content/pkg/FR-2025-12-04/pdf/2025-21940.pdf), 일본 [2025-17908](https://www.govinfo.gov/content/pkg/FR-2025-09-16/pdf/2025-17908.pdf)의 자동차 232 시행 조항. IEEPA 일반 상호관세 조항을 현행 일반관세로 재사용하지 않는다.

‘합산 하한’은 일반관세에 하한 숫자를 더하는 것이 아니라 `max(기본세율, 하한)`이다. 232 제품에는 해당 강제노동 301 경로를 다시 합산하지 않는다. 현재 정책의 조건부 대안은 소재·원산지 요건 충족이 필요하며 임의의 대통령 결정이나 즉시 적용되는 미래 조치가 아니다. 미국산 소재로 바꿀 때 생기는 조달 원가 변화는 이 관세 비교에 자동 포함되지 않는다.

중국 기존 301·예외, 캐나다/멕시코의 USMCA·미국산 함량·추가 조치, 기타국 합계 및 미검증 조합에는 **자동 세율 없음**으로 처리한다. 검토한 현행 총 세율과 출처가 있어야 계산할 수 있다. ‘별도 추가종가세’ 0%는 미적용 가정이지 검증된 AD/CVD 부재가 아니다. 정책 조합에는 별도 세율을 한 번 더하며 직접 입력한 총 세율에는 다시 더하지 않는다. 종량세·기업 세율·쿼터를 임의로 합산하지 않는다.

## 공급국·탄력성 자료

`suppliers-2025.mjs`는 7개 HS6의 2025년 **Imports for Consumption / Customs Value / USD**를 국가별로 조회한 공개 집계다. 로컬 비공개 DataWeb 인증을 사용한 제한적 읽기이며 조회 결과의 기관 집계만 커밋했다. 키·요청 헤더·계정 ID·원시 인증 응답은 포함하지 않는다. 국가를 분리한 상세 행만 정렬하고 합계 행과 섞지 않았다. 상위 8개국은 시장 규모나 제조지 순위가 아닌 미국 수입 통관가액 순위다.

재현: DataWeb에서 HTS6=850423/854460/853521/854232/870323/401110/590220, 연도=2025, 소비용 수입 통관가액, 국가=All/Break Out Countries, HTS6별 상세 조회 후 국가 금액 내림차순. 세부 대표 HTS의 시장 점유율로 자동 사용하지 않는다.

| 폴리에스터 타이어코드 | 3.5 | −1 (가정) | [USITC 연구진 (2004), 표 1 p.15, BEA 170700](https://www.usitc.gov/publications/332/ec200401a.pdf#page=16). 과거 Tire cord and fabrics 산업 모형값. 폴리에스터 단독·현재 실측값 아님 |
| 전력 케이블·직접 정의 | 4 (가정) | −1 (가정) | 대표 사양에 적합한 값 미확보. 다른 소재·품목의 탄력성을 임의 전용하지 않음 |

변압기·타이어 문헌은 미국산·수입산 간 대체를 다루므로 모든 외국 간 대체에 동일 σ를 적용하는 것은 이 비중첩 모형의 근사다. 연구 범위·연도가 다른 매개변수를 결합한 조건부 보정이며, 검증된 현재 산업 전망은 아니다. 반도체 연구의 공급능력 제약·2단계 충격이나 자동차 중고차시장 피드백은 재현하지 않는다. 공급탄력성 1.5/3은 학습용 가정으로 유지한다.

문헌 범위가 있는 σ에는 변압기 2/3.5/5, 타이어 3/4.5/6 민감도를 제공한다. 자동차 σ의 통계적 신뢰구간을 발생 시나리오 범위로 자동 변환하지 않는다. η 범위는 출처 안내·JSON에 남기며 현재 민감도 패널은 σ만 변경한다.

품목 선택 시 해당 시작값을 자동 적용한다. σ 또는 η를 직접 편집하면 **그 매개변수만** 사용자 가정으로 전환하며 다른 값의 출처를 보존한다. ‘문헌 기본값 적용’은 확보된 매개변수만 되돌린다. JSON의 `calibration.elasticity.sigma`/`eta`는 각각 값·근거 유형·원문·연도·적용 범위·문헌 범위를 보관한다. 미확보·수정된 값에는 문헌 출처를 부여하지 않는다. 2004년 값은 UI에서도 과거 산업 대용값으로 표시한다.

σ는 **공급국 간 상대가격 변화에 따른 구매 전환**을 나타낸다. η는 **미국 해당 품목시장 전체의 가격지수 변화에 따른 총수요 반응**이다. η=-1이면 작은 가격지수 1% 상승에 총수요가 약 1% 감소하는 가정이다. σ와 η는 품목·시장·기간에 따라 달라지므로 산업 전체에 통용되는 보편 상수가 아니다. 이 구분의 모형 근거는 [Riker & Schreiber (2020), §2.1](https://www.usitc.gov/sites/default/files/data/gravity/structural_equations_for_pe_models_in_group_1.pdf)이다.

화면은 σ와 η의 적용 근거를 각각 표시한다. 메모리는 σ만 문헌 근사값이며 η=-1에는 실측 근거가 없다. 타이어의 4.5/-0.375는 기관이 공표한 단일 확정값이 아니라 보고서 범위에서 시뮬레이터가 선택한 중간값이다. 문헌 없는 품목과 사용자가 바꾼 값은 사용자 가정으로 표시하며, 연구 원문 링크를 현재 입력값의 실측 근거로 오인하지 않도록 구분한다.

## 모형과 계산

[USITC CES Tariff Model](https://www.usitc.gov/ces_tariff_model) 및
[Riker & Schreiber (2020), §2.1](https://www.usitc.gov/sites/default/files/data/gravity/structural_equations_for_pe_models_in_group_1.pdf)의
비중첩 CES 수요·일정 탄력성 공급을 참고했다. 원래 세 공급원 구조를 최대 8개로 일반화했다.
완전경쟁을 가정한다. 공식 USITC 전망이나 Excel 실행기가 아니다.

초기 관세 포함 구매액 비중을 `w_i`, 생산자가격 비율을 `r_pi`, 관세 인자를 `τ_i = 1+t_i`로 정의한다.
초기 구매가격을 공급국별 1로 정규화하고, 의미가 있는 가격·수량 비율만 비교한다.

```text
r_ci = r_pi × τ_i_after / τ_i_before
P = (Σ w_i × r_ci^(1−σ))^(1/(1−σ))
r_qi = P^(η+σ) × r_ci^(−σ)
공급 균형: r_pi^ε_i = r_qi
```

σ=1은 Cobb-Douglas 극한을 사용한다. 로그 공간에서 20단계 관세 경로와 감쇠 Newton 방법으로
수요·공급 균형을 직접 계산한다. 미수렴·특이 행렬·비유한 결과는 오류로 처리한다.
관세수입은 **관세 제외 매출 × 관세율**이다. 관세 포함 금액에 다시 세율을 곱하지 않는다.

국내 생산이 없는 시장은 USA 행을 제거할 수 있다. 없는 국내 산업이 관세 때문에 새로 생기는 효과는 계산하지 않는다.
환율·보복관세·다른 시장으로의 재판매·생산능력 한도·공급망·신규 진입·GDP·고용·기업별 마진은 범위 밖이다.
