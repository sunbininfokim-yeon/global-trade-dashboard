## 관계·효력 보강

- 관계 3건: 6/2026 → 17/2025 일부 개정, 17/2025 → 10/2023 및 15/2024 폐지.
- 효력 8건: 두 문서 시행, 기본령 개정, 종전 RKAB 두 규정 전체 폐지, 25/2018·7/2020의 열거된 조문만 일부 폐지, 제35조 경과조치.
- 기본령 제35조의 조건부 2026-03-31 사용 기한을 법령 전체 종료일로 사용하지 않는다. 과거 2025년 신청·기존 승인·재조정 조건을 따로 보존했다.
- 17/2025 상태는 `amended`, 6/2026은 시행 근거가 있으나 전체 현행성은 검토 필요다. 원본 `legal_status`는 모두 `unverified`로 유지한다.

## 한국어 검색과 재실행 평가

RKAB·DMO·HPB·HBA·석탄혼합·복구보증금·광구중복·행정제재의 별칭을 추가했다. HBA와 HPB를 같은 개념으로 묶지 않았고 석탄 혼합과 바이오연료 혼합을 구분한다. 기존 단순·다중 키워드 검색 구조는 유지한다.

| AND 질의 | 확인 시점 전체 건수 | 포함되어야 할 문서 |
|---|---:|---|
| 석탄, RKAB, 복구보증금 | 5 | 17/2025 |
| 석탄, 석탄혼합 | 1 | 6/2026 |
| 석탄, 국내공급의무 | 7 | PP 96/2021 |
| 석탄, 기준가격 | 5 | PP 96/2021 |
| 석탄, 광구중복 | 6 | PP 39/2025 |
| 석탄, 광산복구, 복구보증금 | 9 | PP 78/2010 |

건수는 이후 수집에 따라 변할 수 있다. 재실행 가능한 평가기는 전체 건수 고정 대신 예상 문서·모든 검색 조건 일치·검토 조문 연결·실제 키워드 응답 방식을 검사한다. 문서 전체의 조건 일치와 각 발췌의 조건 일치 수는 다를 수 있다.

```sh
node scripts/indonesia_policy/evaluate-search.mjs scripts/indonesia_policy/search-evaluation-coal-20261020.json --env-file /ABS/ENV
```

실제 DB 평가 6개 통과. 수집·목록 Python 31개, 기존 Node 계약 17개 및 신규 평가기 검사 1개, 소유권 규칙 검사 14개 통과. 스키마 변경이 없으며 migration 전체 재실행·배포 화면 검사는 하지 않았다.

## 남은 범위와 보관

PMK 26/2020 OCR, 대기 임베딩, DMO 하위 원문과 최신 가격 산식, 지방 허가·개별 광구 실사, 원 부처 전체 목록 연결은 별도다. 이번 검토로 모든 법규가 수집됐거나 현재 사업 리스크가 전부 판정된 것은 아니다.

원본과 검토 자료는 비공개 `policy-downloads/indonesia-20261020/coal-operations-{texts,amendment,review}/`에 있다. 디스크 부족으로 첫 수집의 두 번째 PDF 저장·마지막 체크포인트 갱신이 실패했다. 첫 성공 파일만 DB에 저장한 뒤 누락된 한 건을 새 실행 경로에서 재수집·검증했다. 이미 완료한 수집을 임의로 처음부터 재실행하지 않았다. 임시 원본 중복은 동일 SHA-256 원본을 보존하는 방식으로만 정리했다.

DB 데이터는 반영 완료. 한국어 별칭과 평가 코드의 사이트 적용에는 PR 병합·Claude 배포가 필요하다. 미국 자료·공유 UI·Worker·워크플로·메일·반복 예약은 변경하지 않았다.
