# 반덤핑 예치 부담 시뮬레이터

2026-10-11 · PR #528 후속 · 로컬 통합 화면에서 검증. 병합·운영 배포 전.

경로: 정책 → 미국 → 관세 시뮬레이터 → **반덤핑**.
로컬: http://127.0.0.1:8773/policy/us/simulator

[데스크톱 검증 화면](previews/antidumping-desktop.png) · [360px 화면](previews/antidumping-mobile.png). 거래가격·가정 예치율·금리·기간은 검증용 입력이며 실제 기업 거래가 아닙니다.

## 사용할 수 있는 기능

- 등록된 사건·정확한 법인·통관일로 선별 최종 공고의 AD 예치 참고율 조회.
- 실제 공표 이력에서 예비/최종, POR, 예치 발효일, 개별조사/비선정 구분.
- 해당 거래의 수입 신고가격과 비교할 예치율, 금리·일수를 입력해 예치금과 단리 금융비용 비교.
- 다른 사건은 사건번호·법인명·직접 확인한 예치율·HTTPS 출처·적용 조건을 기록해 계산.
- 비선정 기업 산정 경로 교육용 비교. 유효한 마진이 모두 제외되면 다른 합리적 방법 필요로 표시. 복수 마진의 가중치는 입력하거나 명시적으로 동일 가중을 가정.
- 결과 JSON에 확인/공표 근거와 사용자 거래·시나리오를 분리 저장. 입력 변경 시 이전 결과를 흐리게 표시하고 저장을 막음.

[2026-20160](https://www.govinfo.gov/content/pkg/FR-2026-10-01/html/2026-20160.htm)의 변압기 재심 개시(POR 2025-08-01~2026-07-31)는 새 예치율이나 조사기업 선정으로 처리하지 않는다. 확정 종료일을 가정하지 않는다. 최신 후속 공고 전체를 자동 수집하는 기능은 이번 화면에 연결되지 않았다.

## 산식과 산정 경로의 한계

예치액 = 해당 거래의 신고가격 × AD 예치율 / 100.
금융비용 = 예치액 × 연 금융비용률 / 100 × 일수 / 365.

소수점 6자리 입력과 BigInt 유리수 연산을 사용하고 마지막 USD 센트에서 반올림한다. 예: 신고가격 100만 USD, 참고율 4.32%, 비교 16.87%, 연 5%, 180일이면 예치금 43,200 → 168,700 USD, 차이 125,500 USD. 금융비용은 1,065.21 → 4,159.73 USD. **거래가격·비교율·금리·일수는 예시 가정**이며 해당 기업의 실제 수입 실적이 아니다.

비선정 산정은 시장경제 국가의 행정재심 교육용 경로다. 0%·0.5% 미만·전적으로 가용정보에 의존한 마진을 제외한다. 유효 마진이 하나면 그 값을 반영한다. 여러 개면 가중치 없이 실제 결과를 재구성하지 않는다. 모두 제외되면 0% 대신 다른 합리적 방법이 필요하다고 표시한다. 2026-16663이 실제 반례다. 2026-14027은 19 CFR 351.109(f)·(g)와 §735(c)(5)를 설명한다. 신규 조사·비시장경제 별도율·CVD를 이 함수로 계산하지 않는다.

LS전선과 LS일렉트릭, 효성중공업과 HS효성첨단소재는 각각 별도 법인이다. 미등록 기업에 22%/21.74% all-others 또는 계열사 세율을 자동 적용하지 않는다. 소송 접수나 재심 개시만으로 기존 예치금을 없애지 않는다.

실제 덤핑마진, 수입자별 사후 확정액·환급, 일반/추가 관세·CVD·수수료, 환율, 미래 재심 결과·법원 판단은 계산하지 않는다. 이를 위해서는 거래별 EP/CEP·정상가격·각종 조정과 결정문·CBP 지침 등 추가 자료가 필요하다.

## 코드·검증

- `New for anti/policy-simulator/antidumping-catalog.mjs`: 공개 공식 공고만 선별한 자료. 원문 PDF·비공개 캐시·키는 포함하지 않음.
- `antidumping-model.mjs`: 참고율 조회·예치/금융비용·비선정 산정의 순수 함수.
- `antidumping-view.mjs`: 공식 이력·직접 입력·확인·오류 이동·JSON 저장·기업 연결.
- `company-profiles.mjs`: 실제 기업 6개사 공식 재무 참고, 제품별 비공개 입력은 null.
- 단위 검증: `node --test scripts/lib/antidumping-model.test.mjs`.
- 브라우저: `PLAYWRIGHT_MODULE=... node scripts/trade_policy/test_antidumping_browser.cjs`.

범용화한 것은 사건번호/기업/공고/기간 구조와 직접 확인 예치율의 계산 경로다. 공식 사례가 전 세계 모든 기업으로 확대된 것은 아니다. 다음 수집 단계는 공고 발견 → 사건·제품 범위·법인 검증 → 예비/최종·예치 발효 조건 구조화 → 검증 후 자료 반영이다. LLM 추출 결과만으로 적용 예치율을 승격하지 않는다.
