### 강관 비선정 21개사와 재심 철회

[2026-08489](https://www.govinfo.gov/content/pkg/FR-2026-05-01/html/2026-08489.htm)의 Appendix II에 기재된 21개사를 전부 포함한다. POR 2023-05-01~2024-04-30의 **최종 배정 마진은 모두 0.80%**다. 이 공고의 Cash Deposit Requirements는 현대스틸파이프·세아의 조건을 명시하므로, 나머지 법인의 미래 통관 예치율을 별도 검증 없이 0.80%로 자동 계산하지 않는다. `margin_pct`는 보존하고 `deposit_rate_pct:null`·근거·POR를 표시한다. 과거 마진 이력과 예치액 계산 가능 여부를 분리한다.

[2026-15399](https://www.govinfo.gov/content/pkg/FR-2026-07-30/html/2026-15399.htm)의 다음 POR 2024-05-01~2025-04-30은 다음처럼 구분한다.

- 개별조사: 현대스틸파이프·세아 예비 0%. 기존 최종 예치 참고율을 바꾸지 않는다.
- 비선정 6개사: Chang Won Bending, Dong Yang Steel Pipe, EEW Korea, HiSteel, Hyundai RB, Nexteel. 예비 배정 0.80%. 개별조사 선정 불을 켜지 않는다.
- 다른 15개사: 해당 POR의 재심 대상 거래가 없어 재심 철회. 별도 상태로 표시하며 예비·최종·CBP 정산 완료나 0%로 처리하지 않는다. 반덤핑 명령 폐지를 뜻하지 않는다.

POSCO/PIC는 해당 열연 재심에서 단일 취급된 그룹이다. POSCO International을 독립 제조기업으로 추정하거나 다른 POSCO 계열사 전체를 자동 포함하지 않는다. Hyundai RB·Hyundai Steel Pipe·Hyundai Steel도 서로 다른 이름 그대로 보존한다.

## 사용할 수 있는 기능

- 등록된 사건·정확한 법인·통관일로 선별 최종 공고의 AD 예치 참고율 조회.
- 실제 공표 이력에서 예비/최종, POR, 예치 발효일, 개별조사/비선정 구분.
- 해당 거래의 수입 신고가격과 비교할 예치율, 금리·일수를 입력해 예치금과 단리 금융비용 비교.
- 다른 사건은 사건번호·법인명·직접 확인한 예치율·HTTPS 출처·적용 조건을 기록해 계산.
- 비선정 기업 산정 경로 교육용 비교. 유효한 마진이 모두 제외되면 다른 합리적 방법 필요로 표시. 복수 마진의 가중치는 입력하거나 명시적으로 동일 가중을 가정.
- 결과 JSON에 확인/공표 근거와 사용자 거래·시나리오를 분리 저장. 입력 변경 시 이전 결과를 흐리게 표시하고 저장을 막음.
- 변압기·타이어의 편집 가능한 예시 입력, 변경한 값의 보존, 기간 90/365/730일 전환. 수동 확인율은 임의로 채우지 않음.
- 재심 대상 기간별 공식 근거에 따른 단계 표시, 각 단계의 기관·행위·날짜·출처 펼침. 신규 조사 및 선택적 소송/환송/항소 경로 별도 안내.
- 단계 영역 상단의 **산업 → 기업** 버튼: 변압기 4개사(HD현대·일진·LS·효성), 타이어 3개사(한국·넥센·금호). 선택 기업·공표 참고율을 즉시 표시하며 하단 사건/기업 입력과 양방향 연동. 산업 변경 시 해당 사건의 기업과 POR만 표시하고, 직접 수정값은 보존하며 이전 계산의 저장과 확인란을 해제. 선택된 기업을 다시 누르는 경우 결과를 유지. 미확인 법인·통관일은 0%로 표시하지 않음.

금액·금리·기간을 공개 공고만으로 업종별 보편값이라고 정할 수 없으므로 임의의 숫자를 실제 평균처럼 소개하지 않는다. 실제 거래 자료가 생기면 대체한다. 품목/기업을 바꾸면 **아직 수정하지 않은 예시만** 새 품목/법인에 맞춰 갱신한다. 이미 직접 입력한 금액·비교율·금리·기간은 보존한다. ‘이 품목의 예시값 채우기’는 명시적으로 예시와 자료 확인일을 다시 불러오고 범위/법인 확인을 해제한다. 회사·제품·통관일의 변경도 확인란을 해제한다.

누락·미등록 법인·확인일 이후의 공표 기준율을 0%로 채우거나 다른 기업의 실제 세율을 빌려 쓰지 않는다. 비교 예시도 그 경우 공란이다. JSON `input_guidance`에 입력별 `editable_example`/`user_input`, 값, 해석을 기록한다. 세율 출처는 별도 `reference`에 남는다.

## 결정 기관과 단계 표시

신규 조사에서 [상무부는 덤핑과 마진, USITC는 미국 산업피해를 별도로 판단](https://www.usitc.gov/press_room/usad.htm)한다. 명령 이후의 특정 POR 행정재심은 상무부가 진행한다. [CBP는 상무부 지침과 적용되는 법원 명령에 따라 수입 건의 관세를 확정·정산](https://www.ecfr.gov/current/title-19/section-351.212)한다. 예치금 자체가 최종 세금은 아니며 추가 납부/환급이 생길 수 있다.

- 신규 조사 안내: 신청·개시 → USITC 피해 예비 → 상무부 덤핑 예비 → 상무부 덤핑 최종 → USITC 피해 최종 → 명령. 상무부 예비 부정 판정만으로 조사가 끝났다고 표시하지 않는다.
- 실제 재심 표시: 개시 → 조사기업 선정/자료 검토 → 예비결과 → 의견/반박 제출·검토 → 최종결과 → CBP 개별 수입 정산. 향후 수입의 새 예치율 발효는 과거 POR 정산과 별도 표시한다.
- 소송 안내: CIT 제소·필요시 liquidation 금지명령 → CIT 기록심사/판결 → 필요시 상무부 환송 재결정과 CIT 재심사 → 선택적 Federal Circuit 항소 → 선택적 대법원 certiorari. 재심과 소송은 병행될 수 있다. 소송 접수만으로 예치 의무나 liquidation이 자동 중단된다고 표시하지 않는다.

[19 U.S.C. §1516a](https://www.cit.uscourts.gov/sites/cit/files/19U.S.C.1516a.pdf), [CIT Rule 56.2](https://www.cit.uscourts.gov/sites/cit/files/Rule%2056.2.pdf), [28 U.S.C. §1295(a)(5) · 2024 법전](https://www.govinfo.gov/content/pkg/USCODE-2024-title28/pdf/USCODE-2024-title28-partIV-chap83-sec1295.pdf), [2026 대법원 규칙 Rule 10](https://www.supremecourt.gov/filingandrules/2026RulesoftheCourt_WEB.pdf)을 근거로 설명한다. 행정재심 최종결과 등의 §1516a(a)(2) 통상 제소 경로는 공표 후 30일 내 summons, 그 후 30일 내 complaint이지만 결정 유형·적격·예외가 있고 이 화면은 기한 계산기가 아니다. 법정 예정일로 실제 단계나 반환일을 만들어내지 않는다.

**초록 = 공식 근거 확인, 파랑 = 이 기간의 수록 최신 근거, 회색 = 미확인.** 후단계가 확인돼도 미수록 앞단계는 임의로 초록색으로 바꾸지 않는다. 법원 사건이 미수록된 것은 소송이 없다는 뜻이 아니다. 자동 법원/CBP 감시나 실제 정산 완료 확인은 아직 연결하지 않았다.

단계는 사건번호·POR·공식 행위를 함께 묶는다. 이전 POR의 최종결과가 새 POR의 최종결과가 되지 않는다. 조회 기간을 바꿔도 통관일로 조회한 계산 참고율은 바뀌지 않는다. 모든 후속 변경을 확인한 실시간 사건 원장이 아니며 기업별 취소·법원 명령·정정 등 추가 확인이 필요하다.

## 산식과 산정 경로의 한계

예치액 = 해당 거래의 신고가격 × AD 예치율 / 100.
금융비용 = 예치액 × 연 금융비용률 / 100 × 일수 / 365.

소수점 6자리 입력과 BigInt 유리수 연산을 사용하고 마지막 USD 센트에서 반올림한다. 예: 신고가격 100만 USD, 참고율 4.32%, 비교 16.87%, 연 5%, 180일이면 예치금 43,200 → 168,700 USD, 차이 125,500 USD. 금융비용은 1,065.21 → 4,159.73 USD. **거래가격·비교율·금리·일수는 예시 가정**이며 해당 기업의 실제 수입 실적이 아니다.

비선정 산정은 시장경제 국가의 행정재심 교육용 경로다. 0%·0.5% 미만·전적으로 가용정보에 의존한 마진을 통상 가중평균에서 제외한다. 유효 마진이 하나면 그 값을 반영한다. 여러 개면 가중치 없이 실제 결과를 재구성하지 않는다. 모두 제외되면 기대방법을 포함한 합리적 산정과 이탈 근거 검토가 필요하다. 0%가 법적으로 불가능하다는 뜻이 아니며 이 교육용 계산에서 0%나 양의 세율을 자동 확정하지 않는다. 2026-16663은 조사기업 0%가 비선정 0%로 자동 이어지지 않은 사례다. 2026-14027은 19 CFR 351.109(f)·(g)와 §735(c)(5)를 설명한다. 신규 조사·비시장경제 별도율·CVD를 이 함수로 계산하지 않는다.

LS전선과 LS일렉트릭, 효성중공업과 HS효성첨단소재는 각각 별도 법인이다. 미등록 기업에 22%/21.74% all-others 또는 계열사 세율을 자동 적용하지 않는다. 소송 접수나 재심 개시만으로 기존 예치금을 없애지 않는다.

실제 덤핑마진, 수입자별 사후 확정액·환급, 일반/추가 관세·CVD·수수료, 환율, 미래 재심 결과·법원 판단은 계산하지 않는다. 이를 위해서는 거래별 EP/CEP·정상가격·각종 조정과 결정문·CBP 지침 등 추가 자료가 필요하다.
