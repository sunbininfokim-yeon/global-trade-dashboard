## 검색

번호 검색은 기존 정확 조회를 유지한다. 일반 질의는 네 문서 종류에서 제목·요약을 조회한 결과와 Gemini 의미 검색을 합친다. 제목 완전 일치 및 CRS 요약 첫 굵은 제목의 공식 약칭이 먼저 나오며, 단어 경계로 STABLEGENIUS 같은 부분 문자열 오탐을 제한한다. 약칭은 특정 법안 ID에 하드코딩하지 않는다. 한국어 주제는 검증 가능한 별칭 사전을 사용하며 암호화폐 관련 영어 표현을 추가했다.

임베딩 장애가 있어도 직접 찾은 문서는 반환한다. 상류 장애와 실제 검색 결과 없음은 구분한다. 캐시 키는 v5로 변경했다. 법안/법률/행정명령/규정 네 라인은 유지하며 각 라인에서 연관도 또는 날짜로 정렬한다. 여러 조건의 충족 개수는 카드 안에 표시한다. 의미 유사도는 모든 조건을 충족했다는 근거로 쓰지 않는다.

각 제목/요약 후보 조회는 최대 60건이며 API 결과 제한은 기본 20건이다. `candidate_limited` 및 `result_limited`로 제한 여부를 알린다. 임베딩 존재와 검색 품질·전체 법안 수집 완료는 별개다.

일반 discovery 커서가 밀려 있어도 즐겨찾기 법안을 공식 API에서 별도로 확인한다. 새 업데이트와 이미 대기 중인 즐겨찾기는 priority 100으로 먼저 처리한다. 완료/처리 중인 항목은 우선순위만으로 재수집하지 않는다. 임베딩도 제목·요약 변경이 있는 경우에만 기존 정책에 따라 갱신한다.

Index 등급도 최신 조치 한 건과 이력을 저장한다. 법안 upsert 후 이력 기록 전에 중단돼도 다음 실행에서 idempotent 이력 삽입으로 복구한다. 같은 날 다른 조치 문구도 분리된다. Mac에서 설정한 `PRUNE_TERMINAL_BILLS=false`를 실제로 준수하도록 수정했다.
