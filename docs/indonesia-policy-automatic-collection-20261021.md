# 인도네시아 자동 수집과 지방 구독의 전국 적용 범위

## 지방을 선택한 구독

상품 조건과 적용 지역 조건을 함께 검사한다. 특정 주를 선택해도 검토된 전국 적용 중앙정부 법률·규정은 포함한다. 중앙정부가 발행했다는 이유만으로 전국 적용으로 추정하지 않는다. 다른 주로 적용이 한정된 중앙 규정은 제외한다. 전국 구독은 선택 상품의 모든 검토된 적용 지역을 포함한다.

메일 SQL 회귀검사에서 석탄/Aceh와 팜유/Banten 구독에 공통 전국 법률이 각각 매칭되고, Aceh 한정 중앙 규정은 Banten에 매칭되지 않는 것을 확인했다. 실제 발송은 IDN 게이트와 원문·상품·적용 지역 검토를 모두 통과해야 한다.

## 자동 수집

Mac 전용 `com.chokemonitor.indonesia-policy` LaunchAgent가 4시간마다 한 배치를 실행한다. 미국 수집 작업과 GitHub 워크플로는 변경하지 않는다. Mac이 꺼져 있거나 잠들어 있으면 정시 실행을 보장하지 않는다. 실행 중 caffeinate가 유휴 잠자기를 방지한다.

실행 순서:
1. 검토된 103개 출처 중 최대 20개를 순환 갱신한다.
2. 검증된 공식 목록 어댑터 6개에서 첫 페이지/전체 단일 표의 변경을 저장한다.
3. 신규·변경 후보 최대 5개에서 공식 원문과 자체 법령 제목·종류·번호·연도·발행기관을 대조한다.
4. 완전한 원문만 DB 문서/버전·출처 점검·처리 결과를 같은 트랜잭션으로 저장한다.

목록 범위는 Jateng ESDM, Sulbar 중앙 PP 재게시, DJBC의 무역·산업·재무부 카테고리, 무역부 원 목록이다. 페이지형은 첫 페이지 감시이므로 전체 과거 목록 수집 완료를 뜻하지 않는다. Sulbar 재게시 중앙 PP를 지방 조례로 분류하지 않는다. 미검증 원 부처 4곳은 자동 요청하지 않고 미지원 목록에 남긴다.

자동 생성 문서는 법적 효력이 `unverified`다. 상품 태그는 검색 관련성이고 적용 지역의 법적 판정이 아니다. 문서 제목은 원문임을 표시하며 유료 AI 번역·임베딩·메일 전송을 호출하지 않는다. 새로 확보한 과거 문서를 새로 제정된 법으로 취급하지 않는다. 불완전 원문·초안·식별 불일치·복수 매칭·지원하지 않는 문서 번호는 보류한다.

## 운영 파일

- 실행기: `scripts/indonesia_policy/scheduled_sync.py`
- 재설치 도구: `scripts/indonesia_policy/install_mac_scheduler.py` (기존 plist가 있으면 덮어쓰지 않음)
- 상태·원문: `/Users/yeoninair/Documents/policy-downloads/indonesia-automatic`
- 정상 설치 로그: `~/Library/Logs/chokemonitor-indonesia/runner.log`, `runner.err.log`
- 초기 검증 실행 로그: `/private/tmp/chokemonitor-idn-launchd.out`, `.err`
- 중단: 상태 폴더에 `STOP` 파일을 생성한다. 자동으로 삭제하지 않는다.

체크포인트는 DB 확인 응답 뒤에만 전진한다. DB 실패 재개 시 저장된 원문을 재사용한다. 로컬 파일 잠금과 DB lease를 함께 사용하고 만료된 lease의 쓰기는 거부한다. 403/429는 해당 호스트를 24시간 쉬고 기타 요청 실패는 최소 1시간 쉬며 기존 차단 상태를 가져온다. 상태/원문이 1 GiB를 넘으면 자동 삭제하지 않고 중단한다.

`20261021043352_indonesia_automatic_ingestion.sql`을 운영에 적용했다. SQL MD5는 `721c3f4e40cfd39f564a3840eeb14b10`이다. 추가된 수집 결과 테이블과 RPC는 서비스 전용이고 미국 문서·즐겨찾기와 분리한다.

## 배포 경계

운영 DB와 Mac 작업은 별도다. PR의 UI 및 메일 Worker 배포는 Claude 담당이고 IDN 메일 발송 게이트는 계속 꺼져 있다. 자동 수집이 성공해도 원문·상품·적용 지역 검토와 발송 게이트 활성화가 없으면 메일은 가지 않는다.
