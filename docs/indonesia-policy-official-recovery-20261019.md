# 인도네시아 공식 출처 복구·산업 규정 후속

2026-10-19. PR #613 후속. 운영 IDN DB 저장과 개요 임베딩은 적용했으며, 검색 사전은 작업 브랜치에 구현했다. 병합·사이트 배포는 Claude 인수 대상이다.

이번 수집은 8회 시도 중 원문 1건 확보·7건 실패다. 실패 횟수와 고유 미수집 후보 수는 다르다. 실패도 `source_checks`에 보존했다. 동일 수집 결과를 재적용했을 때 새 버전은 0건이며 출처 확인 수도 증가하지 않았다. 현행 효력은 모두 `unverified`를 유지한다.

## 실제 추가한 규정과 검색 범위

**Permenperin 35/2025**: 국산화율 TKDN·기업기여도 BMP의 계산·검증·인증 규정. 산업부가 게시한 [최종 PDF](https://ikm.kemenperin.go.id/storage/peraturan/revisi-baru-16-april/permenperin-nomor-35-tahun-2025-ketentuan-dan-tata-cara-sertifikasi-tkdn-dan-bmp.pdf)를 수집했다. 124페이지, 추출 본문 175,679자이며 잘림 없다.

Pasal52는 TKDN/BMP 계산·검증 비용의 인증 지원을 둘 수 있도록 하고, Pasal54는 지원 절차를 별도로 정하도록 한다. 이는 광산 전체에 대한 현금 보조금이나 개별 기업의 수급권 확정이 아니다. 중·하류 제조·산업서비스 사업자의 제품, 조달, 자격, 후속 규정 검토 대상으로 분류했다. 품목 태그는 검토 관련성이다.

한국어 `국산화율`, `현지조달`, 영문 `local content`, 인도네시아어 `tingkat komponen dalam negeri`, `TKDN`을 연결했다. `기업기여도/BMP`도 별도 연결했다. 국산화율 동의어에 일반 보조금을 넣지 않아 서로 다른 질문을 무조건 일치시키지 않는다.

**Permenperin 13/2025**: 산업·산업단지 정보 SIINas 보고 규정은 공식 [산업부 목록](https://ilmate.kemenperin.go.id/pelayanan-publik/peraturan/138bb0696595b338afbab333c555292a?type=repository)과 PDF 주소를 검토 목록에 추가했다. 다운로드 시간 초과로 문서 본체는 미저장이다. `산업정보 보고/산업보고/SIINas` 검색어만 준비했으며, 검색 사전 추가를 원문 확보나 임베딩 완료로 계산하지 않았다. 광업 RKAB 보고와 같은 제도로 합치지 않았다.

## 검증과 저장 위치

- 운영 API: `니켈, 국산화율` + 중류 + 모든 조건 일치에서 새 규정이 2/2로 검색된다(총 3건). 상류 필터에서는 새 규정이 제외된다(다른 결과 2건). `팜유, 국산화율` + 하류는 새 규정 1건이 2/2로 검색된다.
- 상세 API의 원문에 Pasal52가 있으며 일부 수집 표시가 없다. 운영 DB에서 문서 64개·유효 벡터 64개·임베딩 대기 0개를 확인했다.
- Gemini는 새 문서 개요 1개, 입력 3,817자만 생성했다. 전체 175,679자 법령/조문 임베딩이나 자동 번역은 아니다. 실제 청구 토큰·원화 금액은 측정하지 않았다.
- API 검사 5개·임베딩 검사 2개·소유권 검사 14개 통과. 동의어, 무료 키워드 경로, IDN RPC 격리, 필터 검증과 오류 구분을 포함한다. 이번 변경에는 운영 DDL·공유 Worker·UI·스케줄·메일 변경이 없다.
- 수집 원본: 저장소 밖 `policy-downloads/indonesia-20261019/official-recovery-2/` 및 `industry-compliance/`. 검토 설명만 보정한 import는 `industry-compliance-reviewed/collection.json`이며 원래 수집 파일·해시·관측 시각은 보존했다. 벡터는 기존 비공개 `embedding-cache/`를 사용했다.
- 재현 목록: `sources-official-recovery-20261019.json`, `sources-industry-compliance-20261019.json`. 성공 규정과 미확보 SIINas 후보 2건은 기본 `sources.json`에도 추가했다. 실패한 복구 주소를 기본 목록의 정상 주소로 일괄 교체하지 않았다.

다음 우선순위는 ISPO 세 사업단계의 시행규정, 광물별 로열티 부속서, RKAB 기본령·개정·기술 결정, 핵심/전략광물 지정 원문의 회복이다. 현재 자료로 전국 규제·지방 허가·보조금 자격을 전수 확인했다고 볼 수 없다.
