2026-10-19 확인. 기존 2026-10-18 수집 범위 보고서는 당시 스냅샷이다. 이번 문서는 추가 수집과 검색 계약 변경을 기록한다. 전국 전수 수집이나 개별 사업의 규제 적용 판단이 아니다.

## 수집 범위를 넓힌 기준

실제 저장은 기존 37문서에서 57문서로 늘었다. 중앙 44·주 12·군 1문서다. 최신 원문·부속서 38문서(본문 길이 제한으로 일부만 저장한 2문서 포함), 공식 메타데이터만 19문서, 내용 버전 62개다. 27개 신규 후보 중 20문서를 확보했고 7개는 미저장 상태다. 원문 접근 복구·메타데이터 갱신을 포함해 6회 실행/43번 확인했으므로 실행 건수와 고유 법규 수를 혼동하면 안 된다.

전체 출처 이력 97개는 성공 관측 61·실패 관측 36이다. 과거 실패 후 다른 공식 출처로 확보한 사례가 포함되며, 전체 미저장 후보는 23개다. IDN 테이블·인덱스는 이번 측정 시점 1,384,448바이트(1,352KiB)다. 이 수치는 Supabase 전체 프로젝트 사용량이 아니다.

품목 이름이 문서 제목에 있는 수출·광업 규정 외에도 사업에 적용될 수 있는 공통 제도를 포함한다. 품목 태그는 검토 범위이며 개별 사업의 법적 적용성 확정값이 아니다.

## 중앙·지방은 발행기관 기준

- `발행정부 → 중앙정부만`: 중앙정부 문서만. 지방 문서는 제외하며 지방 발행지역 필터를 숨긴다.
- `지방정부 전체`: 주·군·시 문서만. 중앙 문서는 제외한다.
- 주/군/시를 고르면 해당 등급의 자료만 표시한다. 지역 목록도 선택한 등급·품목에서 실제 저장된 지방 발행지역으로 제한한다.
- 지방 발행지역을 선택하면 해당 지역의 지방 문서만 남는다. 중앙 규정의 실제 지역 적용성 판정과 다르다. 중앙 공통 규정을 같이 보려면 지역 전체·중앙/지방 전체 또는 중앙정부만을 별도로 조회한다.
- 검색창에 `중앙`이라고 입력하는 것은 키워드 검색이다. 발행기관 제한은 발행정부 필터로 선택한다.
- 중앙으로 전환하면 이전 지방 지역 선택을 초기화한다. API가 중앙+지방지역의 모순된 요청을 받으면 오류를 반환한다.

## 공식 원문·PDF

검색 결과와 상세 화면 모두 공식 문서 페이지와 실제 추출한 원문 주소를 제공한다. PDF는 `공식 PDF 열기`, HTML 원문은 `공식 원문 열기`로 구분하며 새 탭에서 연다. HTTPS 정부 도메인만 연결한다. 검증하지 않은 다운로드 후보를 동작하는 PDF로 표시하지 않는다.

본문 추출은 최대 300,000자, PDF 최대 300페이지다. 잘린 텍스트는 결과·상세에 일부 수집을 표시하고 전체 원문 링크를 제공한다. 원문 검증·추출에 실패한 자료는 메타데이터로 남긴다. 연결은 수집 시점에 확인한 공식 주소이며 외부 사이트의 이후 변경·차단까지 보증하지 않는다. 로컬 원본 캐시는 사이트나 Git에 공개하지 않는다.

구 환경부 일부 호스트에서 DNS 실패가 발생했다. 현재 공식 부처 카탈로그와 그 페이지에 명시된 첨부 경로를 확인했다. `window.open`의 문자열 주소만 파싱하며 JavaScript를 실행하지 않는다. 공식 PDF 버튼의 Download/Unduh도 지원하고 추상·요약 문서는 원문으로 대체하지 않는다. PDF 하위 요청이 403/429이면 메타데이터를 보존하고 그 호스트의 나머지 수집을 중단한다.
