# 미국 제재·거래 제한: 4개국 시범

## 별도 PR 범위

2026-10-10 사용자 요청에 따라 러시아·중국·한국·일본의 은행, 산업, 물품·예외 허가, 주요 기업을 별도 구성요소로 연결한다. 한국 발표 목록 #519, 정책 자료 #515/#516 및 로컬 통상·반덤핑 시뮬레이터와 별도 PR이다. main 기반이며 #519 코드를 포함하지 않는다. 배포·DB·메일·임베딩·워크플로는 변경하지 않는다.

첫 모집단은 각국10개 법인, 총40개다. 은행과 에너지·금속·반도체·전자·배터리·자동차·전력기기 등 사용자 관심 업종을 시범 선정했다. **100대 기업 순위가 아니다.** 현재 설정은 `scripts/trade_policy/sanctions_roster.json`이며 순위와 기준연도가 합의되면 확장할 수 있다. 지주회사·상장법인·자회사를 구별한다. CNOOC 모회사와 CNOOC Limited를 같은 법인으로 취급하지 않으며 삼성전자 이름의 부재를 삼성그룹 전체로 확대하지 않는다.

## 법인 대조 결과와 한계

공식 CSL 법인명/별칭과 등록한 이름의 정확 일치(대소문자·구두점 정규화), 주소의 국가코드 대조다. 일반 부분문자열이나 LLM 유사도로 제재를 확정하지 않는다. 주소는 소재지 신호이며 법인 국적을 확정하는 자료가 아니다. 그룹명을 자회사에 전파하지 않는다.

| 국가 | 선정 법인 | CSL 일치 법인 | 입력 이름 정확 일치 없음 |
|---|---:|---:|---:|
| 러시아 |10|8|2|
| 중국 |10|6|4|
| 한국 |10|0|10|
| 일본 |10|0|10|

법인명 일치는 원기관 법적 지정을 새로 확정하는 행위가 아니다. 법인등록번호·소유구조·전체 계열사·모든 별칭은 검증하지 않았으므로 각 결과의 공식 명단 및 ID를 제공한다. `no_exact_match`는 **제재 없음/거래 허용 판정이 아니다.** OFAC 50% 규칙에 따른 비명시 소유회사, 거래별 제한·예외, CSL 밖 DoD/UFLPA 등 명단은 별도 확인 대상이다. 선택한 한국·일본 기업에서 일치가 없다는 사실을 해당 국가 모든 기업이 제재를 받지 않는다는 결론으로 쓰지 않는다.

한 법인이 여러 명단에 있을 수 있어 source+source_id로 구별한다. SDN은 자산동결, SSI는 해당 지침의 부문 제한, NS-CMIC은 특정 증권투자 제한, CAPTA는 환거래 계좌 제한, EL은 개별 수출허가 요건으로 표시한다. 전체 금지로 합치지 않는다. 기간이 명시된 과거 DPL 등의 항목은 종료/미래/해석필요 상태를 보존한다. 날짜가 없는 명단 항목은 임의의 지정일을 만들지 않는다.

## 제한·예외와 국가별 적용

`sanctions_measures.json`의9개 참조 카드를 국가·은행/산업/물품 범주로 연결한다. 한국·일본에는 국가 전체 제재를 만들어 넣지 않고 외국 금융기관의 조건부 위험 및 재수출 검토를 표시한다. 산업별 지정 권한을 산업의 모든 기업에 대한 자동 자산동결로 해석하지 않는다.

GL135는 2026-10-09 발행, `2027-04-07T00:01:00-04:00`까지 해당 러시아산 경유 거래를 허용한다. 러시아 중앙은행·국부펀드·재무부의 미국 금융기관 계좌 차감은 제외한다. `ru-petroleum`과 연결하되 기존 제한을 삭제하거나 모든 러시아 제재를 해제하지 않는다. 만료시각 이상이면 ‘허가 기한 경과·연장 확인 필요’로 바뀐다. 이 표시만으로 새 금지나 연장을 확정하지 않는다.

## 갱신과 검증

이번은 고정 스냅샷이다. 자동 예약·유료 AI·API키가 없다. 화면은 확인일과 검토 범위를 보여주며7일 경과시 최신 명단 재확인 표시를 한다.

재현:

```
python3 scripts/trade_policy/build_sanctions.py --input /tmp/us-sanctions-20261010/consolidated.csv --as-of 2026-10-10
```

새 공식 자료 대조(1회 다운로드):

```
python3 scripts/trade_policy/build_sanctions.py --download --as-of YYYY-MM-DD
```

`--as-of`는 대조한 실제 기준일로 입력해야 한다. `checked_on`은 원기관의 모든 원문 발행일을 뜻하지 않는다. 스냅샷 명단 갱신은 법적 참조 카드의 최신성까지 검증하지 않으므로 참조 카드도 별도로 검토해야 한다. HTTP 실패/크기 초과/컬럼 누락/필수 명단 누락/극소 응답은 기존 결과를 덮어쓰지 않는다. 원기관의 누락까지 완전성을 보증하지는 않는다.

검증: Python5개, JS 신규5개+기존12개 총22개. 50% 소유 계산을 구현했다고 주장하지 않는다. 실제 브라우저에서 러시아 은행/경유 허가, 중국 명단 종류, 한국·일본 비일치 문구와 기업 페이지를 확인한다. 로컬 미리보기는 기존8771과 분리한8772다.
