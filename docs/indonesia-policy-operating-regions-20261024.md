# 지방 산업 구독 보강 (2026-10-24)

## 구독과 발송 구분

운영 확인 시점: IDN 구독 4건, delivery_enabled=false. 구독·검토·outbox 로직은 구현됐으나 실제 자동 발송 활성화와 수신 검증은 미완료다. 미국/RSS 발송 설정을 IDN 활성화 근거로 사용하지 않는다. 발송 게이트는 이번 작업에서 켜지 않았다.

기존 38개 주 선택지에는 동·중부·서칼리만탄, 동남술라웨시, 북수마트라가 이미 있었다. 지역 등록과 해당 지방 법령 확보는 다르다. 초기 지방 DB에는 이 5곳 중 동칼리만탄만 있었다.

## 이번 변경

- 위 5개 주를 주요 지역에 노출하고 수력발전 품목을 검색·Auth RPC·구독 CHECK·수집 단계에 추가한다.
- 동칼리만탄/석탄, 중부칼리만탄/석탄, 서칼리만탄/팜유, 동남술라웨시/니켈, 북수마트라/수력발전의 개별 조합 버튼을 제공한다. 버튼은 단일 topic/region RPC만 사용하여 다른 품목×지역 조합을 자동 생성하지 않는다. 기존 별표의 전체 조합 기능은 유지한다.
- 각 지방 조합에도 상품과 관련 있고 전국 적용으로 검토된 중앙정부 법률·규정 변경은 포함된다. 발행기관이 중앙이라는 이유만으로 전국 적용을 추정하지 않는다.
- 사업장/회사 이름·좌표·사용자 이메일은 공개 설정에 저장하지 않는다. 공개 버튼은 지역/산업만 표현한다. 사업장과 군·시의 매칭도 추정하지 않는다.

## 자동 수집

새 지역 6개 후보는 scheduled_sync의 별도 regional 단계와 regional-reviewed 체크포인트를 사용한다. 기존 103개 curated manifest의 정체성과 reviewed 커서는 변경하지 않는다. 기존 수집 20개 갱신 뒤 지역 후보 6개를 점검하며 같은 DB lease와 호스트 쿨다운·완전 원문 보존을 사용한다. 중앙 catalogue 6개와 admission 단계는 유지한다.

PR #704가 병합되어 workflow collector SHA가 572756c39ae5425a8f7d812246a19be1b224acdd로 고정됐다. 4시간 주기 설정을 유지하며 실제 실행 #40068289209가 성공했다. regional 단계에서 완전 원문 3건 확인, 출처 실패 2건·쿨다운 1건을 보존했고 133,069,471바이트 체크포인트 저장이 완료됐다. 실행 성공은 법령 전수 확보를 의미하지 않는다. UI/메일 Worker 배포는 Claude 담당이며 이 문서의 UI 변경(PR #703)은 별도 병합·배포가 필요하다.

## Claude UI 인수 검증 (#701, 2026-10-24)

- 운영 `/policy/indonesia`에서 기존 실계정 로그인 세션을 사용했다. 새 비밀번호 로그인 과정 자체를 실행한 것은 아니다.
- 기존 활성 조합 4건에 테스트 품목 별표를 추가하자 전국(`__all__`)·기존 선택 주에 2건이 실제 저장됐다. 새로고침 후 6건이 유지됐다.
- 테스트 별표 해제 후 원래 활성 4건과 정확히 일치했다. 테스트 2건은 삭제하지 않고 disabled로 남았다. 사용자 이메일·ID는 이 문서에 남기지 않는다.
- 지역 미선택의 전국 기본 저장, 로그인 전 별표→로그인 창, 품목×지역, 별도 단일 조합 버튼은 로컬 브라우저 회귀로 확인했다. DB 조회는 실제 운영 DB, 테스트 Auth/RPC 쓰기는 모의 구현이다.
- 실제 계정 검증에서도 IDN 발송 게이트 false, IDN outbox 0건을 확인했다. 원자재/미국 메일 설정과 구형 발송기는 변경하지 않았다.
- 새 지역 단일 조합 버튼을 섞으면 선택 품목 수×지역 수와 실제 저장 조합 수가 다를 수 있다. 상태 문구는 실제 저장 조합 수를 명시하며 전체 조합으로 오인할 곱셈 표시는 제거했다.
- #701의 절대 자산 경로·공용 상단 메뉴·`run_worker_first` 등록을 유지한다. #668의 발송 활성화는 별도 단계이며 이번에는 실행하지 않았다.
