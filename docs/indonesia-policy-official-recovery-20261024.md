# 지방 법령 공식 대체 출처 복구 (2026-10-24)

## 지금 가능한 보강과 실제 제한

지방 원문 일부가 막혀도 중앙 공통 법령 검색·지역별 구독·기존 공식 원문 갱신은 유지된다. 미확보는 규제 부재나 폐지 판정이 아니다. BPK는 실제 Chrome에서 Website Under Maintenance, Kalbar JDIH는 Cloudflare 차단을 확인했다. 검색 색인의 PDF 정보와 현재 원본 바이너리 다운로드 성공을 구별한다.

## 추가한 도구와 후보

- `scripts/indonesia_policy/recover_official.py`: 법령별 검토된 공식 주소를 최대 3개 확인하는 별도 복구 도구. 같은 문서 식별·최종본 검사를 그대로 사용한다. 비정부 주소·중복 주소·10건 초과 묶음을 요청 전에 거부한다.
- `scripts/indonesia_policy/sources-regional-recovery-20261024.json`: 기존 미확보 3건 + Pergub159/2021 부속서 개정 후보 + Pergub1/2024 시행규정 후보, 총 5건이다. 후보 추가는 DB 등록·현행 효력 확정과 다르다.
- Perda6/2018의 공식 제목은 Pengelolaan Usaha Berbasis Lahan Berkelanjutan이다. 이전 후보의 농장 사업이라는 좁은 제목을 새 복구 묶음에서 바로잡았다. 기존 manifest/hash는 변경하지 않았다.
- 403·429·503 또는 점검/차단 응답을 받으면 해당 호스트의 다른 경로와 다른 문서 요청을 이번 실행에서 보류한다. 불완전 본문도 같은 호스트로 계속 요청하지 않는다. IP 교체·차단 우회·무한 재시도는 사용하지 않는다.
- CLI는 현재 수집기의 cooldown 파일을 필수로 받는다. 알려진 쿨다운 호스트는 최초 요청도 하지 않는다. DB lease가 필요한 등록 단계와 별개인 읽기 전용 수집이므로 운영 수집을 중복 실행하지 않는다.
- 별도 신규 출력 폴더에 PDF 바이트, URL별 실패·대기·성공 기록과 collection.json을 남긴다. 모든 원문이 막히면 documents는 빈 배열이고 실패를 보존한다. 메타데이터·잘린 본문·OCR 관측을 완전한 원본 복구로 표시하지 않는다.

## 실행·운영 경계

`python recover_official.py --help`에서 manifest, 신규 output-dir, 현재 scheduler의 active-run.json 또는 reviewed status.json을 가리키는 cooldown-file을 지정한다. 오래된 Mac 체크포인트로 현재 GitHub 쿨다운을 대체하지 않는다. 이미 기록된 차단을 무시해 즉시 다시 내려받지 않는다.

이 도구는 DB·유료 AI·메일 호출을 하지 않는다. 기존 수집기의 고정 SHA·4시간 주기·103건 reviewed 커서 및 regional 커서도 바꾸지 않는다. 실제 확보된 원문은 원본·식별·개폐 관계 검토 후 기존 DB lease 등록 절차로 넘겨야 한다. 공식 PDF가 끝내 없으면 기관 제공 파일 확보가 필요하다.

원문이 없는 상태에서 AI로 내용을 복원하지 않는다. PDF OCR은 공식 파일 확보 뒤 별도 검토로 수행하며, 원본과 전사 품질을 보존한다. 기존 OCR 경로의 25쪽 제한을 임의로 해제하지 않았다. 41·48쪽 후보는 전체 페이지를 다루는 별도 검증 전까지 자동 완전본 승격하지 않는다.

## 검증

전체 Python 회귀 71개 통과(새 복구 도구 8개 포함). 기존 admission 재개 테스트의 임시 디렉터리 문자열을 Path로 변환하는 오류도 수정했다. 테스트는 실제 정부 사이트 요청을 만들지 않는다. 이번 보강으로 새 원문이 DB에 등록됐다고 주장하지 않는다. IDN 발송은 꺼진 상태를 유지한다.
