## 화면

- 별도 주소: `/indonesia-policy/`. 처음에는 전체 저장 문서를 보여준다.
- 중앙 검색창 아래 품목·기관 등급·지역·정렬·모든 조건 일치 필터. 큰 왼쪽 패널은 없다.
- 발행정부는 중앙정부만/지방정부 전체/주/군/시로 구분한다. 중앙 선택 시 지방 지역을 초기화·숨김 처리하며, 지방 지역 목록은 발행 등급과 품목을 따른다. 검색창에 중앙을 입력하는 것은 기관 필터 선택과 다르다.
- 결과는 하나의 목록. 품목, 중앙/주/군/시, 관할, 원문/메타데이터, 효력 미확인 표시.
- 여러 품목 공통 제도는 적용대상 별도 확인 배지를 표시한다. 수집 실패 이력은 현재 미수집 문서 수와 구분한다.
- 관련도는 일치 조건 수 → 제목/본문/분류 근거 순서 → 문서 연도로 정렬한다. 연도는 실제 발행일과 구분한다.
- 일부 조건만 일치하면 숫자를 명시하고 제목/본문/분류 중 어떤 곳에서 어떤 동의어가 맞았는지 펼쳐 볼 수 있다.
- 세부사항은 원문 제목, 기관, 문서번호, 수집 확인 시점, 범위·검토 사항, 공식 링크, 확보한 원문/메타데이터를 표시한다.
- 검색 결과에도 검증된 공식 원문·PDF 링크를 표시한다. 미확보 후보를 PDF로 표시하지 않으며 일부 본문 수집은 별도 배지로 알린다.
- 조회 실패와 검색 0건을 분리한다. 문서 미수집을 규제 부재로 해석하지 않는다.
- 인도네시아 DPR/DPD의 입법 절차는 미국의 하원/상원 단계와 동일하지 않다. 이번 자료는 기존 부처·지방 규정 중심이므로 미국식 진행 보드를 복제하지 않는다. 입법 단계는 별도 RUU 원천을 연결한 뒤 설계한다.

공식 입법 설명: https://www.dpr.go.id/kegiatan-dpr/fungsi-dpr/fungsi-legislasi

[2026-10-19 근거 구조](indonesia-policy-evidence-20261019.md): 별도 공백 목록, 버전과 인용문으로 검증한 개정·폐지 관계, 사업자/제품/허가/지역의 검토범위와 선택 조문 API를 추가했다. 기존 문서 검색 필터와 순위는 유지하며 조문은 이미 선정된 문서에 근거를 덧붙인다. 현행 효력 및 개별 적용성 판정이 아니다. 화면 연결은 Claude 인수 대상이다.

## 검색·보안

`GET /api/idn/search?q=니켈,수출&topic=nickel_mining&level=national&sort=relevance&match=all`

- 검색어 최대 240자/6조건, 반환 최대 50건, 기본 20건. 기본 일부 일치 허용, match=all이면 모든 조건을 만족해야 한다.
- 쉼표 및 공백으로 조건을 분리하되 palm oil 등 사전에 등록된 구는 유지한다.
- 한국어·영어·인도네시아어 동의어는 search-api.mjs의 인도네시아 전용 사전이다. 기본 키워드 검색은 Gemini를 호출하지 않는다. 후속에서 문서개요 벡터 63건과 명시적 mode=hybrid 검색을 추가했다. 전체 조문 임베딩·번역은 아니다. [최신 계약](indonesia-policy-value-chain-20261019.md)을 따른다.
- 번호 조회도 같은 경로를 이용한다. 예: Permendag 15/2026.
- 서버만 Supabase 서비스 키로 public.idn_search_documents_v2 / public.idn_get_document를 호출한다. 함수는 비공개 policy_idn만 읽는다.
- anon/authenticated는 스키마와 RPC를 사용할 수 없다. 브라우저에는 키를 보내지 않는다. 오류 본문에도 상류의 비공개 내용을 노출하지 않는다.
- 보조금/금융지원/세금감면/투자 인센티브/환경/로열티/재식재/인프라 지원 동의어를 분리했다. 검색 일치는 지원 자격 판정이 아니며 정부 간 세입 배분·기금 징수도 직접 보조금과 구분한다.
- 현재 63건 시범 규모의 키워드·개요 벡터 검색이다. 수천 건으로 늘리기 전에 별도 IDN 검색 색인·구절 임베딩·성능 검증이 필요하다. 미국 벡터/검색 함수를 재사용하지 않는다.

## 실제 검증과 적용 구분

운영 DB에 `20261018113918_indonesia_policy_search.sql`을 적용했다. 로컬 파일과 운영 SQL MD5: b8ef571205c25284a953ccfd429b0bad.

- 실제 DB를 읽는 로컬 브라우저: 전체 57건, 바이오연료 필터 31건, 중앙/지방/군 전환과 지역 초기화, PDF 버튼, 페이지 이동, 니켈/수출 검색, 상세 본문, 0건/오류 구분, 1360/390px 가로 넘침 없음, pageerror 0. 건수는 2026-10-19 확인값이며 테스트는 라이브 필터 응답과 비교한다.
- 기존 미국 Worker 회귀검증 16개 통과.
- Supabase 보안 검사에서 IDN 관련 항목은 비공개 테이블의 RLS 정책 없음 INFO 3건이다. 공개 역할 접근을 의도적으로 거부하고 서비스 역할만 사용하는 설계다. 공개 정책을 추가하지 않는다. 설명: https://supabase.com/docs/guides/database/database-linter?lint=0008_rls_enabled_no_policy

Worker 연결은 `_worker.js`의 import 및 `/api/idn/` 분기로 구현했다. 2026-10-18 사용자가 Codex 구현·Claude 배포 역할을 확인한 데 따라 이번 브랜치에 `_worker.js`만 정확한 소유권 예외를 추가했다. 기존 미국 처리·공용 내비게이션·배포 워크플로는 수정하지 않았다. 운영 사이트 공개·배포 검증은 Claude 담당이다.

## Claude 배포 인수

1. PR #613의 최종 diff와 검사 결과를 검토한다. 이 PR의 DB 마이그레이션 1~6은 운영에 이미 적용됐으므로 수동 재실행하지 않는다. 새 DB에서만 순서대로 적용한다.

3. 사람의 병합·배포 승인 이후 기존 배포 경로를 따른다. Codex는 병합·배포하지 않았다.

## 공식 목록 후보 대조 API

`/api/idn/catalogue-status`와 `/api/idn/catalogue-gaps?source=SOURCE_ID&limit=100&offset=0`는 법령 검색과 별도인 목록 수집·대조다. limit은1–200, offset은0–10000이다. 식별 후보를 검증된 원문으로 표시하지 않으며 목록의 열거 완료를 기관/전국 완전성으로 해석하지 않는다. 구현·운영 범위는 [목록 수집 보고서](indonesia-policy-catalogue-20261019.md)를 따른다.
