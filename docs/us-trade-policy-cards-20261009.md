# 국가별 미국 통상 조치와 시뮬레이터 연결

2026-10-09 · 로컬 변경 · 운영 배포·DB 수정 없음

## 이번에 연결한 것

기존 `us_tariffs_v1.json`의 한국·일본·대만·중국·독일에 베트남·멕시코·캐나다를 추가했다. 미국 국가 패널에서 세 나라를 열 수 있고, 지도에서 해당 국가를 선택해도 기존 수출통제 아래/위의 미국 통상 조치 패널을 재사용한다.

국가마다 실제 조치·조사/재확인 사항·조건부 법적 수단을 구분한다. 법률 카탈로그의 존재는 그 나라에 제재가 발효했다는 판정이 아니다. 232·301·338·201·AD/CVD·307·337·ECRA/EAR·IEEPA 경제제재·122를 법적 요건, 절차, 효과, 공식 출처와 연결했다. 미국의 수입규제와 미국에서 나가는 수출·재수출 통제는 방향이 다르다.

행정명령, 대통령 포고, USTR 공고, 상무부 명령은 동일한 문서 유형이 아니다. 법적 권한 → 개별 시행 문서 → 수정/정지/판결 → 상품·원산지·기업별 적용의 연결로 관리해야 한다.

## 검증 결과와 한계

| 항목 | 처리 |
|---|---|
| 강제노동 301조 | USTR 431쪽 최종 공고의 국가별 결정과 USMCA 예외를 확인. 베트남 추가 12.5%, 멕시코·캐나다 추가 10%, 제품·무관세 신고 예외 별도 |
| 한국·일본·EU·대만 일반 관세 | 기존 “기본세율 포함 상한” 표현 보정. 기본세율이 기준보다 높아도 낮추는 규칙이 아님. 해당 추가관세만 0 |
| 232조 금속 | 4월 조치뿐 아니라 6월 Annex I-C 장비 한시 규칙 연결. 모든 파생제품에 동일한 세율 적용 금지. 후속 변경 전체 검증은 미완료 |
| 캐나다 338조 | 자동차 차별 대응 공고의 지정 제품 추가관세와 수입금지를 별도 레코드로 추가. 최초 시행은 8월 22일, 9월 15일 목록/중첩 수정, 9월 29일 일부 수입금지. 전 품목 50%로 표시하지 않음 |
| 베트남 IP 조사 | 5월 29일 개시 공고를 조사 단계로 연결. 확정 세율을 만들어 넣지 않음 |
| 기존 기타 232조 묶음 | 목재·반도체·의약품·장비·드론의 시행 일정과 예외가 달라 통째로 “시행 중”에 넣지 않고 재확인 그룹으로 이동 |
| 기존 중국 휴전·국가별 투자 약속 등 | 기존 자료 재확인 표시. 발표를 현재 통관세율로 확정하지 않음 |

**부분 검증이다.** 8개 국가의 모든 HTS, 소송·수정, 기업별 AD/CVD 및 캐나다의 별도 주류·유제품 대응 공고까지 완전한 규칙 엔진으로 옮긴 것은 아니다. 확인 표시도 “표시 원문 확인”이며 “현재 적용세율 전체 검증”과 다르다. 공식 출처는 JSON 각 행에 저장했다.

## 데이터 계약

- 기존 `schema_version`, `measures`, `partners`, `rate_ko`, `sources`를 유지하고 필드를 추가했다.
- `partners[ISO].lines[].measure_ids` → 실제 조치. `legal_tool_ids` → 별도의 조건부 법률 목록.
- `verification`: `primary_text_checked` / `needs_review`. 전체 `audit.status`는 `partial`.
- `action_type`: 관세·수입금지·조사 구분. 수입금지를 높은 관세율로 근사하지 않는다.
- `legal_tools[].availability`는 `conditional`, `assumed_rate`는 `null`.
- **모든 `calculation_ready`는 false.** 한국어 세율 설명을 숫자로 파싱해 계산기에 넣지 않는다.
- 계산 연결 전에는 HTS10·서술적 범위·수입일·원산지·생산자/수출자·기본세율·추가세율·미국산 가치·예외·중첩을 별도 정규화하고 검증해야 한다.

## 시뮬레이터가 답해야 하는 질문

관세는 충격 입력이다. 기업 의사결정에는 시장의 반응과 판매 대안을 함께 비교해야 한다.

1. **정책 적용과 현금 부담**: 실제 대상 여부, 수입자가 납부할 예치금, 사후 추가 납부/환급의 불확실성. 반덤핑률을 예측하는 기능과 이미 주어진 예치율의 손익 영향을 분석하는 기능은 다르다.
2. **가격·원가 대응**: 계약상 부담 주체, 수출자의 할인, 수입자의 마진 흡수, 최종 가격 전가. 현금흐름과 회계상 비용을 구분한다.
3. **고객·경쟁사 반응**: 같은 사양 제품의 공급자 간 대체 가능성, 고객 인증·계약·전환비용, 경쟁사 유휴 생산능력·납기. 값이 싸다고 즉시 전량 이동하지 않는다. 장기계약 물량과 신규/갱신 물량은 따로 다룬다.
4. **판매처 전환**: 미국에서 감소한 물량을 자동으로 다른 나라가 사는 것으로 처리하지 않는다. 대체 시장의 수요·인증·기존 판매량·물류비·관세·가격 반응과 공급능력이 필요하다. 통계상의 수출 단가는 품질·제품 구성 차이가 있어 곧바로 판매 가능 가격이 아니다.
5. **경영 대안 비교**: 미국 가격 유지 / 할인 / 물량 축소 / 다른 시장 판매 / 생산지 변경의 제품별 기여이익·운전자금·납기·투자비를 같은 기간에 비교한다. 생산지 변경에는 실제 원산지 요건과 우회수출 규정을 적용한다.

현재 독립 로컬 시뮬레이터의 CES 제품시장 모형과 기업 가격경쟁 모형에는 가격·물량·공급자 대체 반응이 있다. 기업 원가는 가정으로 보정한 값이다. 실제 계약, 생산능력 제한, 미국 밖 시장 균형, 실제 기업별 원가·고객 전환 데이터는 아직 연결하지 않았다. 민감도 범위는 확률이나 신뢰구간이 아니다.

## 다음 구현 순서 제안 — 아직 구현하지 않음

한 회사의 한 제품 사양과 미국 고객 시장을 먼저 확정한다. 전사 실적이나 HTS6 전체 수입을 해당 회사의 판매로 사용하지 않는다.

- 1단계: 실제 판매단가·변동원가·운송비·관세 부담 계약을 입력해 가격 유지/할인 시 손익과 현금 부담 비교.
- 2단계: 미국 고객의 인증/계약으로 이동이 제한된 물량과 경쟁 가능한 물량을 분리하고, 문헌·공식 조사 기반 탄력성의 낮음/기준/높음 시나리오 적용. 경쟁사 증산 한도를 추가.
- 3단계: 검증된 대체 시장 1~2개만 연결. 물량 확대 시 가격 하락과 현지 추가 비용을 반영한 **순수취액**으로 비교.
- 4단계: 기준 시점 이후 실제 관측 결과와 비교해 보정. 검증 범위 밖에서 정밀한 단일 전망치를 제시하지 않음.

UI는 국가 정책 패널 → 제품·원산지·기업 확인 → 미국 판매 유지/할인/대체 시장 비교로 이어지는 구성이 적합하다. 정책 카드만으로 기업 손익 수치를 자동 생성하는 연결은 만들지 않았다.

참고 모형: [USITC CES](https://www.usitc.gov/ces_tariff_model), [USITC 부분균형 모형 설명](https://www.usitc.gov/publications/332/working_papers/an_introduction_to_partial_equilibrium_modeling_of_trade_policy_0.html), [세계은행 TRIST](https://wits.worldbank.org/trist.html), [상무부 AD/CVD 예치와 정산](https://www.trade.gov/faq/faqs-final-determination-antidumping-duty-andor-countervailing-duty-investigation).
