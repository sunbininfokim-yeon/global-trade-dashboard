## 근거 구분

입력과 결과에 공식 공표·통계 근거, 문헌 추정값, 산업·시점 대용값, 계산 예시, 사용자 가정을 구분했다. 공식 관세 근거도 검토 시점의 조건부 적용이며 실시간 전체 세율 인증이 아니다. 기존 문헌의 연도·범위·출처는 유지한다.

국가 구매액50/25/25에는 계산 예시, 직접 편집한 값에는 사용자 가정·실측 미검증을 표시한다. 공급탄력성 미국1.5/해외3은 가정임을 입력칸에 표시한다. 기업 흡수율50%·탄력성2·계약비중0% 역시 업계 평균이나 기업 실증값으로 바꾸지 않았다. 기업 거래·원가 공란은 유지한다. 결과 JSON에도 근거와 시장 보정 상태가 남는다.

## 결과 범위

국가 모형의 기존 기준 결과와 σ 단독 민감도를 유지한다. 추가로 σ·η·공급탄력성의 최대27조합을 비교한다. σ와 η는 적용된 문헌 범위가 있으면 해당 양 끝과 입력값, 없으면 입력값0.5/1/1.5배의 명시적 민감도 가정이다. 입력 유효 범위에서 제한한다. 공급탄력성0.5/1/1.5배는 사용자 가정이며 산업 표준이 아니다. 직접 수정한 탄력성에 기존 문헌 범위를 자동 상속하지 않는다.

성공한 조합의 판매량·매출 변화 최저/최고와 각 조합의 값·성공/불가를 JSON에 보존한다. 화면에는 판매량 범위와 상세 조합을 표시한다. 계산 불가 조합은 범위에서 제외하고 건수를 표시한다. 발생 확률·예측구간·통계적 신뢰구간으로 해석하지 않는다.

기업은 기존 흡수율 민감도에서0/50/100%를 이름 있는 대응 비교로 보여준다. 공급 한도 공란은 `unbounded_assumption`으로 표시하며 생산·납기·인증 제약 미반영 경고를 제공한다. 국가 결과 연결은 원산지 평균 대용이며 기업 실증값이 아니다. 기업 모델 내부 국가 재계산에는 불필요한 민감도 조합을 실행하지 않는다.

## 반덤핑 단위 비교

선택한 기업·통관 가정일의 공표 참고율에 대해 신고가격10만USD당 예치 참고액을 표시한다. 예:4.32%는4,320.00달러. 실제 거래액에 대한 결과와 구분한다. 수치 연산은 원래 세율을 이용한 정수 고정소수점 계산으로, 작은 실제 거래액의 반올림 결과를 확대하지 않는다.

실제 계산의 제품·생산자/수출자 확인 조건은 유지한다. 미확인 법인·예치 지침 미수록·자료 확인일 이후 통관에는 단위 비교도 미확인이다. 금리5%·365일·+5%p는 계속 계산 예시이며 평균 금리·정산일·미래 판정 예측이 아니다. 회사·날짜 변경 시 단위 참고액도 갱신한다.
