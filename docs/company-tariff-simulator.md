# 기업 관세 시뮬레이터 v1

정책 → 미국 → 관세 시뮬레이터 → **기업**에서 사용한다. 국가 탭과 같은
`/policy/us/simulator` 경로이며 국가·반덤핑·기업의 입력·결과를 브라우저 메모리에 별도로 보존한다.
새로고침하면 입력 초기 상태로 돌아간다. 운영 배포는 별도다.

[실제 기업 자료 데스크톱](previews/company-real-desktop.png) · [360px 모바일](previews/company-real-mobile.png)

반덤핑 현금예치 비교는 [반덤핑 탭](antidumping-simulator.md)으로 분리했다. 효성중공업·한국타이어 프로필에서 해당 사건으로 바로 이동할 수 있다.

## 답하는 질문

- 관세를 구매자에게 전가하거나 수출단가를 낮출 때 판매량·제품 손익은 어떻게 달라지는가?
- 계약 물량·경쟁 제품 가격·시장 수요·공급 한도에 따라 대응 결과가 어떻게 달라지는가?
- 선택한 시나리오에서 손익분기 판매량과 감당 가능한 단위 변동원가는 얼마인가?
- 국가 모형의 같은 원산지 평균 반응을 한 기업에 적용하면 어떤 조건부 손익이 나오는가?

LS전선·대한전선·기아·효성중공업·HS효성첨단소재·한국타이어의 공식 2025 재무 참고 자료를 선택할 수 있다. 다른 기업은 직접 입력한다. 공시 전사 실적은 미국향 제품 거래·원가 입력으로 대입하지 않는다. 제품 사양이나 원산지는 별도 확인한다. 자세한 확보 범위는 [기업 공개자료](company-public-data-availability.md)를 참조한다. 기업의 한 제품·한 원산지·같은 기간만 비교한다.
한국 기업의 미국 생산분은 원산지 미국, 한국 생산 수출분은 원산지 한국으로 별도 분석한다.

## 입력

| 입력 | 의미·단위 |
|---|---|
| 기업명·품목·원산지·기간 | 실제 거래와 맞춰 사용자가 정의. 원산지는 본사 소재지와 다름 |
| 기준 통관 단가 | USD/동일 제품 단위. 관세 제외 수취단가와 통관 단가가 같다는 단순화 |
| 기준 판매량 | 분석 기간에 미국에 판매한 동일 제품 물량. 다른 사양·물리 단위 혼합 금지 |
| 단위 변동원가 | USD/제품 단위. 기업이 부담하는 제조·수출 물류비 등 포함 |
| 기간 고정비 | 이 제품·사업에 배분한 같은 분석 기간의 고정비, USD |
| 변동원가 변화율 | 생산·조달·물류비 변화 가정. 관세를 다시 비용으로 빼는 칸이 아님 |
| 최대 공급 가능 물량 | 선택 사항. 기준 판매량 이상, 공란은 한도 미반영 |
| 현행/비교 관세 | 국가 탭의 부분 검토 HTS·원산지별 규칙 공유. 미확인은 직접 총 세율과 출처 |
| 수출자 흡수율 | 기존 통관가액 기준 관세 변화의 분담. 0%는 수취단가 유지, 100%는 구매가격 유지 |
| 기업 가격반응 탄력성 | 상대 구매가격 변화에 따른 경쟁 가능 물량의 반응. 산업 σ와 다른 사용자 가정 |
| 계약 고정 물량 비중 | 상대가격에 반응하지 않는 기준 물량 비중. 전체 시장 수요 변화는 반영 |
| 경쟁 제품 가격 변화 | 같은 사양 경쟁 제품의 관세 포함 가격 변화율 가정 |
| 시장 전체 수요 변화 | 상대가격 전환과 별도로 입력하는 수동 수요 충격 가정 |
| 경쟁 제품 기준 가격 | 선택 사항. 같은 사양·단위·가격 기준의 관세 포함 비교가격 |
| 자료 메모 | 공시·거래·원가·계약 자료 출처와 가정 기록 |

실제 제품 단가·원가·물량·고정비·분석 기간·원산지는 확보되지 않아 초기값을 공란으로 둔다. 테스트에서 사용하는 100/70/10,000/100,000은 실제 기업 자료가 아닌 검증 입력이다.
기업 탄력성 2, 계약 비중 0%, 경쟁 가격·시장 수요 변화 0%도 추정치가 아닌 사용자 가정이다.
단가와 통관가격이 다르거나 관계사 거래·유통 마진·수입자 비용이 중요한 경우 별도 보정이 필요하다.
국가 탭 구매액은 백만 USD, 기업 탭 단가·금액은 USD이므로 서로 자동 대입하지 않는다.

## 수동 기업 반응 산식

관세는 계산 시 소수로 변환한다. 기준 수취단가 `p0`, 관세 `t0/t1`, 흡수율 `a`:

```text
p1 = p0 × [1 + t0 + (1 − a) × (t1 − t0)] / (1 + t1)
buyer0 = p0 × (1 + t0)
buyer1 = p1 × (1 + t1)
relative = (buyer1 / buyer0) / (1 + 경쟁 제품 가격 변화율)
q_demand = q0 × [계약 비중 + (1 − 계약 비중) × relative^(−기업 탄력성)]
           × (1 + 시장 수요 변화율)
q1 = min(q_demand, 입력한 공급 한도)
c1 = c0 × (1 + 변동원가 변화율)
매출 = p × q
기여이익 = (p − c) × q
제품 손익 = 기여이익 − 기간 고정비
손익분기 판매량 = 기간 고정비 / (p1 − c1), 단위 기여이익 > 0일 때만 산출
감당 가능한 단위 변동원가 = p1 − 기간 고정비 / q1, q1 > 0일 때만 산출
```

수입자 납부 관세는 새 통관 단가 `p1`에 적용한다. 수출자의 단가 할인에 이미 반영한
부담을 기업 비용에서 관세로 다시 차감하지 않는다. 흡수율은 위 산식의 시나리오 정의이며
실제 계약상 법적 납세자나 회계 처리를 자동 판정하는 값이 아니다. 관세 인하 때도 같은 분담식을 적용한다.

기본 수치에서 관세 15→25%, 변동원가 변화 0%, 계약 0%, 경쟁·시장 변화 0%, 탄력성 2:

| 수출자 흡수율 | 수취단가 | 구매가격 | 판매량 | 제품 손익 USD |
|---|---:|---:|---:|---:|
| 0% | 100.00 | 125.00 | 8,464.00 | 153,920 |
| 50% | 96.00 | 120.00 | 9,184.03 | 138,785 |
| 100% | 92.00 | 115.00 | 10,000.00 | 120,000 |

기준 제품 손익은 200,000 USD다. 표의 25%는 직접 입력한 테스트 시나리오이며 현행 세율이라는 뜻이 아니다.
판매량은 계약·품질·인증·납기와 사용자 탄력성에 의존한다. 싼 제품으로 전량 이전한다고 가정하지 않는다.
경쟁 가격 비교만으로 기업 간 물량 배분을 확정하지 않으며 기업 모형은 경쟁사 균형을 직접 풀지 않는다.

## 국가 계산 연결

1. 국가 탭에서 같은 품목으로 해당 원산지를 포함해 유효한 계산을 완료한다.
2. 기업 탭의 반응 방식에서 **국가 계산의 원산지 평균 반응 연결**을 선택한다.
3. **최신 국가 계산 결과 연결**을 누르면 해당 원산지의 관세 총 세율과 입력 스냅샷을 복사한다.
4. 연결된 조건을 다시 확인하고 계산한다.

기업 엔진은 저장된 국가 입력으로 CES를 다시 풀어 원산지 평균 생산자가격·물량 변화율을
기업의 기준 단가·물량에 한 번 적용한다. 원가 변화·고정비·공급 한도는 기업 입력을 적용한다.
수동 흡수율·기업 탄력성·계약 비중·경쟁 가격·수요 변화는 다시 곱하지 않는다.
품목·원산지·관세가 다르거나 유효한 국가 결과가 없으면 연결을 거부한다.
이 방식은 **원산지 평균 반응의 기업 대용 시나리오**이며 기업별 수주·점유율·실적의 예측이 아니다.
연결 시점 스냅샷은 국가 탭의 후속 입력 변경을 자동 반영하지 않는다. 최신 결과가 필요하면 다시 연결한다.
공급 한도는 단순 물량 제한이며 이후 국가·경쟁사 균형을 다시 풀지 않는다.

## 근거·범위·저장

기업 가격 분담식·일정 탄력성 반응·제품 손익은 이 프로젝트의 명시적 시나리오 산식이다.
실제 기업에 보정한 문헌값으로 소개하지 않는다. 국가 연결의 외부 근거는
[USITC CES](https://www.usitc.gov/ces_tariff_model),
[Riker & Schreiber (2020), §2.1](https://www.usitc.gov/sites/default/files/data/gravity/structural_equations_for_pe_models_in_group_1.pdf)다.
관세 근거·지원 범위는 [국가 버전 문서](country-tariff-simulator.md)의 2026-10-11 부분 검토 범위를 공유한다.

전사 이익·세금·금융비용·환율·현금예치/확정 차액·다른 시장 재판매는 계산하지 않는다.
반덤핑 예치율을 법적 확정 관세로 바꾸거나 실제 덤핑마진을 예측하지 않는다.
현재 판매량에서 단가·원가를 고정한 손익분기 계산이며 가격을 바꾼 후 물량까지 다시 최적화하는 기능은 아니다.
손실 기준의 손익 변화율, 0물량의 마진, 비양수 기여이익의 손익분기점은 산출 불가로 표시한다.

입력 변경 시 이전 결과를 표시하고 재계산 전 JSON 저장을 막는다. JSON에는 입력·모형 버전,
가정·관세 출처·HTS·검토일·국가 연결 입력/원산지 결과·회계 항등식 잔차를 남긴다.
계산용 API·AI 호출과 서버 저장은 없다. 실제 기업의 비공개 자료를 Git에 저장하지 않는다.
