# 쉼표 조건 검색

`니켈, 수출통제, 배터리`는 조건 검색이며 문장형 입력은 기존 Gemini 의미 검색을 유지한다. 최대 5개 고유 조건, 전체 200자, 조건당 60자. 쉼표·전각 쉼표를 지원하고 빈 항목 및 같은 개념의 중복은 제거한다. 등록된 한국어·영어 표현 사전은 `scripts/lib/policy-search-terms.js`가 정본이다. 사전에 없는 표현은 원문 그대로 검색하며 자동 번역 또는 임의 의미 확장을 주장하지 않는다.

- bills(title/summary), executive_orders(title/summary), regulations(title/abstract), public_laws(law_title) 조회.
- 각 조건의 후보와 전체 AND 후보를 별도 조회한다. 단일 조건 후보가 많아 전체 일치 후보가 밀리는 문제를 줄인다. 조회당 60행, 동시 요청 4개로 제한한다.
- Gemini가 설정돼 있으면 등록된 영어 표현을 합친 질의의 임베딩 후보도 보완한다. 임베딩 점수만으로 조건 충족을 판정하지 않는다.
- 최종 판정은 제목·요약에서 단어 경계 및 등록된 유사 표현의 등장 근거를 찾는다. 문서 원문 전체, 부정문 의미, 개념 사이의 실제 법적 관계를 검증하는 기능은 아니다.
- `condition_matches`는 조건별 확인 여부, 일치 표현, 제목/요약 구분, 짧은 근거를 제공한다. `matched_condition_count`, `total_condition_count`, `match_level`로 전체/부분 일치를 구분한다.
- 조건 수 내림차순 → 의미 유사도 순. 화면에서도 전체 일치 구역 뒤에 `3개 중 2개`, `3개 중 1개` 구역을 따로 표시한다. 기존 문서 유형별 분류는 각 구역 안에 유지한다.
- `candidate_limited`/`result_limited`를 공개하여 0건을 자료 부재로 해석하지 않게 한다. Gemini 장애는 `semantic_available:false`와 단어 검색 결과로 표시하고, DB 조회 실패는 503으로 반환한다.
- Supabase 마이그레이션과 문서 재임베딩은 필요 없다. 기존 일반 검색의 public_law 확장은 PR #362와 별도이며, 이번 조건 검색에는 public_laws 직접 조회가 포함된다.

검증: Node 테스트 30개, Worker esbuild 번들 성공. 실제 Supabase 읽기 전용 질의(2026-09-30, 임베딩 보완을 끈 확인)에서 3개 조건 모두 확인 0건, 2개 확인 1건(CIRCUIT Act, 119-s-448; 니켈·배터리 확인 / 수출통제 미확인), 기본 표시 20건 중 나머지 19건은 1개 조건 확인. 후보 제한이 있으므로 전체 DB에 해당 법률이 없다는 증거는 아니다. 로컬 렌더링 확인. 운영 배포 미실시.

현재 자료만으로 '니켈, 수출통제, 배터리'의 기존 0건 원인이 유사도 임계값인지 공급자 오류인지 확정하지 않는다. 이 변경은 쉼표 조건 검색을 별도로 정의해 후보와 일치 근거를 설명 가능하게 만드는 수정이다.
