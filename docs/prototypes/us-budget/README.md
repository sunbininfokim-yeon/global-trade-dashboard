# 미국 예산 탐색: 검토용 시안

작업: `US-BUDGET-HANDOFF-20261031`. 이 폴더는 정책 → 미국 → 예산을
기존 제품에 통합하기 위한 화면·공개 데이터 인수 자료다. 운영 화면이나 자동 수집기는 아니다.

## 열어보기

저장소 루트에서 실행한다. API 키·로그인·로컬 `.env`는 필요 없다.

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory docs/prototypes/us-budget
```

브라우저에서 `http://127.0.0.1:8765/`를 연다. 종료는 `Ctrl+C`다.
`index.html`은 같은 폴더의 `budget-data.json`을 읽으므로 `file://`로 직접 열지 않는다.
월별 차트만 D3 7.9.0을 jsDelivr에서 읽는다. 연간 카드·도넛·정렬·계정 탐색은
서버 API 없이 제공된 스냅샷으로 작동한다. 배포 통합 시 라이브러리 로딩은 기존 CSP에 맞춘다.

```sh
node --test tests/us-budget-preview.test.cjs
```

## 사용자 결정

- 위치: **정책 → 미국 → 예산**. 정치·선거 메뉴에 넣지 않는다.
- 미국 메뉴에서 의회·행정부·관세 시뮬레이터와 같은 수준의 예산 탭을 둔다.
- 상단은 **세출 → 세입 → 재정적자** 토글. 선택한 내용만 아래에 표시한다.
- 세출은 의무지출(비재량)·재량지출·순이자 구성비를 먼저 보여준다.
- 정렬은 **지출액순 → 증가율순 → 증가액순**, 기본값은 지출액순이다.
- 국방은 군사사업/기타 국방 → 인건비·운영유지·조달·연구개발 등 → 예산계정까지 내려간다.
- 하위 분류에도 같은 정렬을 적용하며 지출액·증감액·증감률을 구분한다.
- 최근 5개 완료 연도(FY2022–2026), 36개월 실적(2023-10~2026-09), FY2027 정부안을 구분한다.
- FY2027은 처음부터 **정부안·추정**, 비교 기준과 대상 기간을 표시한다.

## 파일과 데이터 계약

- `index.html`: 로컬 경로·대화 호스트에 의존하지 않는 독립 미리보기. 제품 공통 스타일을 대체하지 않는다.
- `budget-data.json`: `budget`(요약·세입·성격별 지출·재량 분야·월별·조달),
  `defense`(FY2022–2025 국방 계정), `fy2027`(4월 정부안 및 같은 발표본의 FY2026 비교값).
- `sources.json`: 공식 URL, 원래 단위, 발표본, 조회일, 원자료/스냅샷 해시.

정규화된 금액은 **명목 USD**다. 원표마다 단위가 다르다.

| 원자료 | 원래 단위 | 변환 |
|---|---|---|
| OMB Historical Tables 1.1·2.1·8.5·8.7 | 백만 달러 | × 1,000,000 |
| OMB Historical Table 8.1 | 십억 달러 | × 1,000,000,000 |
| OMB Public Budget Database outlays | 천 달러 | × 1,000 |
| Treasury MTS API의 사용 필드 | 달러 | 그대로 |

금액을 표시할 때만 조 달러/B$로 반올림한다. 원자료의 작은 음수·실제 0을 보존한다.
미확인 금액을 0으로 채우지 않는다. 전년 금액이 0·음수이거나 올해 음수인 경우
백분율을 표시하지 않으며 순액 증감은 보존한다.

## 발표본과 비교 기준

1. FY2022–2025 연간 요약은 FY2027 OMB 예산서에 실린 과거 실적이다.
2. FY2026 요약·36개월 실적·자금조달은 Treasury MTS 발표본이다.
   OMB는 과거 값과 기관/계정 구조를 나중에 수정할 수 있으므로 서로 다른 발표본을 강제로 맞추지 않는다.
3. FY2027은 **2026년 4월 정부 제출본 추정**이다. 중간수정 전망·의회 확정액·실제 지급액이 아니다.
4. FY2027의 증감 기준은 **동일 4월 자료의 FY2026 정부 추정치**다.
   뒤에 발표된 FY2026 MTS 실적을 분모로 섞지 않는다.
5. 국방 하위 집계는 PBD에서 `BEA Category = Discretionary`이고
   `Subfunction Code = 051/053/054`인 행만 사용한다.
   같은 계정의 grant/non-grant 등 분리 행은 더하되 상위 합계와 중복 합산하지 않는다.
6. 국방부 군사사업(051)은 bureau별 → 계정 코드·명칭별로 집계한다.
   기타 국방은 053/054 → 기관/bureau → 계정으로 나눈다. 국방이라는 기능 전체와 국방부를 동일시하지 않는다.
7. FY2027 `Allowances`는 실제로 있는 음수 계획 조정액이다. 누락하면 재량 총액이 맞지 않는다.
8. FY2026 실제 의무/재량 분류는 이 자료에서 검증하지 못했다. 4월 추정치를 실적으로 채우지 않았다.

재정적자는 **세출 − 세입**이다. 국채 발행은 세입에 포함하지 않는다.
FY2026 조달은 MTS 표 6의 `Total Borrowing from the Public`, 연준계좌 잔액 변화 및
나머지 조달·조정 순액이다. 총발행·상환이나 부채잔액 변화와 동일한 지표가 아니다.
나머지 조달·조정은 표시된 적자·순차입·현금 변화의 잔차이며 별도 공식 단일 계정으로 해석하지 않는다.

## 재생성할 때

이 PR에는 원본 XLSX·API 캐시를 넣지 않았다. `sources.json`의 공식 URL에서 원본을 다시 받고
해시·단위·발표본을 확인한 뒤 별도 수집기로 생성해야 한다. 자동 갱신은 아직 설치하지 않았다.

- OMB 표의 `estimate` 열/행과 과거 실적을 분리한다. April 정부안과 Mid-Session Review는 다른 vintage다.
- MTS 표 1은 `record_date`가 관측 월과 같지 않다. 부모 `FY xxxx` 블록을 먼저 식별하고
  `record_type_cd = MTH`의 월 이름으로 대상 월을 만든다. `Year-to-Date`와 월별 행을 더하지 않는다.
- 2024-09 발표본에서 FY2024 월별 12개, 2026-09 발표본에서 FY2025·FY2026 월별 24개를 사용했다.
- 2026-09 MTS 표 3은 세입 항목·하위 사회보험 합계 및 FY2026 부처별 순지출에 사용했다.
- MTS 표 6은 총액과 하위 조달/자산 계정을 중복 합산하지 않는다.
- OMB 일부 XLSX는 read-only 로더가 sheet dimension을 잘못 해석할 수 있다.
  행 수·연도 존재 여부를 확인하고 누락 시 정상 로드 또는 dimension 재계산을 사용한다.
- 새 다운로드의 검증 실패·차단 시 기존 게시 스냅샷을 보존한다. 실패를 최신 정상 수집으로 표시하지 않는다.

## 제품 통합에서 남은 것

- 실제 `/policy/us/budget` 라우트·메뉴·공통 스타일·접근성 연결(경로는 제안).
- 생산용 수집/생성 스크립트와 갱신 주기·실패 감시·마지막 정상 발표본 보존.
- 데이터의 source/vintage/status 필드를 렌더링 값에 연결하고 실적·추정 혼합을 차단.
- 부처/계정의 법률·세출법 연결, 계약·보조금·수령기업. 현재 시안은 해당 기능을 구현했다고 주장하지 않는다.
- 실제 날짜 기준의 연도 롤오버와 과거 36개월 범위 갱신.

현재 앱·Worker·워크플로·운영 DB·메일 발송 설정은 이 PR에서 바꾸지 않는다.
전체 시안을 그대로 제품에 복사하지 말고 기존 앱의 메뉴·렌더러에 통합한다.
