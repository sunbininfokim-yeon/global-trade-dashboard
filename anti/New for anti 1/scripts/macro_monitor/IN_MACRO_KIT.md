# India Macro Kit (`in_macro_v1`)

내수 고성장 · **에너지 수입 CAD** · RBI의 적극적 환율·물가 개입.

## 구조 (6탭)

| 탭 | 핵심 |
|----|------|
| 유동성 | 외환보유 · **CRR** · M3 |
| 금리 | **RBI Repo** · G-Sec 10Y · **LAF** |
| 환율·대외 | **USD/INR** · **CAD/GDP**(최중요 펀더멘털) |
| 주식 | Nifty · Sensex · **FPI** |
| 성장 | GDP · PMI(서비스 중점) · **이륜차·트랙터** · 은행신용 |
| 물가 | CPI(식료 ~45%·몬순) · **WPI** |

## 헤드라인

CAD/GDP · Repo · USD/INR · GDP · FPI · CPI

## 한계

1. 공식 고성장 ≠ 비공식 부문 체력  
2. Repo로 식료·몬순 물가 통제 불가  
3. M3↑ ≠ 균형 투자·고용
