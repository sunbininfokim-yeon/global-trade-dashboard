# Vietnam Macro Kit (`vn_macro_v1`)

**China+1 FDI** · 수출주도 · SBV **관리변동·신용쿼터**.

## 구조 (6탭)

| 탭 | 핵심 |
|----|------|
| 환율 | **USD/VND**(±5% 밴드) · 외환보유 · 무역수지 |
| 자본·주식 | **FDI 등록/실행** · VN-Index |
| 유동성 | **신용증가 한도(Quota)** · M2 |
| 금리 | 재융자·할인율 · 예금/대출금리 |
| 성장 | GDP · **수출 YoY** · PMI · IIP |
| 물가 | CPI (목표 ~4–4.5%) |

## 헤드라인

FDI 실행 · USD/VND · 신용쿼터 · 수출 YoY · VN-Index · CPI

## 한계

1. 수출·FDI↑ ≠ 내수·자국 질적성장 (FDI기업 ~70%+)  
2. 밴드 안 환율 안정 ≠ 외환건전성 (비공개 개입)  
3. 금리↓ ≠ 실물신용 (Quota·규제 차단)
