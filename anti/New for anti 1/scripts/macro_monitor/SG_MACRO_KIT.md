# Singapore Macro Kit (`sg_macro_v1`)

초개방 무역경제. MAS는 **금리 대신 S$NEER 밴드**로 물가·성장을 통제한다.

## 구조 (6탭)

| 탭 | 핵심 |
|----|------|
| 환율·통화정책 | **S$NEER** · 밴드 기울기/폭 · USD/SGD · OFR |
| 유동성 | 총유동성 · M2 · **외화예금**(WM 허브) |
| 금리 | **SORA**(≠MAS 스탠스) · SGS 2Y/10Y · SOFR−SORA |
| 주식·부동산 | STI(금융주) · **S-REIT** · 민간주택 |
| 성장·무역 | **NODX**(최중요) · GDP · SIPMM PMI |
| 물가 | **MAS Core**(타겟) · 헤드라인 CPI |

## 헤드라인

S$NEER · NEER 기울기 · NODX · SORA · MAS Core · STI

## 한계

1. SORA↑ ≠ MAS 긴축 — NEER 밴드를 보라  
2. 헤드라인 CPI는 COE·임대 착시 — MAS Core 우선  
3. M2 팽창 ≠ 내수 유동성 (Family Office 대기성 자금)
