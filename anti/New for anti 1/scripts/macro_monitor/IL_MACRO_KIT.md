# Israel Macro Kit (`il_macro_v1`)

**하이테크 수출** · **셰켈/위험프리미엄(CDS)** · 전시 **재정·노동공급** 제약.

이란과 달리 BOI·CBS·시장 데이터가 열려 있어 **표준 6탭이 성립**한다.  
다만 전쟁·지정학이 평시 거시모형을 자주 깨뜨린다 (한계 4항).

## 구조 (6탭)

| 탭 | 핵심 |
|----|------|
| 유동성·재정 | BOI 자산 · 외환보유 · M2 · **재정수지/GDP** · 부채/GDP |
| 금리·신용 | **BOI 정책금리** · 셰켈 국채 2Y/10Y · **5Y CDS** · 등급 |
| 환율 | **USD/ILS** · 경상 · us_fx_watch |
| 주식 | **TA-125** |
| 성장 | **하이테크 수출**(KR 반도체 슬롯) · GDP · 실업 · PMI |
| 물가 | CPI · Core (목표 **1–3%**, 중심 ≈2%) |

## 헤드라인

CDS · BOI Rate · USD/ILS · TA-125 · 하이테크 수출 · CPI

## 한계 (4)

1. 전쟁·지정학 → CDS/셰켈/주가 비정량  
2. 낮은 실업 ≠ 여유 (예비군·공급 제약)  
3. 하이테크 수출↑ ≠ 내수 전반  
4. 재정 적자·전시 GDP ≠ 지속 성장

## 이란은?

**표준 매크로 키트 비추천.** 제재·이중환율·통계 불투명·거래 접근 제한.  
호르무즈·유가·해운은 **타국 growth/fx 외생충격**으로만 추적.
