# Eurozone Macro Kit (`ez_macro_v1`)

**한 줄:** 돈(유로)은 하나인데 나라는 여러 개(재정 따로).  
그래서 ECB 정책 + **이탈리아−독일 국채 격차(분절화)** 를 같이 본다.

지도에서 독일·프랑스·이탈리아 등을 눌러도 이 팩(`EMU`)으로 연결된다.

---

## 처음 볼 때 용어

### 유동성 · ECB 대차대조표

| 이름 | 뭐냐 | 왜 보나 |
|------|------|---------|
| **ECB 총자산** | 유럽중앙은행 전체 BS 크기 | QE 키웠다/QT로 줄인다의 총량 |
| **APP** | Asset Purchase Programme. **일반 QE**로 국채·회사채 등을 사 모은 잔고 | 코로나 전후 “평시 매입” 포트폴리오. 지금은 주로 **만기 재투자 축소·중단(QT)** 추적 |
| **PEPP** | Pandemic Emergency Purchase Programme. **팬데믹 긴급 매입** 잔고 | 위기 때 만든 별도 봉투. 국가별 매입 비중을 **유연하게** 조절할 수 있어, 이탈리아 금리 발작 때 완충재 |
| **APP vs PEPP** | 둘 다 “채권 사기”지만 | APP=상시 QE 틀, PEPP=코로나 비상 틀(+유연 재투자). QT 국면에서 **둘 다 잔고가 어떻게 줄는지** 봄 |
| **M3** | 유로존 **광의통화** | ECB가 통화량 지표로 **M3**를 공식 모니터링한다. 미국=M2, 영국=M4, 유로=M3 (관할마다 정의가 다름) |
| **TLTRO** | 은행에 싼 장기 대출 풀어 준 프로그램 | 만기·조기상환되면 시중 유동성이 회수됨 |

### 금리 · “유로존만의” 리스크

| 이름 | 뭐냐 | 왜 보나 |
|------|------|---------|
| **DFR (수신금리)** | 은행이 ECB에 돈을 맡길 때 받는 금리 | 사실상 **기준금리** 역할 (지금은 이게 정책금리의 중심) |
| **MRO / MLF** | 주간 자금공급 / 긴급 대출 금리 | DFR과 함께 “금리 복도(corridor)” |
| **Bund 10Y** | **독일** 10년 국채 | 유로존 **무위험 벤치마크** |
| **BTP 10Y** | **이탈리아** 10년 국채 | 고부채국 대표 |
| **BTP−Bund 스프레드** | 이탈리아−독일 금리 차(bp) | **분절화** 지표. 커지면 “유로 깨질라” 공포·재정 위기 신호. ECB가 가장 예민하게 보는 것 중 하나 |
| **TPI** | Transmission Protection Instrument | 스프레드가 **부당하게** 벌어질 때 ECB가 특정국 국채를 사줄 수 있는 **방화벽**. 평시에는 **미가동** |

### 주식

| 이름 | 뭐냐 | 왜 보나 |
|------|------|---------|
| **Euro Stoxx 50** | 유로존 대형주 50 | 지역 대표 지수 (S&P500 자리) |
| **Euro Stoxx Banks** | 유로존 **은행주** 지수 | 금리·신용·남유럽 리스크가 은행에 먼저 탐. 분절화·대출태도와 같이 봄 |
| **DAX / CAC** | 독일 / 프랑스 대표지수 | 역내 최대 경제권 온도 |

### 물가 — “기준이 뭐야?”

| 이름 | 뭐냐 | 기준 |
|------|------|------|
| **HICP** | Harmonised Index of Consumer Prices. **EU가 맞춘 소비자물가** | **ECB 물가 목표의 공식 지표** |
| **ECB 목표** | | **중기 2%**(HICP YoY). “적합한가?” → **이 키트의 물가 기준은 ECB 공식 목표=HICP 2%** |
| **근원 HICP** | 에너지·식품 제외 등 | 일시 충격을 걷어낸 끈적한 물가 |
| **협약임금 (negotiated wages)** | 노사 협약으로 정한 임금 상승 | 서비스 물가를 밀어 올리는 **임금 끈적임**. ECB가 근원물가와 같이 봄 |

미국이 Core PCE를 중시하듯, **유로존은 HICP(및 근원 HICP)** 가 정책 기준이다.  
CPI라는 이름 대신 HICP를 쓰는 이유는 회원국 통계를 **같은 방식으로 비교**하려고 EU가 표준화했기 때문.

### 고용 — “미국 4%랑 비교해도 돼?”

유로존 실업률 해석 앵커는 대략 **6–7%**(권역 평균·구조실업). **미국 U3 ≈4.2%와 숫자 비교 금지.**  
독일은 낮고 남유럽은 높아 **권역 평균이 가린다** — Bund/BTP처럼 국가 편차를 같이 보라.

## 이 키트에 넣은 논리 (기준)

1. **정책금리** → DFR (+ corridor)  
2. **QE/QT** → APP · PEPP · 월간 순매입 바 · ECB 총자산  
3. **통화량** → M3 (ECB 관행)  
4. **분절화** → BTP−Bund · (보조) CDS/등급 · TPI 가동 여부  
5. **실물** → GDP · 독일/유로 PMI · 대출태도  
6. **물가** → HICP / 근원 / 협약임금 (**목표 2%**)  
7. **위험자산** → Stoxx50 · **Banks** · DAX/CAC

## 한계

- 유로존 **평균**은 독일 vs 남유럽 격차를 가린다 → 그래서 Bund/BTP를 같이 둔다  
- PEPP·TPI가 있으면 스프레드가 “진짜 시장 가격”보다 눌릴 수 있다  
- M3↑이 곧바로 대출·물가로 안 이어질 수 있다
