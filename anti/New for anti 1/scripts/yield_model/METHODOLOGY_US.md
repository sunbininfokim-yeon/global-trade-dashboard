# 미국 콘벨트 작황 예측 모델 — 방법론 정리

작성 기준: 2026-08-02 · 대상: 옥수수(corn), 대두(soybeans) · 지역: 미국 콘벨트 8개 주

---

## 1. 핵심 구조 — 왜 "수확량"이 아니라 "추세 대비 편차"를 예측하는가

```
수확량 = 기술 추세(technology trend)  +  기상 편차(weather deviation)
                    ↑                            ↑
          품종·비료·기계화·경영개선          모델이 예측하는 부분
```

**근거**: FAO 『Review of Crop Yield Forecasting Methods』(Basso, Cammarano, Carfagna)가 정리한 Thompson(1969, 1986) 방법론.

> 대면적 평균 수확량을 시간에 회귀시켜 추세를 도출한다. 이 추세는 **유전·경영 개선, 특히 비료 사용 증가**를 포함한 기술 진보를 담는다. **추세로부터의 편차**를 지역 월별 기상자료와 상관시킨다.

**중요**: 비료·품종 데이터를 따로 수집하지 않는다. 추세가 이미 흡수하고 있기 때문. 이것이 표준 절차다.

- 실측된 미국 옥수수 기술 추세: **연 +2.30 bu/acre**
- 참고(브라질 남부 대두 실증연구): 연간 증가분 = 경영개선 44% + 육종 42% + 기후 14%

**추세값의 의미**: "기상 변수가 전부 평년(편차 0)이었다면 나왔을 단수". 2026년 옥수수 추세 = 198.0 bu/acre.

| 예보 | **Open-Meteo** (16일) | — | 불필요 |

### ⚠️ 기상 소스를 NASA POWER로 정한 이유 (중요한 교훈)

처음엔 Open-Meteo를 썼으나 **토양수분에 데이터 불연속**을 발견했다.

```
브라질 고이아스 1~2월
  2024: 강수 348mm → 토양수분 0.4634
  2025: 강수 348mm → 토양수분 0.3511  (−24%)
```

강수량이 **완전히 동일한데 토양수분만 24% 급락** — 물리적으로 불가능. NASA POWER는 같은 기간 0.716 → 0.754로 오히려 상승(실제로 그해는 기록적 풍작).

이걸 못 잡았다면 **−800 kg/ha 틀린 예측**을 "AI 예측"으로 배포할 뻔했다.
**교훈: 단일 소스를 믿지 말고 물리적 정합성(강수 vs 토양수분)을 교차검증할 것.**

## 3. 변수 설계 — 전부 문헌 근거

### (1) 모든 기상 변수는 **편차(anomaly)** 로 변환

직전 **20년 이동 평년** 대비 표준화: `(올해값 − 평년) / 표준편차`

**왜 원값을 쓰면 안 되는가** (브라질 1차 시도에서 실패한 원인):

기상 변수 자체가 수십 년 추세를 갖는다. 브라질 협실비대기 토양수분은 43년간 −0.094 하락(r_시간 = −0.63). 원값을 넣으면 모델이 **"최근일수록 조건이 나쁘다"** 고 학습하는데, 실제 수확량은 기술 발전으로 계속 올랐다. 결과는 **체계적 과소예측**(최근 10년 오차가 거의 전부 음수).

편차로 바꾸면 장기 기후 드리프트는 이동 평년이 흡수하고 **"올해가 평년보다 얼마나 이상한가"** 만 남는다.

### (2) 고온은 **EDD(극한 적산온도)**, 일수 카운트가 아님

**근거**: Schlenker & Roberts (2009)

> 옥수수 3°C까지 **°C당 −8.2%**, 대두 −5.7%. 그 이상에서는 각각 −10.4%, −10.6%로 **가팔라짐**

손상이 비선형이므로 "34°C 넘은 날 수"로는 그 형태를 담을 수 없다.

```
EDD = Σ max(0, 일최고기온 − 임계온도)
임계: 옥수수 29°C, 대두 30°C
```

### (3) VPD(증기압차) 추가

**근거**: Urban et al.(2015), Roberts et al.(2012), Lobell et al.(2014) — 미국 옥수수의 강력한 예측변수.

기온과 습도를 결합해 "덥고 건조함"의 복합 스트레스를 단일 변수로 포착.

```
VPD = es(Tmax) − ea(Tdew)     (Tetens 포화수증기압 식)
```
일평균이 아닌 **일최고기온** 기준 — 작물이 실제 겪는 최대 대기 수요를 반영.

### (4) 파종 전 강수 (9월~6월)

**근거**: Thompson(1986)이 미국 중서부 5개 주에서 **파종전 강수(9~6월), 6월 기온, 7·8월 기온·강수**가 추세편차와 강한 상관임을 확인. 토양수분 충전(recharge)을 나타냄.

### (5) 최종 변수 목록 (core 7개)

```
july_edd_anom           7월 극한적산온도
julaug_edd_anom         7·8월 극한적산온도
julaug_vpd_anom         7·8월 증기압차
julaug_precip_anom      7·8월 강수
preseason_precip_anom   파종전(9~6월) 강수
julaug_soil_anom        7·8월 근권토양수분
oni_growing             생육기 엘니뇨 지수(AMJ~ASO 평균)
```

### 실험: 주별 모델링이 더 나은가?

| 설계 | 옥수수 RMSE | 옥수수(2012 제외) | 대두 RMSE |
|---|---|---|---|
| A. 가중평균 (현재) | **4.37** | 3.53 | 2.79 |
| B. 패널(주별 데이터 + 공유 기상모델) | 5.55 | **3.43** | **2.11** |

- **대두는 패널(B)이 명확히 우세** (오차 −24%). 표본이 34 → 272로 늘어 계수 추정이 안정
- **옥수수는 판정 유보** — 전체 기간엔 A 우세지만 2012년 제외 시 B가 근소 역전. 14개 시즌뿐이라 결정적이지 않음

## 5. 모델 및 검증

**모델**: RidgeCV (정규화 강도는 fold 내부 CV로 결정) — n=34에 변수 7~22개라 정규화 필수

**검증 3중 장치**:

1. **전진검증(forward-chaining)** — `연도 < Y`로만 학습해 Y 예측. **이것이 신뢰할 숫자**. 실제 예보와 동일 조건
2. **추세를 fold 안에서 재적합** — 전체 기간으로 추세를 먼저 구하면 미래 정보가 모든 학습셋에 누수됨
3. **추세만 쓰는 베이스라인과 항상 비교** — 기상이 "그냥 추세대로"를 못 이기면 무의미

**보고 지표**: `skill = 1 − RMSE/RMSE_추세만`, `추세제거 R²` (문헌의 "기상이 변동의 X% 설명"과 같은 기준)

## 6. 성능 (1992–2025, 34시즌 / 검증 14시즌)

| 작물 | 추세 대비 오차감소 | 추세제거 R² | 상관 r |
|---|---|---|---|
| **옥수수** | **+69.3%** | 0.906 | +0.968 |
| **대두** | +39.1% | 0.552 | +0.762 |

**옥수수 단서**: 2012년 대가뭄이 검증기간 편차 분산의 **75.8%**를 차지. 그 해를 빼면 R² = **0.679**. 이것도 문헌의 30~50%를 웃돌아 단일 이상치 의존은 아님. (2012 실제 −46.3 → 예측 −36.1로 방향·규모 모두 포착)

### 변수 중요도가 문헌을 독립적으로 재현

```
july_tmean_anom   r=−0.635   ← Thompson(1986)의 7월 기온
```

## 7. 시즌 중 예측 (2026 적용 예)

관측 → 예보 → 평년값 3단계로 시즌을 조립:

1. **관측**: NASA POWER (2~3일 지연)
2. **예보**: Open-Meteo 16일
3. **평년값**: POWER 과거의 일자별 정규값 (예보 범위 밖)

**신뢰구간을 미관측 비율만큼 확대**: σ = 모델σ × (1 + 0.5 × 미관측비율). 시즌이 진행될수록 자동으로 좁아짐.

**2026년 결과 (7월 완료, 8월 진행중, 7·8월 창의 48% 관측)**

```
옥수수  191.6 bu/acre  (68% 186.1–197.1)   추세 198.0, 기상효과 −6.7
대두     57.0 bu/acre  (68%  54.4–59.7)    추세  57.4, 기상효과 −0.5
ONI +0.98 (엘니뇨)

주요 편차: 파종전 강수 −0.57σ, 7월 EDD +0.34σ, 7·8월 강수 −0.24σ
→ 옥수수만 크게 불리한 이유: 수분기 고온 민감도가 대두보다 높음(−8.2%/°C vs −5.7%/°C)
```

**전국 환산**: 콘벨트 8개주 단수는 전국보다 높음(2024년 194.9 vs 179.3). 33년 비율이 안정적(옥수수 0.93±0.02, 대두 0.92±0.02)이라 최근 5년 평균으로 환산.
※ 이 변환 오차는 위 신뢰구간에 포함되지 않음.

## 7-1. 시도했다가 기각한 개선안 (중요)

문헌 근거가 있는 아이디어 3가지를 붙여봤고, **대부분 성능이 나빠져 채택하지 않았다.**
전부 전진검증으로 측정했고, 비교는 항상 동일 구간에서 했다.

### ① 수분기(silking) 정렬 창 — 기각

"고정 7월 대신 실제 수분 시기 ±2주" — 농학적으로 타당해 보였으나 결과는 명확히 악화.

| | 옥수수 | 대두 |
|---|---|---|
| base | **4.37** | **2.79** |
| + 수분기창 | 8.97 ❌ | 3.00 ❌ |

**원인**: 수분기 표준편차가 ±6~8일뿐이라 실제 창(28일)이 7월(31일)과 거의 겹친다.
**새 정보는 거의 없는데 변수만 4개 늘어난** 전형적 과적합.

### ② 파종 지연 — 대두만 소폭 개선, 근거 약함

| | 옥수수 | 대두 |
|---|---|---|
| base | **4.37** | 2.79 |
| + 파종지연 | 5.91 ❌ | **2.53** |

대두 계수 −1.250(파종 늦으면 감수, Thompson과 부호 일치), 잔차 상관 r=−0.352.
다만 **2012년 제외 시 R²가 −0.062로 붕괴** — 이득이 한 해에 의존. 미채택.

### ③ MODIS NDVI — 기각

NDVI 자체는 **가장 강한 단일 상관**을 보인다(옥수수 추세잔차 대비 r=+0.801,
기존 최강 변수 july_tmean의 −0.635보다 높음). 그런데 모델에 넣으면 나빠진다.

| (동일 21시즌) | 옥수수 | 대두 |
|---|---|---|
| base | **4.28** | 2.80 |
| + NDVI 7·8월 | 5.31 ❌ | 3.48 ❌ |
| + NDVI 최대 | 5.17 ❌ | 2.81 |
| + NDVI 3개 | 4.85 ❌ | 2.57 |

**원인**: NDVI가 낮은 이유가 바로 고온·건조이고, 그건 EDD·VPD가 이미 재고 있다.
**NDVI는 원인이 아니라 결과** — 중복 정보를 넣으며 파라미터만 늘린 셈.

> **공통 교훈**: n=21~34에서는 "기존 변수와 정보가 겹치는 변수"는 예외 없이 순손실이다.
> 농학적으로 옳은 아이디어라도 **새 정보인지를 먼저 확인**해야 한다.

### NDVI를 버리지는 않는 이유

수집 파이프라인(`collect_ndvi.py`)과 데이터는 유지한다. 예측 모델에는 넣지 않지만:
- **시즌 중 실시간 모니터링** — 16일마다 갱신되는 직접 관측. 8월이 예보·평년값으로
  채워지는 시점에 "실제 작황이 어떤지"를 보여주는 유일한 실측
- **화면 표시용 현재 작황 지표**로는 유효
- 표본이 더 쌓이면 재검증 가치 있음

## 7-2. 오차의 원인 진단 — 데이터 부족인가, 모델 문제인가, 기후의 한계인가

세 가지를 측정해 구분했다.

### 옥수수 — 기후 설명력의 한계에 도달

```
학습곡선   12년 +32% → 16년 +37% → 20년 +66% → 24년 +70% → 전체 +69%
                                                  ↑ 24년에서 포화
과적합     인샘플 RMSE 4.87  vs  아웃샘플 4.37  → 격차 0.90배 (과적합 없음)
잔차       연도간 자기상관 +0.07 = 백색잡음
```

세 신호가 일치한다. **데이터를 더 줘도, 모델을 바꿔도 크게 나아지지 않는다.**
남은 오차 ±4.4 bu/acre는 기후 밖 요인(병해충, 종자 선택, 국지 우박, 통계 오차).

### 대두 — 데이터 부족

```
학습곡선   12년 +2.8% → 16년 -2.2% → 20년 +10.7% → 24년 +13.1% → 전체 +18.6%
                                                     ↑ 아직 상승 중
과적합     인샘플 49% vs 아웃샘플 20% → 계수가 불안정
```

학습곡선이 **아직 안 꺾였다**. 표본이 늘면 계속 좋아진다.
§4의 패널 실험(34→272 표본에서 오차 −24%)이 같은 결론을 독립적으로 지지한다.

**단, 운영 단순성을 위해 가중평균 방식을 유지하기로 결정했다.** 패널 전환은
성능 근거가 있으나 구조 복잡도가 올라가므로, 시즌이 더 쌓인 뒤 재검토한다.

## 8. 알려진 한계

1. **주당 기상 샘플링 지점이 1곳** — 주 전체 공간 평균이 아님
2. **고정 달력 창** — 실제 파종·수분 시기가 아닌 6/7/8월 고정. NASS 생육진행률(PCT PLANTED / SILKING, 1992~)로 개선 예정
3. **추세가 선형** — piecewise/LOESS 등 대안 미검토
4. **다른 지역으로 외삽 불가** — FAO 리뷰 명시: *"통계 모델의 결과는 토양·지형·기상 차이 때문에 다른 공간·시간으로 외삽할 수 없다"*. 지역마다 별도 모델 필요
5. **검증 시즌 14개** — 설계 간 비교(§4)의 통계적 검정력이 약함
6. **NDVI 미포함** — 실험 결과 성능 악화로 기각 (§7-1). 데이터·수집기는 유지

## 9. 다른 작물에 그대로 쓰면 안 되는 경우

기상이 수확량 변동의 30~50%를 설명한다는 건 **조건부**다.

**신호가 강한 곳** (이 방법론 적용 가능)
천수답 + 1년 1작 + 기계화 → 미국 콘벨트, 아르헨티나 팜파스, 호주 밀, 우크라이나·러시아 밀, 브라질 대두

**신호가 약해 별도 구조가 필요한 곳**
- **인도 쌀·이집트 밀** — 관개 의존이라 강수와 수확량이 분리됨
- **팜유·커피·카카오** — 다년생. 나무 수령, 격년결실, **2~3년 전 기상의 지연 효과** → 지연변수 포함 모델 필요
- **네덜란드 시설재배** — 외부 기상 거의 무관

## 9-1. 밀 (겨울밀 / 봄밀) — 별도 모델

옥수수·대두와 물리가 달라 각각 별도 변수 설계를 썼다. 참고 문서:
`Regions/미국/대평원_GreatPlains/밀`, `Regions/미국/북부대평원_NorthernPlains/봄밀`

### 성능

| 작물 | 지역(가중) | 추세 대비 | 추세제거 R² | 판정 |
|---|---|---|---|---|
| **겨울밀** | KS .34 OK .15 TX .13 CO .13 NE .13 MT .12 | **+31.3%** | 0.521 | 사용 가능 |
| **봄밀** | ND .50 MT .22 MN .15 SD .13 | +13.4% | 0.247 | **신뢰도 낮음** |

### 겨울밀 — 물이 지배한다

```
spring_soil_anom    r=+0.732     heading_edd_anom  r=-0.472
winter_soil_anom    r=+0.654     heading_vpd_anom  r=-0.462
heading_soil_anom   r=+0.624
spring_precip_anom  r=+0.565
```

반건조 대평원이라 토양수분·강수가 압도적. Kansas State가 지목한
**"덥고·건조하고·바람 부는(hot-dry-windy)"** 복합 사건을 `heading_edd` + `heading_vpd`
+ `spring_soil` 조합이 포착하고 있다.

**⚠️ 참고 문서가 강조한 변수는 신호가 없었다.** 문서의 서리 패널티 공식
`Σ max(0, T_crit − T_min)`을 그대로 구현했으나:

```
winter_chill_anom  (춘화처리)   r=+0.020   ← 사실상 무상관
winter_freeze_anom (동해)       r=-0.104
heading_frost_anom (서리)       r=-0.071
spring_frost_anom               r=-0.220
```

서리 최다 3개년(1996·2002·2019) 중 **2019는 오히려 +8.1 증수** — 방향이 엇갈린다.
이 지역·이 기간에서는 서리가 지배 요인이 아니다. (변수는 core에 남겨 두어
향후 재검증이 가능하게 했다.)

또한 **기술 추세가 매우 약하다**: 연 +0.25 bu/acre, 추세 R²=0.240.
옥수수(+2.30, R²=0.776)와 대조적 — 겨울밀은 지난 30년 품종 개량 투자가 적었다.

### 봄밀 — 비정상성 때문에 고정 계수가 실패

처음에는 **추세만 쓰는 것보다 나빴다**(−1.0%, 전체 변수는 −40.1%).
단일 상관은 멀쩡한데(flowering_edd r=−0.578) 모델은 무너지는 전형적 패턴.

**원인**: Lanning et al. (2010, Crop Science) — 몬태나 봄밀 1950~2007 분석

> 따뜻해진 봄에 따른 **조기 파종**과 **조기 출수 품종 육종**으로 7월 고온을 회피하게 되면서

즉 **"7월 고온 → 감수"의 관계 자체가 시간에 따라 약해져 왔다.** 34시즌에 하나의
계수를 맞추면 서로 다른 두 규제(regime)의 평균을 추정하게 된다.

**해법: 20시즌 이동창** (최근 20년으로만 재적합 = 가장 단순한 시변계수 모델)

| 방식 | 추세 대비 |
|---|---|
| 고정(전체 과거) | +3.3% |
| 최근 15년 | +0.2% ← 표본 부족 |
| **최근 20년** | **+13.4%** ✅ |
| 최근 25년 | +10.4% ← 낡은 규제 유입 |
| 지수가중(반감기 5~12년) | +6~7% |

**지수가중이 이동창보다 나쁘다**는 점이 중요하다. 오래된 데이터를 낮은 가중치로
남기는 것보다 **완전히 버리는 게 낫다** — 점진적 드리프트가 아니라 실제로 관계가
바뀌었다는 증거다.

**정식 시변계수(칼만/상태공간)는 n=34에서 불가능**하다. 이동창이 현실적 대안.

**단, +13.4%는 낮다.** 화면에 표시할 경우 신뢰도가 낮음을 명시해야 한다.

### 미검증으로 남긴 것

- **풍속(WS2M)**: Kansas State가 hot-dry-**windy**를 복합 사건으로 지목하나,
  VPD가 이미 heat+dry를 담고 있어 중복 가능성이 높다. §7-1의 3연속 기각 전례를
  감안해 우선순위를 낮춤
- **병해**: "Weather, Disease, and Wheat Breeding Effects on Kansas Wheat Varietal
  Yields, 1985–2011"이 별도 논문으로 존재할 만큼 중요. 겨울밀 잔차 ±3.63의
  상당 부분이 여기일 수 있음

```
scripts/yield_model/
├── collect_us_cornbelt.py   수집: NASS 수확량 + POWER 기상 + ONI → 학습 테이블
```
