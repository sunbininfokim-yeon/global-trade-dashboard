# FuelEU 풀링 시장·준수 잔액 (로컬 도구)

FuelEU Maritime(Regulation (EU) 2023/1805)의 선박별 준수 잔액을 항차 단위로 계산하고,
풀 매입·차입·부담금·이월 중 비용을 비교한다. 풀 가격은 공개 월간 해설에서 수집한 시계열을 쓴다.

담당: Claude (TASKS CF02). 해운 탄소금융 ETS 쪽(`tools/shipping_carbon/`, Codex CF01)과는
아직 합치지 않았다. 통합은 Codex의 해운 탄소 전체 구조가 정해진 뒤에 한다.

## 실행

```bash
cd tools/fueleu
python3 collect_pool_prices.py      # 공개 해설 수집 → source_data/pool_prices.json
python3 server.py --port 8772       # http://127.0.0.1:8772
python3 -m pytest -q                # 엔진·파서 테스트
```

## 가격 자료

- FuelEU 잉여분은 거래소 상품이 아니라 선사 간 풀링(양자 계약)으로 거래되며 공식 가격이 없다.
- 키 없이 얻을 수 있는 시계열은 OceanScore Pool-Price Index(OPX) 월간 해설뿐이다.
  OPX는 공개 호가 기반 지수라 체결가가 아니다. BetterSea 등 체결가 자료는 공개 경로가 없다.
- 수집기는 해설 문장에서 월별 지수, 호가 범위, 대상 준수연도, 전월 재기재 값을 뽑고 근거 문장을 남긴다.
  2026년 4월 말 풀링 마감 전까지는 2025년분, 이후는 2026년분으로 보되, 문장에 연도가 적혀 있으면 그걸 따른다.
  해설이 없는 달(2025-07, 2025-12, 2026-01)은 비워 두고 그래프 선을 잇지 않는다.
- **재배포 미확인.** OceanScore 약관은 자사 제품 정보의 재배포를 금지하며, 공개 해설이 여기에 포함되는지
  확인하지 못했다. 그래서 수집 결과는 `source_data/`(git 제외)에만 두고 공개 사이트에 올리지 않는다.
- EUA 가격(EEX 경매)은 Codex의 `tools/shipping_carbon/collect_prices.py`가 맡는다. 겹쳐 만들지 않았다.

## 화면 구성 (업계에서 보는 순서)

1. **규칙과 가격 범위**: 한도 계단(2025~2050)과 연료별 집약도, 연료마다 부족으로 바뀌는 해, 부담금 상한, 원문 확인된 연간 일정.
2. **풀 가격 추이**: OPX 월별 시계열과 호가 범위.
3. **수급 구조**: EMSA MRV 기반 선종별·추진 연료별 잉여/부족 추정, 2024→2025 변화, 2030·2035 한도 적용 시.
4. **선박 판정**: 총톤수·연료·EU 노출 비중을 넣으면 잉여/부족과 전환 시점.
5. **항차·거래**: 항차별 잔액과 비용, 매입·차입·부담금·이월 비교, 선대 상쇄.

## 수급 구조 추정 (mrv_supply.py)

FuelEU 데이터베이스는 비공개라 시장 전체 공식 잉여/부족 수치가 없다. EMSA MRV 공개 자료(선박별 연간
연료량, CO₂·CH₄·N₂O를 EU 역내·출항·입항·정박으로 나눈 값)로 선박별 집약도와 잔액을 추정해 합산한다.

- CO₂/연료 비율로 석유(3.11~3.21)와 LNG(2.75)를 가르고, CH₄/연료로 LNG(메탄 슬립)를 판별한다.
- TtW는 선박이 보고한 CO₂·CH₄·N₂O를 그대로 쓴다(보고된 슬립 반영). WtT·LCV는 연료 판별에 따른다.
- FuelEU 반영 비율 = (EU 역내 + EU 항구 내 + 출항·입항의 절반) ÷ 전체.
- 2025년(v80) 결과: LNG 추진선 756척(2024년 451척), 잉여 약 63만 t, 석유선 부족 약 237만 t.
  장부상 순부족이지만 시장 해설은 공급 우위라고 한다. 차이는 바이오 혼합으로 메워지고,
  그래서 가격은 바이오 혼합 비용이 정한다고 해석한다.
- 한계: 공식 잔액 아님, 총톤수가 없어 5,000 GT 이하를 못 거름(부족 과대), 바이오 혼합 선박 제외(잉여 과소),
  최외곽지역 항해가 역내에 섞임, 풍력·육상전원 보정과 기존 풀링 미반영.
- 결과는 `source_data/`(git 제외). EMSA 재사용 조건은 확인 전이다.

## 계산 (engine.py)

| 항목 | 규정 | 구현 |
|---|---|---|
| 적용 범위 | 제2조(1) | 정박·EU↔EU 100%, EU↔역외 50%, EU↔최외곽지역 50%, 역외↔역외 0% |
| 목표 | 제4조(2) | 91.16 × (1 − 2/6/14.5/31/62/80%) |
| 집약도 | 부속서 I 식(1), 부속서 II | WtT + TtW(슬립 포함), RFNBO 보상계수 2(2033년까지), 풍력 보정 |
| 준수 잔액 | 부속서 IV A | (목표 − 실제) × 에너지 |
| 부담금 | 부속서 IV B, 제23조(2) | \|CB\| ÷ (실제 × 41,000) × 2,400 EUR, 연속 배수 1 + (n−1)/10 |
| 차입·이월 | 제20조 | 한도 2% × 목표 × 에너지, 1.1배 상환, 연속 차입 불가 |
| 풀 유효성 | 제21조(4) | 합계 양수, 부족 선박 악화 금지, 잉여 선박 부족 전환 금지 |

- 부속서 I·IV 식은 EUR-Lex에서 이미지라, 옆의 기호 표대로 구성했다. HFO 91.744, LFO 91.392,
  MGO 90.767, LNG(오토 중속) 89.203 gCO₂e/MJ로 알려진 값과 맞는지 테스트로 고정했다.
- GWP100(CH₄ 25, N₂O 298)은 부속서 I이 가리키는 Directive 2018/2001 부속서 V C(4)의 값이다.
- 바이오·e-연료는 인증 경로별 WtT가 필요해 기본값을 넣지 않았다. 사용자 정의 연료로 넣는다.
- EEA(노르웨이·아이슬란드) 적용 여부와 인근 컨테이너 환적항 목록은 확인 전이라 하드코딩하지 않았다.

### 업계 방식 반영

준수 관리 도구는 항차 단위로 계산한다. 이 엔진도 같다.

1. 항차(출발항→도착항)마다 MRV·정오보고 연료량을 받는다.
2. 두 항구의 관할로 적용 비율을 자동으로 정한다.
3. 실적 항차와 예정 항차를 합쳐 연말 잔액을 예측한다.
4. 항차별 비용은 그 항차를 뺀 연간 결과와의 차이로 정확히 계산한다(RFNBO가 있으면 비례 배분이 틀린다).
   용선계약 FuelEU 조항의 청구 근거가 된다.
5. 선대 안에서 먼저 상쇄하고 남는 부족·잉여만 외부 풀로 거래한다.

## 범위 밖

실제 선박의 항차·연료 자료(예제는 가상), RFNBO 하위목표(2034년~), 얼음 항해 보정, 중개 수수료·자금비용·
거래상대 신용, 공개 사이트 메뉴·배포. EMSA MRV 연간 자료(Codex #794)로 선박별 기준선을 잡는 것은
통합 단계에서 한다. MRV 공개 자료는 항차별이 아니라 연간 합계라 항차 계산에 바로 쓰지 못한다.
