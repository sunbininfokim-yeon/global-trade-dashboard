# “키를 찍는다” / 학습 신호 — 운영 설명

## 한 줄
뉴스를 딥러닝으로 다시 배우지 않는다.  
**틀린 점수 규칙을 고치라고, 짧은 이름표(key)에 스티커(promote/demote)를 붙인다.**

## 비유
시험 채점 기준이 있음 (1급 피습, 2급 수출통제…).  
가끔 채점이 틀리면 노트에 적는다:

> “`info:4` 로 분류된 게 너무 많이 티커에 남음 → demote”  
> “`source:xyz` 가 연예 섞음 → drop에 가깝게 demote”

그 노트의 **제목줄**이 `key` 다.

## 자주 쓰는 key 예시

| key | 의미 |
|-----|------|
| `geo:1` … `geo:4` | 그 국가급 묶음 전체 보정 |
| `info:1` … `info:4` | 그 정보급 묶음 보정 |
| `USA:cabinet` | 특정 국가+유형 |
| `source:oilprice` | 특정 RSS |
| `region:ssa` | 아프리카 권역 점수 |
| `elevated:pandemic` | 승격 규칙 자체의 신뢰 |

## label 값

| label | 다음 빌드 효과 (개념) |
|-------|----------------------|
| promote | 가중 ×1.2~1.3 |
| keep | ×1.0 |
| demote | ×0.7 |
| drop | ×0.35 또는 필터 제외에 가깝게 |

## 한 뉴스 사례가 “학습에 쓰인다”는 말의 정확한 뜻

1. **실시간:** 규칙만으로 통과/점수 → 티커에 표시.  
2. **사후 (사람):** “이건 과했다”면 관련 key에 demote 한 줄 추가.  
3. **이후 유사 뉴스:** 같은 key에 걸린 점수만 살짝 달라짐.  

기사 본문이 training set에 쌓여 모델이 재학습되는 구조가 **아님**.
