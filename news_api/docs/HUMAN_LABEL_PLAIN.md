# 사람이 라벨을 남긴다는 말 — 쉬운 설명

## 비유
자동 채점기가 뉴스를 점수로 매긴다.  
가끔 틀리면 **사람이 한 줄 메모**를 남긴다. 그게 라벨이다.

## 일상 언어로
- “라벨 남긴다” = 구글 스프레드시트에 “이 규칙은 쎄게 / 약하게” 적기  
- 지금 구조에서는 그 메모가 JSON 한 줄로 파일에 쌓임  
- **매일 기사를 읽고 별을 다는 전임 알바가 필수라는 뜻이 아님**

## 누가 하나 (현실적)
| 주체 | 언제 |
|------|------|
| **선빈(또는 운영자)** | “이거 왜 떴지?” 싶을 때 가끔 |
| **에이전트** | 리뷰 요청 받았을 때 제안 → 사람 확인 후 반영 |
| **안 해도 됨** | 규칙·pair_rank만으로도 티커 동작. 라벨은 **미세조정 옵션** |

## 안 하는 것
- 모든 뉴스에 좋아요/싫어요  
- 딥러닝 데이터셋 구축 의무  
- 수율 모델 재학습

## 한 줄 예
파일이 있다면:

```text
info:3 에 demote  →  “지선급이 너무 잘 뜬다, 좀 줄여”
source:xxx 에 drop 느낌 demote → “이 매체 노이즈”
```

없으면 기본 규칙만 사용.
