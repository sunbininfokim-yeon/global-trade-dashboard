기후·수율과 **무관**. 설정 정본: `news_api/config/`.

## 1. 국가 4급 (geo_tier)

국가급은 “그 나라에서 일어난 일이 우리 대시보드에 얼마나 **배경 무게**를 갖는가”다.  
정보는 아래 2절. **국가 1급 ≠ 정보 1급.**

### 1급 — 구조적 초강대·핵심축
**미 · 일 · 러 · 중** (사용자 지정)

- 일상적 통상 뉴스여도 기본 노출 우선순위가 높다.
- 지방 이야기라도 “무시”보다 “요약 1줄 후보”로 남는 경우가 많다.

### 2급 — 에너지·안보·시장 연동 + 대륙 앵커
- 걸프·전장: 사우디, 이란, UAE, 이스라엘  
- 유럽 주요: 영·프·독  
- 튀르키예 · **브라질** · **인도** · **한국** · 인도네시아 · 남아공·나이지리아(아프 앵커 초안)  

### 3급 — 대륙·권역 “주요국” (구도 이해용)
- 남미: **아르헨티나**, 멕시코, 칠레 등 (브라질 제외)  
- 유럽: 이탈리아·스페인·폴란드·**네덜란드**·**스위스** 등  
- **우크라이나 3급** — 전쟁은 geo를 안 올려도 **정보 1급·critical_escape**로 상단  
- 대만·호주·캐나다, 아세안 다수, CIS 일부, 아프리카 주요 등  

### 허브 키워드 승격 (스위스·암스테르담 패턴)
3·4급 국가라도 **특정 상품 허브 키워드**면 `effective_geo += 1` (캡 보통 2).

| 예 | 기본 geo | 키워드 | 효과 |
|----|----------|--------|------|
| 네덜란드 | 3 | Amsterdam, Rotterdam, ARA barge… | → 유효 2 (해운) |
| 스위스 | 3 | SNB, Zurich, Geneva trading… | → 유효 2 (금융·귀금속) |
| 싱가포르 | 3 | bunker, Strait… | → 유효 2 |

설정: `country_tiers_v1.json` → `hub_boost`.

### 4급 — 그 외 전 국가
기본 노이즈. **단, 4절 승격**이 발동하면 국가급이 낮아도 상단에 뜬다.

### 권역 단위 (대륙 + 연합)
국가 ISO와 **동시에** 권역 태그를 붙인다. (필터·스태거 수집·쿼터)

| 권역 id | 의미 | 포함 감각 |
|---------|------|-----------|
| `na` | 북미 | US, CA, MX |
| `latam` | 남미·중미 | BR, AR, CL… |
| `eu_core` | 유럽 핵심 | GB, FR, DE + EU 주요 |
| `eu_other` | 유럽 기타 | CH, Nordics, 남·동유럽 등 |
| `mena` | 중동·북아프 | SA, IR, AE, IL, EG… |
| `ssa` | 사하라이남 아프리카 | ZA, NG, KE… |
| `cis` | CIS·구소련 권 | RU, UA, KZ, BY… |
| `east_asia` | 동북아 | CN, JP, KR, TW, MN |
| `asean` | 아세안 | ID, TH, VN, SG, MY, PH… |
| `south_asia` | 남아시아 | IN, PK, BD… |
| `oceania` | 오세아니아 | AU, NZ… |
| `global_specialist` | 상품/해운 전문 매체 | 국적 모호한 전문지 |

한 기사는 `geo_tier`(주 국가) + `regions[]`(복수 가능, 예: 제재 뉴스 = `mena`+`east_asia`)를 가진다.

## 2. 정보 가치 4급 (info_grade) — 모호함을 이렇게 푼다

사용자 고민: “1급은 글로벌 뉴스인데 2–4를 어떻게 말할지.”

### 정의 축 (질문 3개)

정보가 모호하면 **아래 3질문에만** 답하게 한다. 점수로 급을 고정한다.

| # | 질문 | 예 |
|---|------|-----|
| Q1 | **지리 전파:** 국경 밖 시장/안보에 직접 닿는가? | 수출금지 O / 시의원 당선 X |
| Q2 | **비가역·희소:** 되돌리기 어렵거나 드믄 상태 변화인가? | 대선 확정·쿠데타·피습 O / 일상 기자회견 X |
| Q3 | **대시보드 연결:** 원자재 물동·환율·유동성·해운·무역제재 중 하나와 명시 연결이 있는가? | 작물 수출통제 O / 연예 정치 X |

### 급 정의 (말로)

| 급 | 한 줄 정의 | 통과 감각 | 예시 (사용자 제안 포함) |
|----|------------|-----------|-------------------------|
| **1** | **글로벌 헤드라인**: 국가 체제·시장·안보의 “상태 전환”이 즉시 읽힘 | 24h 안에 전 세계 데스크가 1면에 둘 수준 | 대통령 **피습/유고**, **전쟁 선포·전면 침공**, **대선/총선 최종 결과(핵심국)**, 갑작스런 **디폴트·자본통제 전면**, **핵·대형 테러** |
| **2** | **국경을 넘는 레버**: 무역·에너지·식량·금융 경로를 비트는 정책/사건 | 상품 창·제재 맵에 바로 그림 | **특정 작물/에너지 수출 통제·쿼터**, 대규모 **제재 패키지**, 해협·파이프 **봉쇄**, 주요국 **개각(외무·재무·국방·에너지)**, **기준금리 서프라이즈**, QRA급 유동성 충격 |
| **3** | **국가 단위 프로세스**: 그 나라 정국·산업에 중요, 글로벌 즉시는 아님 | “모니터링” 줄 | **지방선거·지역구 결과**, 당대표 경선 중간, 통상 **실무협상** 진전, 공장 파업(비핵심 허브), 중기 예산안 1독 |
| **4** | **배경·루틴**: 알아야 할 수도 있으나 티커 기본 제외 | 로그·검색용 | 의례 회담, 지지율 소폭, 일반 시황 복붙, 루머성 기사 |

**2급을 “수출 통제급”으로 잡자는 직관 — 맞다.**  
1급은 “역사 이벤트/정치 연속성 붕괴”, 2급은 “가격·물동 레버”, 3급은 “국내 일정/과정”, 4급은 “소음”.

### 애매할 때 기본 규칙

1. 의심되면 **한 급 낮춘다** (과다 1급 방지).  
2. **국가 1–2급**에서 나온 3급은 티커에 남을 수 있음. **국가 4급**의 3–4급은 기본 폐기.  
3. 국가 4급이어도 Q1+Q2가 강하면 → **승격** (아래).

### 표시 결합 — 사용자 확정 우선순위

단순 곱(`geo_w × info_w`)만 쓰면 (1,3)이 (2,2)를 이길 수 있어 **pair_rank 표가 정본**이다  
(`config/info_value_v1.json` → `pair_priority.rank`).

| 규칙 | 의미 |
|------|------|
| **(2,2) > (1,3)** | 2급 국가의 2급 정보(레버)가 1급 국가의 3급 정보(지선급)보다 **우선** |
| **(1,3) ≈ (3,2)** | 1급×3급 와 3급×2급 은 **거의 동급** (같은 rank 밴드) |
| **(3,2) > (2,3)** | 3급 국가의 2급 정보(수출통제 등)가 2급 국가의 3급(지선)보다 **우선** |

요지: **“정보 레버(2)”가 “국내 프로세스(3)”보다, 국가 한 급 낮은 쪽에서도 세다.**  
국가 1급이라고 지선이 수출통제를 자동 이기지 않는다.

표 일부 (클수록 우선):

| | info1 | info2 | info3 | info4 |
|--|-------|-------|-------|-------|
| **geo1** | 100 | 94 | **72** | 48 |
| **geo2** | 96 | **86** | **64** | 40 |
| **geo3** | 90 | **72** | 52 | 28 |
| **geo4** | 82 | 60 | 36 | 16 |

→ 86(2×2) > 72(1×3)=72(3×2) > 64(2×3).

최종 표시 ≈ `pair_rank` + 소량 신선도 + 라벨 보정 (+ hub/escape 반영 후 geo·info).

## 4. 무엇이 “학습”이고, “키를 찍는다”는 뜻인가

이전 문장이 불친절했다. **풀이:**

### 학습 ≠ 모델 가중치 자동 재훈련
수율 Ridge처럼 계수를 매일 다시 맞추는 게 **아니다.**

여기 학습은:

1. 시스템이 뉴스를 점수 매김 (규칙).  
2. 사람이(또는 리뷰 에이전트가) 나중에 **“이 판단 맞았다/틀렸다”** 를 남김.  
3. 그 메모가 **같은 종류의 다음 기사 점수에 곱해질 숫자**가 됨.

### “키(key)를 찍는다”
라벨 한 줄에 **짧은 이름표**를 붙여 저장한다는 뜻이다.

예:

```json
{"key": "info:1", "label": "promote", "note": "피습은 맞음"}
{"key": "geo:4", "label": "demote", "note": "4급 루틴 정치 과다"}
{"key": "source:rt_ru", "label": "demote"}
{"key": "elevated:pandemic", "label": "keep"}
```

- **key** = “어떤 규칙 묶음에 보정을 줄지” 이름  
- **label** = promote(가중↑) / demote(↓) / drop(거의 제외) / keep(현상)

파일에 한 줄 추가 = “그 이름표가 붙은 점수에 0.7배 하라” 같은 식.  
**뉴스 전문을 딥러닝에 넣는 것이 아니다.**

### “한 뉴스가 학습에 쓰이는 법” 예시가 의미한 것
그 표는 **교육용 시나리오**였다.  
“이 제목이면 통과/드롭이고, 사람이 나중에 어떤 key에 투표할 수 있는지”를 보여 준 것이지,  
이미 자동으로 신경망이 학습한다는 뜻이 **아니었다.**

| 뉴스가 실제로 하는 일 | 학습에 쓰이나? |
|----------------------|----------------|
| 티커 JSON 한 줄로 **표시** | 표시용 (필수) |
| rank_reasons에 왜 떴는지 기록 | 디버그 |
| 사람이 demote key 추가 | 그때부터 같은 패턴 점수 변화 |
| 수율 training.csv 행 추가 | **안 함** |

## 6. 유동성 (주기 수정)

- **결론: 6시간 크론 불필요 → 하루 1회면 충분.**  
- 이유: 지표 공표는 일·주 단위, 속보는 이미 30분 언론 배치가 돈다.  
- **양영빈 등** = “특수 학습 모델”이 아니라 **일반 언론 슬롯 + 지표 사전(FIMA/TGA/RRP…)으로 키워드 스캔**하는 한 소스.  
- **BOK** = 공식 C축(일 1 또는 공표 캘린더)에 편입.  
- 타임: KST 아침 고정 1회 (예: 08:10) + 분 분산 스케줄에 맞춤.

## 7. 수집 주기: 30분 격자 + 권역 스태거

**아이디어 채택:** 전 피드를 00/30에 동시 폭주시키지 않는다.

- **격자:** 매 시간 `HH:00–HH:29` 와 `HH:30–HH:59` 에 한 번씩 “슬롯”  
- **권역 offset:** 권역마다 고정 분 (예: mena=:03, asean=:07, cis=:11 …)  
- 구현: GitHub Actions는  
  - (A) **워크플로 여러 개** 권역별 cron, 또는  
  - (B) **단일 잡 5분 cron**이 “지금 분에 해당하는 권역만 fetch”

권장 **(B)** — Actions 수 폭증 방지.

예시 분 배정 (`region_schedule_v1.json`):

| 분 (:00 반) | 권역 |
|-------------|------|
| :03 | mena |
| :06 | south_asia |
| :09 | east_asia |
| :12 | asean |
| :15 | cis |
| :18 | latam |
| :21 | ssa (아프리카) |
| :24 | eu_core + eu_other |
| :27 | global_specialist + na (보조) |

:30 반에는 같은 offset +30 ( :33 mena … ).  
→ **각 권역은 30분마다**, 전 세계 동시 스파이크는 없음.

## 9. “소스 리스트 초안” / “매핑 코드” — 무슨 말이었나

제안을 설명한 것이지, 이미 구현한 작업이 아니다.

### 소스 리스트 초안
지금 MENA·인도 쪽은 언론 **이름+RSS URL 표**가 있다.  
아프리카·남미·CIS·아세안은 권역 칸은 있는데 **그 표에 넣을 매체 후보가 비어 있다**는 뜻.

- “다른 국가처럼” = 알자지라 넣듯 **Africanews 한 줄**을 후보로 적자  
- 국가 1–4급을 언론마다 복제한다는 뜻이 **아님** (국가는 ISO, 소스는 feed)

### 매핑만 코드
예전에 A/B/C 티어로 쓰던 점수를, 여기 **1/2/3/4** 와 숫자만 연결하자는 뜻.  
뉴스 엔진을 통째 다시 짠다가 아님.

## 10. 한 페이지 요약

1. **국가 1–4 / 정보 1–4** + pair_rank + hub/escape 승격  
2. 정보 1=글로벌 충격, 2=레버, 3=프로세스, 4=소음  
3. 권역·스태거·일 1 유동성  
4. 라벨 = **선택적** 메모 보정 (필수고도 딥러닝도 아님)  
5. `news_api/` 정본, 기후 분리
