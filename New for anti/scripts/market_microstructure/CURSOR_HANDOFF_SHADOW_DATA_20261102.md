다음의 작은 보강/확인만 요청한다. 전체 데이터셋 교체나 모형 재학습은 하지 않는다.

1. **당일 KODEX 200 가격의 반복 갱신 경로**
   - 보정 후보 엔진은 새 15007 콜/풋 외에 069500의 당일 OHLC와 직전 20거래일 가격이 필요하다.
   - 현재 `kospi200_etf_candidates_daily_v1.json`의 069500 행은 2026-10-30까지다.
   - 기존 FDR/Naver 시세 수집 경로를 우선 재사용해 이후 완료 거래일을 갱신할 수 있게 준비한다.
   - 기존 수정가격과 새 가격을 섞지 않는다. 배당·분배락 전후와 겹치는 기간의 정의를 대조한다.
   - 수집 실패/장중 미완료 자료는 missing으로 남긴다. 전일 가격으로 새 날을 만들지 않는다.
   - 일일 workflow 연결은 Claude 소유이며, Cursor는 수집/정규화 경로와 완료 조건을 인계한다.

2. **실제 만기일 메타데이터**
   - 기존 KRX 15018/종목 원본에서 `contract_code`, 상품명, 월물, 실제 만기일을 먼저 확인한다.
   - 표준 월물과 위클리를 구분하고, 확인 가능한 실제 만기일만 `expiry_date`로 보존한다.
   - 만기월 YYYYMM에서 임의로 둘째 목요일을 계산해 확정 관측값으로 만들지 않는다.
   - 원본에 실제 만기일이 없으면 null과 확인 실패 사유를 보고한다. 화면 번호를 추정해 새 조회하지 않는다.
   - 별도 계약 메타데이터 표를 만든다. 여러 만기를 기존 `kospi200_option_oi`에 섞으면
     기존 빌더의 (date, call/put, strike) 중복 제거 키가 만기를 구분하지 못하므로 금지한다.

3. **시간 기준**
   - 앞으로 거래일, 세션(정규/야간), 원천 시각·시간대(있는 경우), 실제 수집 시각을 따로 기록한다.
   - 파일 mtime을 제공처 공개 시각으로 쓰지 않는다. 과거 공개 시각은 증거 없으면 unknown.
   - 미국 자료와 결합할 때는 미국 거래일과 KST 달력 날짜를 분리한다. 잘 맞는 하루 오프셋을 골라
     UTC/KST 보정으로 주장하지 않는다. 이번 연구의 lag=1은 단순 지연 민감도 실험이다.
