## 기간을 세 가지 질문으로 나눔

입력은 t일까지로 고정하고, h는 KRX 거래일 기준 1·2·3·4·5 모두 사전 지정했다.

1. **누적 방향:** `close(t+h)`가 `close(t)`보다 위/아래인가.
2. **지연된 하루 방향:** h번째 하루의 종가가 그 직전 거래일 종가보다 위/아래인가.
3. **첫 개장 이후 방향:** `close(t+h)`가 `open(t+1)`보다 위/아래인가.

h번째 시가 갭과 장중 시가→종가 방향도 별도 집계한다.
처음 오른 가격이 유지되는 것과 5일째 뒤늦게 오르는 것을 구분한다.
결측을 건너뛰어 다음 관측일을 h번째 거래일로 바꾸지 않는다.

5일 미래 가격을 모두 가진 **같은 511개 source 날짜**를 각 종목의 관측 비교에 사용했다.
source 2024-09-11~2026-10-23, 최종 가격 대상 2026-10-30.
원래 1일 분석의 177쌍과 기간/분모가 다르므로 수치를 직접 이어 붙이지 않는다.
관측 빈도는 상승·하락·동가를 모두 남긴다. 합이 100%이며 동가를 하락으로 넣지 않는다.

## 비율의 정의

| 지표 | 정의 | 성격 |
|---|---|---|
| 외국인 1일 수급 비율 | 당일 순매수 주식 수 / 당일 주식 거래량 | 거래 흐름 |
| 외국인 5일 수급 비율 | 과거 5거래일 순매수 주식 수 합 / 같은 5일 거래량 합 | 거래 흐름; 1일 비율의 단순 합/평균 아님 |
| 제공처 외국인 보유율 | 원본 `foreignerHoldRatio` | 보유 상태; 분모 기준 확인 필요 |
| 보유율 1일/5일 변화 | source 보유율 − 정확한 직전/5거래일 전 보유율 | 퍼센트포인트 변화 |
| LETF 롱 노출 비율 | 양수 L의 AUM×L 합 / 모든 상품 AUM×abs(L) 합 | 보고된 상품 바스켓 노출 추정 |
| LETF 순노출 편향 | 모든 AUM×L 합 / 모든 AUM×abs(L) 합 | -1~1의 바스켓 노출 지표 |
| 리밸런싱 추정 비율 | 기존 검증된 signed rebalance 추정 / 현물 당일 거래대금 | 실제 ETF 주문·체결·가격 영향 아님 |

수급 비율은 실제 보유율이 아니다. 누적 순매수에 임의 초기값을 넣어 포지션을 만들지 않았다.
LETF 바스켓 비율은 외국인 포지션이 아니다. AUM 중 롱/인버스 한쪽 누락을 0으로 채우지 않는다.
모든 상품 AUM 품질과 중복, 저장된 롱/인버스 합계와의 일치를 검사한다.
리밸런싱은 기존 `implied_rebalance_for_signal()`의 `observed_krx` 게이트를 그대로 사용한다.

## 통계 모델과 검증

운영 엔진은 L2 로지스틱 회귀(C=1)에 별도 기간의 단조 시그모이드 확률 보정을 사용한다.
운영 모델/고정 계수는 이번 연구에서 변경하지 않았다.

새 연구는 두 방법을 분리한다.

**방향 확률:** h별 L2 로지스틱 회귀 + 독립 시그모이드 보정.
자기 가격의 당일 변화·5일 모멘텀·5일 변동성을 통제로 고정하고 아래 묶음을 비교했다.

- 가격만 / 가격+외국인 1일 / 가격+외국인 1·5일 / 가격+한국 콜풋 수급 / 가격+외국인+한국 콜풋.
- 보유율 코호트에서는 가격만 / 가격+보유율 수준·1·5일 변화 /
  가격+외국인+콜풋 / 여기에 보유율을 추가한 모델을 **같은 날짜에서** 비교.
- LETF/리밸런싱 모델은 별도 완전 관측 코호트에서만 비교하고 표본 부족 시 학습하지 않음.

기본 최소 학습은 **250개의 유효 이진 표본**, 보정은 별도 **60 source일 창**, 평가 블록은20 source일.
운영 엔진의 6개월 보정 구간과 다른 연구 프로토콜이다.
학습→보정 및 보정→평가 양 경계에서 모든 5일 결과의 종료일이 다음 구간 시작일보다 앞서도록 purge한다.
평균/표준편차는 학습 구간에서만 계산한다. 무작위 분할, test로 임계값/시차/C 선택, 최적 h 자동 채택은 없다.

미래 다른 h의 동가 여부로 현재 h의 예측을 제외하지 않는다. 각 h는 자신의 동가만 이진 평가에서 제외한다.
따라서 모델 확률은 해당 h의 비동가 조건부 상승/하락 확률이며 관측 빈도의 동가 비율과 구분한다.
같은 h 안의 후보는 같은 학습/보정/평가 날짜를 사용한다. h별 최종 이진 분모는 동가 때문에 다를 수 있다.
상승/하락 각각의 정밀도·재현율·혼동행렬, 중립 수, Brier와 모델 신호/최근 빈도 상태를 기록한다.

**기간별 연관:** Jordà 방식에서 착안한 horizon별 조건부 회귀(OLS) + HAC(maxlags=5) 표준오차.
누적 로그가격 변화에 대해 자기 가격·변동성과 콜풋 수급을 통제한 외국인 1일/5일 비율의 계수를 본다.
2종목×5기간×2수급 비율, 총20개 p값을 함께 Holm 보정한다.
이는 외생 충격을 식별한 인과적 impulse response가 아니다. 거래량/수급/가격의 내생성은 남는다.
시장 전체·미국·환율의 모든 요인을 통제한 것도 아니며 HAC(5)가 모든 의존성을 해결한다는 뜻도 아니다.

참고: [Jordà (2005), AER](https://www.aeaweb.org/articles?id=10.1257/0002828053828518),
[scikit-learn LogisticRegression](https://scikit-learn.org/1.6/modules/generated/sklearn.linear_model.LogisticRegression.html).
