# 개별 전망과 통합 전망의 화면 계약 제안

2026-11-05 사용자 요청 반영. UI 구현 담당은 Claude Code.
이 문서는 화면 설계/모델 상태 매핑이며 운영 UI·공개 JSON 스키마를 변경하지 않는다.
없는 확률을 UI에서 만들어 채우지 않는다.

## 사용자에게 보여줄 구조

```
대상 [KOSPI | 삼성전자 | SK하이닉스]   목표일 YYYY-MM-DD
질문 [다음 장 개장 방향 | 다음 장 종가 방향]

통합 전망
  상승 확률 —   하락 확률 —
  상태 / 실제 입력일 / 생성 시각 / 연구모델 표시

입력별 전망 비교
  한국 옵션 중심 | 미국 주가 중심 | 미국 옵션 중심
  각각 같은 대상·같은 질문의 확률과 사용 가능한 상태

관측 자료
  콜/풋 수급, 미국 주가 등락, 옵션 거래량·OI·IV
  원시 지표 단위와 실제 관측일을 표시

검증 결과
  실제 최초 발행 예측 수 / 발행률 / 확률 오차 / 공통 날짜에서 추가 개선
```

유지/추가 진행은 별도 접기 영역에 두고 상승/하락과 다른 질문임을 명시한다.
방향 유지 확률 75%를 종가 상승 확률로 표시하지 않는다.
한국장 전망과 미국 자체 다음 장 전망은 서로 다른 목표다. 후자는 별도 모델/탭이
완성되기 전까지 전자의 확률을 재활용하지 않는다.

## 먼저 구분할 세 층

| 층 | 의미 | 표시 방식 |
|---|---|---|
| 관측 | QQQ 등락률, 콜/풋 거래량, OI, IV 등 실제 값 | 단위·원천일·수집 시각. 예측 확률처럼 표시하지 않음 |
| 입력별 전망 | 특정 입력 묶음으로 같은 대상의 다음 장 방향을 예측 | 해당 고정 모델의 확률·모델 ID·검증 상태 |
| 통합 전망 | 여러 묶음을 함께 사용해 학습/보정한 고정 모델 | 개별 확률의 단순 평균/투표로 생성하지 않음 |

원하는 최종 비교는 공통 한국 가격 통제변수를 고정한 뒤 한국 옵션, 미국 주가,
미국 옵션을 별도 묶음으로 두는 것이다. 필요한 단독/결합 모델을 각각 검증한다.
기본 통제변수가 들어간 모델을 문자 그대로의 "옵션만 사용" 모델이라고 쓰지 않는다.

VIX는 S&P500 옵션에서 계산한 변동성 지표다. 미국 주가만의 기여를 볼 때 VIX를
주가 묶음에 섞지 않는다. 별도 묶음으로 두거나 모든 비교 모델에 동일한 통제로 넣어,
어느 설계인지 명시하고 새 버전으로 검증해야 한다.

## 지금 구현된 모델과의 정직한 매핑

| 현재 모델/데이터 | 지금 가능한 이름 | 표시하면 안 되는 이름 |
|---|---|---|
| primary | 국내·미국 자료 통합 전망 | 미국 옵션 체인까지 통합한 전망 |
| domestic_price_options | 국내 가격·옵션 전망 | 한국 옵션만의 독립 전망 |
| price_us | 한국 가격·미국 가격·VIX 전망 | 순수 미국 주가만의 전망 |
| frozen_recent | 과거 보정 구간의 사건 빈도 | 추가 예측 모델 신호 |
| 미국 옵션 최신 관측 | 미국 옵션 관측 지표 | 미국 옵션 기반 상승 확률 |

현재 모델을 위의 정확한 이름으로 비교하는 화면은 가능하다. 새 비교 결과는 archive의
`comparisons`에 있으며 기존 public 표시 JSON에는 아직 포함하지 않았다.
실제 공개 전달 계약을 추가할 때는 Claude와 협의해 모델 버전·대상·질문·시각을 보존한다.
"한국 옵션 중심 / 미국 주가 중심 / 미국 옵션 중심"이라는 최종 카드 이름은 해당 입력
묶음의 모델을 만들고 검증한 뒤 사용한다. 미국 옵션 모델 미완료 상태에서는
"관측 자료 있음 · 예측 모델 준비 중"을 보여주고 확률 영역은 비워 둔다.

## 신호 일치와 기여도

- 선택한 대상·목표일·사건·판단 시각이 일치하는 유효 모델끼리만 일치/엇갈림을 계산한다.
- `recent_base_rate_only`, missing, 늦은 관측은 모델 방향 신호의 표결 수에 포함하지 않는다.
- 일치한 모델 수는 신뢰 확률이 아니다. 일치가 통합 확률을 자동으로 끌어올리지 않는다.
- 주 모델과 제외 모델의 확률 차이를 보여줄 경우 "모델 간 예측 차이"로 표시한다.
  이를 "미국 옵션이 상승을 몇 % 일으킴" 또는 합이 100%인 영향 비중으로 표시하지 않는다.
- 기여 검증의 기본값은 같은 날짜에서 입력 묶음을 추가했을 때의 Brier 오차 변화와 공통 표본 수다.
  예측 개선은 인과관계나 시장을 실제로 움직인 비율을 증명하지 않는다.
- 주가와 옵션이 동반 변화할 때의 상호작용은 별도 모델 후보로 검증한다.
  "둘 다 증가하면 무조건 상승" 같은 규칙을 화면이 자체 생성하지 않는다.

## 결측/시각/상태

- 실제 입력일, 예측 생성 시각, 대상일, 예측 마감 시각을 구분한다.
- 예측 없음은 `—`와 이유로 표시한다. 0%, 50%, 어제 값으로 채우지 않는다.
- 과거 재생은 "사후 재현"을 명시하고 실제 사전 발행 성적과 분리한다.
- 일부 모델만 준비된 경우 준비된 비교 범위와 미완료 범위를 표시한다.
  미국 옵션이 없는데 "주가+미국 옵션 통합"이라고 제목을 붙이지 않는다.
- 현재 통합 모델의 필수 입력이 빠지면 기존 unavailable 동작을 유지한다.
  남은 모델 점수를 UI에서 평균 내어 임시 통합 점수를 만들지 않는다.
- 전향 평가 표본이 없으면 "실제 사전예측 성적 집계 중"으로 표시한다.
  과거 재현 적중률을 오늘 확률의 검증된 정확도로 표시하지 않는다.

## 적용 순서

1. 기존 primary 카드와 #884 최초 예측·비교 기록·사후 평가를 연결한다.
2. 현재 3개 모델은 위의 정확한 입력 이름으로 비교 영역에 연결한다.
3. Cursor가 미국 옵션의 원천 시각·미국 세션일·만기/행사가/콜풋별 이력을 보강한다.
   QQQ와 NDX는 서로 다른 상품이며 이력을 합산하지 않는다.
4. Codex가 순수 미국 주가/미국 옵션/결합의 같은 표본 실험을 하고 새 모델 버전을 발행한다.
5. 검증된 출력이 생긴 카드부터 최종 개별 전망 영역을 활성화한다.

현재 #884는 1~2를 위한 모델/기록 기반이다. 3~5의 모델이나 UI가 구현됐다는 뜻은 아니다.
