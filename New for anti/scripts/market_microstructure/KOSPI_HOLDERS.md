# 코스피 보유 구조 · 국민연금 국내주식 여력 (`kospi_holders_v1.json`)

시장 미시구조 › 가격대별 체결 탭, 「가격대별 누적 수급」 아래 두 섹션.
`build_investor_price_levels.py` 가 같은 실행에서 같은 KOSPI 상장목록으로 쓴다
(목록 호출은 하루 한 번 -- data.krx.co.kr 는 IP 를 막는다).

```bash
python build_investor_price_levels.py --live --holders-only               # 이 파일만
python build_investor_price_levels.py --live --holders-only --foreign-days 250   # 1년 소급 (한 번이면 됨)
```

## 외국인 보유율 (observed)

- 종목별 `foreignerHoldRatio`(네이버 모바일 trend, 한도 소진율 아닌 보유 비율) × 상장주식수(FDR `Stocks`) × 그날 종가,
  코스피 보통주 시총 상위 100종목 합산. 커버리지(상위 100 ÷ 보통주 시총)를 같이 싣는다 (2026-11-17: 90.8%).
- 시장 전체 외국인 보유 비중은 KRX 로그인 뒤에만 있어서 상위 종목 합계로 대신한다.
- 하루 60행만 새로 받고 이전 날짜는 앞 파일에서 이어받는다. 상위 종목 시총의 97% 이상이 보고된 날만 점으로 남긴다.
- 가격대별 차트의 일별 행에도 `foreign_hold_pct` 가 붙어, 상세 표에 가격대별 평균 보유율 열이 생긴다.
- 개인·기관의 *보유* 비율은 매일 공개되지 않는다 (순매수만). 예탁원 연간 소유자 현황은 주식 수 기준이라 붙이지 않았다.

## 국민연금 (estimated)

- 공시: fund.nps.or.kr 포트폴리오 현황(월말, 약 2.5개월 지연) + 자산군별 페이지의 연말 표(1990~).
  연말 기금 총액은 공시 표에 없어서 네 자산군의 금액÷비중 평균으로 낸다.
- 일별 추정: 마지막 공시 시점을 이어 붙인다 -- 국내주식은 코스피, 해외주식은 ACWI×원/달러,
  해외채권은 원/달러, 나머지는 그대로. 새 공시가 나오면 선이 공시값으로 옮겨 가고, 그 차이가 그 사이의 실제 매매다.
  (검산: 2025년 말 공시에서 이어 온 8/27 추정 25.9% ↔ 8월 말 공시 25.8%.)
- 기준선: 2026 목표 20.8% (2026-05-28 기금위), 전술 ±2%p, 전략 ±3%p. 전략 범위는 연말까지 한시 확대됐고
  폭은 비공개라 15.8~25.8% 는 *공개된 마지막* 범위다.
- 시나리오: 코스피 0~−30% 에서 각 선까지의 금액 = 선 × 기금 전체 − 국내주식 (다른 자산을 팔아 사므로 총액 불변),
  각 선을 넘는 코스피 레벨.
- 한계: 국내주식에 코스닥이 섞여 있다(코스피 하나로 움직이는 것은 근사). 월중 매매는 공개되지 않는다.

## 국민연금 종목별 지분 (observed) · 공시 일정

- 연말 전 종목 목록: 국내주식 페이지의 「국내주식 종목별 투자 현황(YYYY년 말)」 xlsx 링크를 매일 확인하고,
  새 연도가 생길 때만 받는다(연 1회). 파일에 종목코드가 없어 이름으로 코스피 상장목록과 맞춘다(2025년 말: 상위 100 중 97).
  해마다 지분율 표기가 바뀐다(0.0776 / 8.52 / '7.28%') -- `_as_pct` 가 맞춘다.
- DART 5% 대량보유: `majorstock.json`(시크릿 `DART_API` → `DART_API_KEY`), 시총 상위 100종목, 보고자 국민연금공단만.
  `dart_corp_codes_v1.json` 으로 종목코드→고유번호. DART 가 실패하면 전에 받은 보고를 그대로 둔다.
- 공시 일정(`schedule`): 외국인 = 다음 거래일, DART = 다음 10일(시행령 §154 특례), 연말 목록 = 다음 해 3분기,
  월말 포트폴리오 = 공식 일정이 없어 새 달을 처음 본 날(`first_seen`)을 쌓아 그 간격 중앙값으로 추정(두 달 쌓이기 전엔 '미정').
