# 콜·풋 단기 수급 연구 설계 — 2026-11-04

상태: 탐색 설계 및 보유 데이터 진단. 예측모델 승격/배포 아님.
기존 연구 브랜치의 고정 스냅샷을 사용하며 최신 main 보유량을 뜻하지 않는다.
콜·풋/069500: 2019-01-02~2026-10-30 각 1,921일. 실제 입력 해시는 진단 JSON에 기록한다.
기존에 확인한 과거 성능 구간은 다시 독립 검증 구간으로 부르지 않는다.

## 1. 질문과 시간축

핵심 질문: 일별 순수급에 담긴 정보가 당일에 소진되는가, 다음 장의 갭/장중에 남는가?
입력 평균 기간(1/2/3/5거래일)과 예측 기간은 서로 다른 축이다.

| 결과변수 | 정의 | 용도 |
|---|---|---|
| 당일 장중 | C[t]/O[t]-1 | 동시 움직임 진단, 예측 성적 아님 |
| 다음 갭 | O[t+1]/C[t]-1 | 사후 정보 전달 진단; t 종가 진입 가능성은 별도 |
| 다음 장중 | C[t+1]/O[t+1]-1 | 1차 예측 목표 |
| 2일차 장중 | C[t+2]/O[t+2]-1 | 잔존 효과와 반전 |
| 3일차 장중 | C[t+3]/O[t+3]-1 | 잔존 효과와 반전 |
| 2/3일 보유 | C[t+h]/O[t+1]-1, h=2,3 | 다일 전략 보조 분석 |
| 당일 5/15/30/60분 | 관측 가능 시각 이후 가격 변화 | 장중 자료 확보 후 별도 연구 |

일별 최종 수급은 당일 시가에 알려져 있지 않다. 공개/수집 시각이 미확인인
과거 데이터로 실행 가능한 수익률을 확정하지 않는다. 다음 갭은 조정가격의
분배락 처리에도 민감하다. 원시가격/조정계수 확인 전에는 참고 결과다.
단순히 날짜를 앞뒤로 움직여 성능이 좋아진 경우를 시간대 보정이라고 부르지 않는다.

## 2. 입력의 분해와 중복 방지

상품 p별 외국인 매수 B, 매도 S, 시장 매수 M_b, 시장 매도 M_s. 모두 원 단위 거래금액.

- N = B-S: 순매수 금액.
- A = B+S: 외국인 매수·매도 활동 합계. 시장의 단일 집계 거래대금과 다름.
- I = (B-S)/(B+S): 매수 우위. A=0이면 null.
- P = (B+S)/(M_b+M_s): 양쪽 기준 시장 참여율. 분모=0이면 null.
- F = (B-S)/M_b: 기존 시장 대비 순수급.
- M_b=M_s일 때 F=2*P*I. 따라서 F/P/I가 서로 독립인 정보는 아니다.
- B와 S는 N/A로 정확히 복원 가능하다. B,S,N,A를 모두 넣어 정보가 네 배라고 주장하지 않는다.
- 시장 전체 순매수는 매수·매도 대응으로 0이다. 예측 대상 주체는 외국인/기관 등으로 명시한다.

콜/풋별 F, I, P를 우선 비교한다. 콜·풋 F의 차이 D와 합 S_f는 해석용이며,
선형모델에서 콜/풋 F를 이미 넣었다면 D/S_f는 새 정보가 아니다.
둘 다 매수/둘 다 매도/엇갈림 상태와 I*P 상호작용은 비선형 후보로 별도 검증한다.
콜·풋 동시 매수를 동일 투자자의 스트래들로 해석하지 않는다.
표준/위클리, 정규/야간 포함 범위가 불명확한 시계열에 범위를 임의로 부여하지 않는다.

## 3. 고정 실험 순서

1. 자료 진단: observed·단위·매수-매도=순매수·시장 양쪽 일치·날짜 중복·결측 확인.
2. 당일 F/I/P와 각 시점 수익률의 Spearman 상관을 전체/연도별로 공개한다.
   전체 후보를 공개하고 가장 좋은 상관만 선택하지 않는다. 인과/예측/유의성 주장이 아니다.
3. 예측 비교: 동일 가격 통제변수를 둔 가격만 모델, 기존 옵션 4변수 모델과 비교한다.
   A: 당일 콜/풋 F; B: 당일 콜/풋 I/P; C: B+직전 거래일 대비 I/P 변화.
   이후 B의 2/3/5일 평균을 각각 비교. 전체 조합 탐색 금지.
4. 한 번에 한 묶음씩 OI/IV/만기/선물 정보를 추가한다. 데이터 추가로 바뀐 표본과
   지표의 기여를 구분하기 위해 해당 묶음의 동일 날짜 표본에서 기준모델도 재평가한다.

기본 모델은 정규화 로지스틱(C=1), scaler는 학습 구간만 fit.
훈련/보정/검증은 시간순. 분기별 확장 학습과 직전 6개월 보정 구간을 유지하며,
각 목표의 마지막 결과 날짜가 다음 구간 시작보다 앞서도록 경계를 제거한다.
결측을 건너뛴 다음 관측을 다음 거래일로 취급하지 않는다.
겹치는 2/3일 수익률의 불확실성은 시간 블록 단위로 계산한다.
주평가: 다음 장중 Brier/log loss. 정확도·상승 빈도 기준모델·확률 구간별 실제 빈도 병기.
후보 전체 비교에는 다중검정 보정(Holm 등 사전 지정), 성능차의 블록 신뢰구간을 보고한다.
임계값/lag/반대 방향 선택을 평가 구간에서 최적화하지 않는다.
과거 결과는 탐색으로 표시. 최종 선택 후 새 날짜의 예측을 결과 전에 고정 저장해야 한다.
방향 신호가 약하면 보류 가능. 절대수익률/변동성 예측은 별도 목표로 검증한다.

## 4. 2차 후보와 해석 제한

- 거래금액과 계약 수: 각각 N/A/I/P 계산. 계약 수 없이 금액으로 추정하지 않는다.
- 평균 체결 프리미엄: 같은 범위의 금액/(계약 수*승수). 구성 변화에 영향받으므로 IV로 해석하지 않는다.
- 수급 충격: 과거 60일만 이용한 순위/중앙값 대비 변화. 당일을 기준분포에 포함하지 않는다.
- 만기: 실제 만기일 기준 잔여 거래일, 롤 전후, 월물/위클리 분리.
- 행사가: 동일 만기의 ATM/외가격별 거래·OI·IV. 95% 행사가를 25델타라고 부르지 않는다.
- OI: 동일 계약의 직전 거래일 변화. 시장 OI를 외국인 잔고로 해석하지 않는다.
- 선물: 동일 시점 외국인 수급과 옵션 방향의 일치/불일치. 상품별 규모를 정규화한다.
- 델타 가중 수급: 투자자별 계약별 거래 수량과 당시 델타/승수 필요.
  일별 집계 수급에 종가 델타를 곱한 값을 실제 헤지 수요로 주장하지 않는다.
- 딜러 감마: OI만으로 누가 long/short인지 알 수 없다. 방향 가정 없이는 딜러 노출을 확정하지 않는다.

## 5. 예측 엔진 계약

새 자료 도착 시 고정된 모델·변환·보정 계수로 재계산한다. 자동 재학습은 별도 버전 작업.
source trade_date, session, observed_at/available_at, generated_at, target_start/end,
입력 해시, 모델 버전, p_up, p_non_up, raw_score, information_state를 보존한다.
결과가 알려진 뒤 생성한 예측은 replay로 분리한다. 이전 예측을 덮어쓰지 않는다.
현재 shadow 보정 기울기 0 상태에서는 확률이 입력에 반응하지 않으므로 recent_base_rate_only 표시 유지.

처리한 뒤 구간 차분하며 과거 일별 합계를 장중에 배분하지 않는다.
여러 만기는 기존 date/type/strike 중복 제거 경로에 넣지 말고 별도 계약키 경로로 제공한다.
15001 별도 지표로 기존 activity를 대체하지 않는다. 원본은 private, 공개에는 집계와 매니페스트.
