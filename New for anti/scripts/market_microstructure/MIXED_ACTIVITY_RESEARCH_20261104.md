# 복합 옵션 활동 실험 — 정의 및 해석

사용자 요청: 거래량·거래금액·수급을 복합적으로 섞어 실제 비교.
기존 short_horizon 설계의 확장 탐색이며 과거 구간은 독립 holdout이 아니다.

입력은 고정 연구 checkout 콜/풋 15007·069500과 기존 private
krx-month-paste 커밋 3a27fa40872926d3e907abd2cb00ec08b4c32072의 94개 월별
kospi200_option_oi 정규장 체인이다. 새 KRX 조회 없이 git blob SHA/SHA256을 확인한다.

동일 공통 날짜에서 다음을 비교한다. 가격 통제 6개는 모든 후보에 공통이다.

1. 가격만.
2. 기존 콜/풋 60일 순위·5일 평균.
3. 2 + 콜/풋 시장 거래금액의 과거 20일 평균 대비 로그 비율, 풋/콜 금액 비율,
   외국인 콜/풋 매수 우위·시장 참여율.
4. 3 + 순수급×당일 거래금액 충격, 콜/풋 매수 우위 곱, 콜/풋 참여율 곱.
5. 4 + 보관 체인 거래 계약 수의 로그 합계·풋콜 비율·전일 대비 변화·거래량/OI.
6. 5 + 풋콜 OI 비율·OI 가중 체인 IV 수준·콜풋 IV 차이.

거래금액 급증의 기준은 당일을 제외한 과거20일이다. 체인 변화는 직전 거래일과
동일 만기일 때만 사용하며 롤·결측일 다음 날짜를 붙이지 않는다.
체인 내 동일 일시 중복은 한 번만 사용하고, 값이 충돌하면 결측으로 차단한다.
null을 0으로 바꾸지 않는다. 실제 거래량 0은 관측값이나 비율 분모가 0이면 예측 입력에서 제외한다.

방향은 다음 장 069500 close/open>0. 시간순 분기·6개월 분리 보정·label 경계 제거·
학습 구간 scaler·고정 C=1을 기존 실험과 동일하게 쓴다.
4후보×3기준(가격/기존/최근빈도) 및 거래량 추가·OI/IV 추가의 Brier 차이
14개에 5일 블록 bootstrap 및 Holm 보정을 적용한다.
raw/calibrated, 중립 폭 0/2.5/5%p 및 왕복비용 0/5/10bp를 모두 공개한다.

움직임 크기는 다음 장 절대 시종가 수익률과 log(high/low)를 각각 예측한다.
Ridge alpha10, log(target+1e-5), 학습 구간 정규화, 분기별 시간순 평가.
최근6개월 단순 평균과 동일 날짜 비교하며 MAE/순위상관을 보고한다.
log 모델의 역변환은 중앙값 쪽 추정이며 기대수익/분산 추정으로 해석하지 않는다.
크기 예측은 탐색 진단으로 별도의 통계적 우위 확정을 하지 않는다.

중요한 범위 제한:

- 체인 거래량은 보관된 표준 최근월물 정규장 행의 합계이다. 모든 시장/위클리/야간
  전체 거래량이 아니며 누락 행사가가 있으면 합계도 불완전하다. 실제 만기일까지의
  기간과 행사가 구성의 영향도 있어, 거래량 변화 자체를 순수 수요 충격으로 확정하지 않는다.
- 15007 금액과 위 체인의 범위가 같다고 가정하지 않는다. 두 값을 직접 대체/합산하지 않는다.
- 금액은 백만원→원 변환이 끝난 공개 집계값이다. 계약 수와 금액 단위를 섞지 않는다.
- OI는 시장 전체 잔존 계약이며 외국인 포지션이 아니다. 거래량이 높다고 변동성 long/short를 확정하지 않는다.
- IV는 각 행사가 OI 가중 값으로 ATM 고정 IV가 아니다. 차기 하루 실현 변동과 IV의 만기 범위가 다르다.
- 과거 공개 시각과 수정 OHLC 거래 정합성 미확인. 성능은 탐색이며 신규 전향 검증 필요.
- 모델/UI/workflow/기존 public 데이터 변경 없이 별도 연구 산출물만 생성한다.
