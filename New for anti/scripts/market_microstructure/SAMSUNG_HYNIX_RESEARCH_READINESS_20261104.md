# 삼성전자·SK하이닉스 종목별 확장 점검

후속 업데이트: 사용자의 시작/종가 방향 지시에 따라 네이버 차트 일봉을 각1,921일 별도 확보했다.
종목별 방향 비교 결과는 `data/manifests/stock_open_close_direction_20261104.md` 참조.
아래181일·미학습 상태는 장기 일봉 확보 전 점검 시점의 기록이다.

2026-11-04 읽기 전용 보유자료 점검. 아래는 기존 연구 checkout 및 private 고정 커밋
3a27fa40872926d3e907abd2cb00ec08b4c32072 기준이며 최신 main 전체 보유량 감사가 아니다.

## 가능한 모델 범위

1. KOSPI200 옵션 수급·시장 거래금액·체인 거래량/OI/IV를 공통 시장 입력으로 사용하고,
   목표를 삼성전자(005930)/SK하이닉스(000660)의 다음 거래일 시가→종가 및 고저폭으로 바꾼다.
2. 각 종목 고유 가격·현물 거래량·투자자 매수/매도 수급을 추가하고 종목별로 독립 학습·보정한다.
3. 각 종목 자체 옵션 체인·수급은 별도 자료 확보 후 추가한다. 1을 자체 옵션 분석으로 부르지 않는다.

KODEX200 모델의 확률을 그대로 두 종목에 붙이지 않는다. 종목마다 상승 빈도/변동폭/민감도가 다르다.
가격만, 시장 옵션만 추가, 종목 현물 수급 추가, 자체 파생 추가를 같은 날짜에서 비교한다.
시장 베타 때문에 생기는 예측과 종목 고유 정보를 구분하려면 가격 통제에 KOSPI200을 포함한
기준모델도 비교하고, 종목수익률과 시장대비 초과수익률 목표를 별도로 명시한다.

## 확인한 자료

| 자료 | 확인 범위 | 판단 |
|---|---|---|
| investor_price_levels_v1.json 두 종목 days[] | 각각 2026-02-02~10-30 181일, OHLC 유효181, 중복0, 비거래일0 | 종목별 목표 정의 가능, 기존 장기 검증 구조에는 짧음 |
| 같은 파일 현물 수급 | 외국인/기관/개인 net shares observed, net KRW estimated | 수량과 추정 금액 구분. 수량×종가를 실제 매수/매도 거래금액으로 대체 금지 |
| stock_letf_history_v1.jsonl | 두 종목 합198행(99일씩) | 짧은 보조 표본; AUM 결측 및 기초수익률 정의 검토 필요 |
| private krx_12009_stock_investor | 2019-01~2026-10 월별93개 gzip part; 첫/끝 파일에 두 종목 있음 | 장기 현물 매수/매도 금액 백업 존재. 전기간 종목별 연속성·중복·단위는 추가 검증 필요 |
| private price_labels | 지수용 label_only/not_realtime_feature, 종목 OHLC 없음 | 종목 주가 자료로 사용 불가; 미래수익 label을 입력으로 사용 금지 |
| private stock_derivative | 아래 상세 | 자체 옵션 장기 일별 입력 불충분 |

stock_derivative/year=2026/month=08의 두 종목 매칭행은 총8개다.
2026-07-29~08-28 기간 합계의 선물·풋 옵션 4행은 date=null,
grain=period_total_not_daily, exclude_from_model_inputs=true다.
2026-08-31 하루의 선물·풋 옵션 4행은 daily이며 exclude=false다.
이 파티션에서 두 종목의 콜 옵션 일별 이력은 확인되지 않았다.
기간 합계를 일별로 나누거나 자체 콜풋/OI/IV 장기 이력이 있는 것처럼 사용하지 않는다.

현재181일은 가격20일 lookback 및 학습250일+분리보정60일 조건을 만족하지 못한다.
따라서 점검 단계에서 종목별 확률·적중률을 새로 생성하지 않았다.

## 우선 데이터 보강

P0: 005930/000660의 일별 OHLCV를 기존 옵션 공통 구간인 2019-01-02부터 확보한다.
실제 거래대금이 제공되면 별도 필드로 보존. 종가×거래량을 실제 거래대금으로 부르지 않는다.
원시/수정주가·분할/배당 처리·시간대·trade_date·source·collected_at·원본 해시를 기록한다.
장중/휴장일/가격 없는 날을 전일 관측으로 채워 observed로 만들지 않는다.
기존181일과 중첩 대조하고 정의가 다르면 별도 시계열로 보존한다.

P1: 기존 private krx_12009_stock_investor에서 두 종목을 추출, 날짜/범위/투자자 정의와
중복 수집·단위 정정을 검증한다. 현물 기관/외국인 buy/sell/net 및 시장총액을 재사용한다.
전기간 재다운로드보다 기존 백업 정규화를 우선한다.

P2: 자체 옵션을 보강하려면 종목·계약코드·실제만기·행사가·콜/풋·정규/야간·일자별
계약거래량·거래대금·OI·IV가 필요하다. 투자자별 수급은 지원 여부를 따로 확인한다.
희소하거나 미거래면 실제0과 미수집 null을 구분한다. 기간합계 자료는 일별 입력에서 제외한다.
해당 자료가 없어도 1+2의 시장옵션·현물수급 모델 연구는 장기주가 확보 후 가능하다.
