# 작황 모델 선택 학습 — Ridge, XGBoost, MLP

호주 곡물 수수 실험에서 확인한 공통 모델 선택 원칙이다. 이 문서는 특정
알고리즘을 기본값으로 강제하지 않는다. 동일한 시점·피처·검증 폴드에서 복잡도를
비교하고, 재현 가능한 개선만 운영 모델로 승격하기 위한 체크리스트다.

## 핵심 결론

데이터 길이만 보고 모델을 선택하지 않는다.

- 소표본 연 단위 패널에서는 규제 선형모델(Ridge)을 기본 challenger로 둔다.
- XGBoost는 고온·가뭄 임계값처럼 안정적인 비선형 구조가 시간순 검증에서
  반복될 때만 채택한다.
- 딥러닝은 지역×연도 독립 표본이 충분하지 않으면 사용하지 않는다.
- 복잡한 모델이 한 지역에서 이겨도 다른 지역에 일괄 적용하지 않는다.

데이터가 부족할수록 머신러닝이 유리하다는 해석은 틀리다. 일반적으로 소표본은
복잡한 모델의 분산과 과적합 위험을 키운다. 예외는 단순하고 안정적인 임계값이
여러 시간순 폴드에서 반복되는 경우다.

## 호주 곡물 수수 사례

동일한 9개 피처와 12개 외부 시간순 폴드로 비교했다.

| 지역 | Ridge 전체/최근 skill | XGBoost | 2층 MLP | 결정 |
|---|---:|---:|---:|---|
| NSW | +13.9% / +15.0% | **+18.8% / +19.6%** | +12.7% / +15.6% | Ridge 기준, XGBoost challenger |
| Queensland | **+13.6% / +14.0%** | +3.0% / +3.2% | −4.7% / −2.1% | Ridge 유지, XGBoost·MLP 기각 |

NSW에서는 12개 외부 폴드가 모두 같은 깊이 1 XGBoost 설정을 선택했다. 이는 큰
트리 앙상블이 필요하다는 뜻이 아니라 개화기 고온·고온×건조에 몇 개의 안정적인
조건 분기가 존재한다는 증거다.

Queensland에서는 학습 종료연도가 이동할 때 선택 트리 구조가 바뀌었다. 중앙·남부
지역, 파종일, 품종, 건답·일부 관개가 하나의 주 라벨에 섞인 상황에서 소표본
비선형 모델이 이질성을 불안정한 분기로 바꾼 것이다. 계수를 축소하는 Ridge가
분산을 덜 키워 더 정확했다.

2층 MLP는 NSW에서 XGBoost를 이기지 못했고 Queensland에서는 추세보다 나빴다.
32개 완전 시즌은 신경망의 유효 자유도를 지탱하지 못한다.

세부 재현 결과는 `australia/SORGHUM_MODEL_COMPARISON.md`에 있다.

## 공통 검증 절차

1. 기술 추세 전용 모델을 기준선으로 둔다.
2. 작물 생육단계에 맞는 강수·열·토양수분 피처를 사전 정의한다.
3. 같은 피처와 같은 외부 예측연도로 Ridge, XGBoost, MLP를 비교한다.
4. 추세와 스케일러는 각 외부 폴드의 과거 자료로만 다시 적합한다.
5. 하이퍼파라미터는 외부 평가연도를 제외한 내부 시간순 검증에서 선택한다.
6. 전체와 최근 skill이 모두 +10% 이상이어야 forecast 후보가 된다.
7. 최근 skill이 +20% 미만이면 `low_confidence`로 표시한다.
8. 추세보다 정확했던 외부 폴드 수와 선택 하이퍼파라미터 안정성을 함께 본다.
9. 복잡한 모델은 단순 모델을 안정적으로 이길 때만 challenger로 등록한다.
10. 미래 생육기간이 관측되지 않았으면 평년값만으로 숫자 forecast를 만들지 않는다.

## 상태 분류

| 상태 | 의미 |
|---|---|
| `production` | 단순 모델을 안정적으로 이기고 외부 검증 기준을 통과 |
| `challenger` | 개선은 있으나 표본·안정성·미사용 작기 검증이 부족 |
| `reference` | 기후·수분 방향만 표시하고 수치 예측은 숨김 |
| `rejected` | 추세보다 나쁘거나 폴드별 구조가 불안정 |

## 해석 시 주의

- 예측 기여도는 인과효과가 아니다.
- 주·국가 단위 라벨에는 품종, 관리, 관개, 파종일 효과가 섞여 있다.
- 모델 비교 후 바로 운영 모델로 승격하지 않는다.
- 다음 미사용 작기에서 challenger가 다시 이겨야 승격한다.
- 소표본에서 딥러닝을 쓰는 것은 고급화가 아니라 과적합 위험 증가일 수 있다.

## 국가별 작업 보고 항목

- 완전 학습 시즌 수와 외부 시간순 폴드 수
- 추세 기준 RMSE
- 모델별 전체·최근 skill
- 추세보다 정확했던 외부 폴드 수
- 폴드별 선택 하이퍼파라미터의 안정성
- 현재 작기 실제 관측 비율
- `production` / `challenger` / `reference` / `rejected` 판정

> 이 시스템은 AI 복잡도를 성능으로 간주하지 않는다. 지역별 시간순 검증에서
> 단순 통계모델과 비선형 머신러닝을 경쟁시키고, 임계값 구조가 반복적으로
> 재현될 때만 복잡한 모델을 채택하며 데이터가 부족하면 예측 대신 관측 패널로
> 전환한다.
