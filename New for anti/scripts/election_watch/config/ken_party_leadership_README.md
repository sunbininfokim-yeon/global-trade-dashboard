# 케냐 정당 지도부 (2026-11-07)

요청 1만 담았다. 대통령제라 국민의회 의석 요약표의 1위 UDA와 2위 ODM만 넣었다.

의석 148과 86은 2026년 8월 12일 파일명의 국민의회 명부 요약표다. 같은 파일 각주는 2025년 12월 2일이다. UDA와 ODM은 요약표와 이름 행 개수가 같다. JP 요약 27과 이름 행의 DCP 1명은 숫자가 달라 현재 의석으로 합치지 않았다.

ODM은 제1야당으로 적지 않았다. UDA 글이 연립 협의와 broad-based coalition을 같이 적는다.

상원 지도부 이름은 상원 첫 화면에 있으나 정당이 없어 두 당의 상원 원내대표 칸은 비웠다. 국민의회 소수당 대표도 페이지가 서로 달라 비웠다.
