# 산업별 공시 매핑 1차

`pe_cr.industry_note_metrics`는 DART/SEC 정규화 재무제표에 검토된 산업별 공시 수치를 별도로 붙인다. 산업 키트는 지표 후보를 정하고, **검토된 회사·기간의 표만** 값을 만든다. 기존 재무지표·P1 주석 어댑터·CR/PE 진단 로직을 교체하지 않는다.

| 업종 | 매핑 항목 | 함께 보면 안 되는 항목 |
| --- | --- | --- |
| 반도체 | DRAM·NAND·기타 제품 매출과 비중, 명시 공시된 HBM·가동률 | HBM은 DRAM의 하위 항목. 사업부 총매출이나 출하량·ASP로 HBM 매출을 역산하지 않음 |
| 조선 | 확정 수주잔고(금액·척수 구분), 자금 배정/미배정 잔고, 기간 신규 확정수주, 가동률 | 신규 수주 ≠ 기말 수주잔고 ≠ 매출 ≠ 계약부채. 옵션·LOI 제외 |
| 기계·건설 | 확정 수주잔고와 기간 신규 수주, 기계는 가동률 추가 | 총계와 제품/현장 내역의 중복 합산 금지 |
| 유통 | 직매입/소매의 동일점 매출 증감률, 중개는 GMV | 동일점 지표는 회사 정의 유지. GMV를 회계 매출이나 CCC 분모로 사용 금지. 혼합은 보류 |
| IT | 서비스는 ARR 및 확정 수주잔고, 하드웨어는 가동률 | ARR은 기준일의 회사 정의 지표로 IFRS/GAAP 매출이 아님 |
| 해운 | 운영 선대의 TEU 및 용선 선박 척수 | 선복량·선대 소유와 리스 장부금액을 섞지 않음. 기존 리스 조정 유지 |

FY2025 검토 매핑:

- 반도체: 마이크론 [SEC 10-K 주석 21](https://www.sec.gov/Archives/edgar/data/723125/000072312525000028/mu-20250828.htm)의 52주 연결 재무표(백만 USD), SK하이닉스 [SEC F-1 감사 연결 주석 24(2)](https://www.sec.gov/Archives/edgar/data/2120882/000119312526280172/d32785df1.htm)의 백만 KRW 표. 하이닉스는 DART 고유번호와 SEC CIK의 명시 교차 연결을 거치며, DART 연결 매출과 공시 표 합계 대조에 통과해야 출력한다. 하이닉스 제품 행의 원천은 **SEC F-1**이며 DART 주석 아카이브를 검증했다는 뜻이 아니다. HBM 별도 금액은 보류했다.
- 유통: Costco [SEC 10-K](https://www.sec.gov/Archives/edgar/data/909832/000090983225000101/cost-20250831.htm)의 전사 동일점 매출 성장률 6%, 환율·연료가격 효과 제외 8%. 같은 기간의 보조 지표지만 정의가 달라 별도 키를 쓴다.
- 조선: Huntington Ingalls [SEC 10-K](https://www.sec.gov/Archives/edgar/data/1501585/000150158526000006/hii-20251231.htm)의 FY말 전사 수주잔고 USD 53.139bn, 자금배정 31.985bn, 미배정 21.154bn. 세 금액의 범위·표·합계를 검증하고 후자의 두 행은 전사 합계에 포함됨을 표시한다. 전사에 비조선 사업부가 포함되므로 조선 부문만의 잔고나 한국 조선사와 동등한 비교값으로 읽지 않는다. 한국 조선 원문 표와 기계·IT·해운의 회사별 값은 후속 검토 대상이다.

## 승인 입력과 연결

1. `config/industry_note_metrics.json`의 허용 업종·지표·단위·정의 확인 → 공시 원문 표에서 정확한 열과 행을 읽는다. `config/industry_note_registry.json`의 패킷에는 회사의 재무 API 식별자, 기간 종류/시작/종료, 연결 범위, 통화, 공식 접수번호·게시일·원문 URL, 각 수치의 표/행/원단위·배율을 기록한다. 주석 후보, Gemini 결과, 텍스트 유사도는 등록 근거가 아니다. 해당 회사의 다른 보고서나 기업으로 규칙을 전파하지 않는다.
2. 매출 분해 표는 동일 표의 DRAM·NAND·기타를 연결 합계와 대조한다. 표 합계가 같은 범위·기간·원통화의 canonical 매출과 표시 단위 한 자리 미만 오차로 일치할 때만 행과 비중을 공개한다. 검증된 HBM 하위행은 `included_in:"dram_revenue"`이며 배분의 합계에 추가하지 않는다. 다른 항목은 `scope`를 명시하고 같은 이름만으로 기업 간 비교 가능하다고 판단하지 않는다.
3. 금액은 원통화 절대 단위, 비율은 소수, 물량은 척/TEU 등 고유 단위다. 기말 잔고는 `period_start:null`로 구분한다. 별도 승인 없이 연간값을 분기로 이월하거나 누적 기간을 분기 지표로 변환하지 않는다. 과거 시점 재현은 엔진의 `publication_cutoff`를 넘겨 공시 이후 공개된 값을 차단한다.
4. UI는 `pe_cr.industry_note_metrics.rows`에서 `status:"reported"`인 행과 원문 근거만 렌더링한다. `unavailable`은 미확인이지 0이 아니다. 이 PR은 Python·JSON 계약까지이고 Worker/UI/배포/스케줄러, DART 문서 API 실호출, 전체 업종 데이터 적재는 하지 않는다.

회귀 검증: `python3 -m unittest discover -s "New for anti/scripts/dart/tests"`. 공개 표의 수치를 옮긴 DART/SEC 응답 형식 테스트와 회사·기간·통화·CFS/OFS·단위·합계·HBM 중복 방지 테스트를 포함한다.

## 조선: 선수금환급보증(RG)과 이행성보증

[금융위원회 정의](https://www.fsc.go.kr/po010103/83744)에 따르면 RG는 선박 미인도 등 계약상 보증 사유가 발생할 때 발주자가 이미 낸 선수금의 환급을 보증기관에 요구할 수 있게 하는 보증이다. 조선사에 제공된 보증의 한도는 신규 차입·가용현금·수주잔고가 아니다. **이 모듈 값을 순차입금·계약부채·유동성 커버리지·DSCR에 자동 합산하지 않는다.**

- 출력: `pe_cr.industry_note_metrics.shipbuilding_rg`. 검토된 연결 또는 별도 기준일의 발급기관·통화별 `limit`, `outstanding`, `limit_less_outstanding`, `utilization` 및 원문 근거. 같은 행의 한도·잔액이 모두 확인된 경우만 차이(한도−잔액)와 사용률(잔액÷양수 한도)을 계산한다. 단순 차이는 추가 발급 승인 또는 인출 가능 금액이 아니다. 잔액이 한도를 넘으면 원문 금액만 표시한다.
- `portfolios[].basis`: 순수 RG 약정(`rg_only`), 순수 RG 보험(`rg_insurance_only`), RG를 포함한 이행성보증(`rg_and_other_performance`)을 구분한다. 혼합 범위만 있으면 `status:"partial"`과 `rg_only_available:false`; 화면은 `label_ko`로 구분한다. `rg_only_available:true`는 RG 전용 자료가 있다는 뜻이지, 실제 발급 잔액도 확인됐다는 뜻은 아니다. 발급기관·통화·연결/별도·사업 그룹을 임의 합산하지 않는다. 공란을 0으로 바꾸지 않는다.
- 한화오션: [2026 반기 DART](https://dart.fss.or.kr/dsaf001/main.do?rcpNo=20260812000829)·[2026 Q1](https://kind.krx.co.kr/external/2026/05/13/000687/20260513001561/11013.htm)·[FY2025 정정](https://kind.krx.co.kr/external/2026/03/17/000756/20260317002932/11011.htm)·[2025 Q3](https://kind.krx.co.kr/external/2025/11/12/000650/20251112001455/11013.htm) 연결 주석 17의 혼합 이행성보증 한도·실보증잔액을 기관·통화별로 제공한다. 별도 공제조합 행이나 기타 기관의 구성 변화는 합산·추정하지 않는다.
- HD한국조선해양: [2026 반기 DART](https://dart.fss.or.kr/dsaf001/main.do?rcpNo=20260814002569)·[FY2025](https://kind.krx.co.kr/external/2026/03/20/001327/20260320004889/11011.htm)·[2025 반기](https://kind.krx.co.kr/external/2025/08/14/001966/20250814005958/11012.htm)의 회사 환산 혼합 약정 한도. FY2025 별도 한도는 별도 요청에서만 노출한다. 실보증잔액은 이 표에 없어 사용률을 계산하지 않는다.
- 삼성중공업: [2026 반기 DART](https://dart.fss.or.kr/dsaf001/main.do?rcpNo=20260814003496) 연결 주석 14의 RG 보험 한도 USD 11,616백만, 주석 6의 기계설비건설공제조합 대상 RG 발행 담보 금융자산 KRW 22,233백만. 보험 한도와 발급 잔액을 동일시하지 않고, 담보를 해당 보험 한도나 가용현금에서 차감하지 않는다. RG와 일반대출이 함께 묶인 제한 금융자산 금액은 순수 RG 담보로 승격하지 않았다.
- 검토한 공개 DART·KRX 원문과 기업 식별자를 연결했으며 런타임 자동 파싱·실시간 조회는 하지 않는다.

## 조선: 사업부별 수주 계약잔액

- 출력: `pe_cr.industry_note_metrics.shipbuilding_orderbook`. HD한국조선해양의 2026·2025 반기 연결 및 FY2025 연결/별도 수익 주석을 등록했다. `opening + contract_movement − recognized = closing`을 각 행과 합계에서 대조한다. 연결 합계 아래 조선·해양플랜트·기타를 표시하고 `included_in` 하위행을 합계에 다시 더하지 않는다. `contract_movement`에는 신규·추가계약, 계약 변경, 외화 환산 등이 포함되며 음수도 가능하다. 순수 신규 수주·실제 수금과 구분한다. 원문 사업부 범위에서 공동영업(FDH JV) 등은 공시 기준에 따라 제외되어 있다.
- `source_window:"half_year_ytd"`는 Q2에서 보여도 1~6월 누계다. 단독 분기 및 다른 연결 범위로 이월하지 않는다. `expected_revenue_recognition`은 보고서에 표시된 연도별 **수익 인식 예상 구간**이며, 계약잔액 합계와 일치해야 한다. 확정 인도일·수금·매출 전망으로 바꾸지 않는다. 검증된 척수가 없어 `closing_vessels:null`을 반환한다. 한화오션·삼성중공업의 검토한 사업현황 표는 같은 연결 범위라는 근거가 불명확해 이 계약잔액 모듈에 넣지 않았다.
