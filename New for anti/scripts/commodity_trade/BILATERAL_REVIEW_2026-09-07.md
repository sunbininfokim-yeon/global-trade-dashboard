## 1. 결론과 기존 설명 정정

요구사항은 상품 → 기준국 → 연도/월 → 수출 대상국 및 수입 원산국 → 물량·금액·비중·순위다.
기반은 이미 일부 있다. “상대국별 데이터가 아예 없다”는 기존 설명은 틀렸다.
다만 모든 국가·상품·월의 양방향 거래를 완전하게 확보한 상태도 아니다.

| --- | ---: | --- | --- | --- |
| 사우디 → 미국 | 2,893,000 배럴 | 산출 보류 | 산출 보류 | 미국 EIA의 사우디산 원유 수입 보고치 |
| 사우디 → 중국 | 미확보 | 미확보 | 미확보 | 이번 Comtrade Preview 응답은 빈 결과. 0으로 표시 금지 |
| 사우디 → 한국 | 인증 후 확인 | 미확보 | 미확보 | 한국 nitemtrade의 상대국 SA 수입으로 보완 가능. 기본 단위 kg, 임의 배럴 환산 금지 |
| 사우디 → 기타 국가 | 미확보 | 미확보 | 미확보 | 같은 월·품목·단위의 직접 또는 상대국 보고 자료 추가 필요 |
| 다른 국가 → 사우디 | 미확보 | 미확보 | 미확보 | 사우디 수입 방향을 별도로 조회. 수출만 있다는 이유로 수입=0 처리 금지 |

[EIA 원문 시계열](https://www.eia.gov/dnav/pet/hist/LeafHandler.ashx?f=M&n=PET&s=MCRIMUSSA1):
2026-06 값은 2,893, 단위 Thousand Barrels, 발표일 2026-08-31.
따라서 2,893 × 1,000 = 2,893,000 배럴. 이 표의 2026-07은 공란이며 7월 0의 근거가 아니다.

수입 도착 월과 수출 출항 월은 다를 수 있다. 미국의 이 값을 사우디 직접 보고 6월 수출과 동일하다고 단정하지 않는다.
동일 기준의 사우디 총계와 전체 상대국 자료가 없으므로 비중·전체 순위는 null이 맞다.

## 5. 공통 데이터 계약 제안

각 거래 관측치를 먼저 보존하고, 그 위에서 화면용 수출입 목록을 만든다.

| 필드 묶음 | 필요한 내용 |
| --- | --- |
| 상품 | commodity_id, HS 코드/버전, 상품 범위, 정광/정제 구분 |
| 기간 | frequency=A/M, period, 발표일, 조회일, 수정 버전 |
| 방향 | focus_country, exporter, importer, 실제 reporter, 원래 flow |
| 출처 | source, source_url, direct_report/mirror_report, 신고/추정 플래그 |
| 물량 | 원 수량/원 단위, net_weight_kg, quantity_bbl 등 허용된 환산값; 누락은 null |
| 금액 | 원 금액/통화, FOB/CIF 기준; 환율 환산 시 환율·기준일 별도 기록 |
| 분모 | 같은 국가·월·상품·방향·단위·출처 범위의 World 총계, 비교 가능 여부 |
| 분석 | quantity_share_pct, value_share_pct, rank_quantity, rank_value, rank_scope |
| 품질 | partial/complete/unknown, covered_partner_count, truncation, missing_reason, latest_available_period |

계산 및 표시 규칙:

1. 물량 비중 = 해당 상대국 물량 ÷ 비교 가능한 공식 World 물량 × 100. 금액 비중은 금액끼리 따로 계산한다.
2. World 총계가 없으면 국가 전체 비중을 만들지 않는다. 확보 상대국 합계 내 비중을 제공할 때는 별도 이름과 불완전 표시를 쓴다.
3. 수출 순위/수입 순위, 물량 순위/금액 순위를 분리한다. 전체 상대국 확보를 확인하지 못하면 '확보된 상대국 중 순위'로만 표시한다.
4. 원유 kg/톤을 고정 계수로 배럴로 바꾸지 않는다. 공식 부피 단위 또는 검증된 품종별 환산 근거가 필요하다.
5. 직접 보고치와 mirror는 별도 관측치다. 동일 거래를 양쪽에서 더하지 않고, 대체 표시 시 누구의 보고치인지 밝힌다.
6. 금액 CIF/FOB 차이, 원산국/위탁국 차이, 운송 시차, 재수출을 보존한다. 타국 원산지 제품의 재수출을 해당국 생산으로 해석하지 않는다.
7. 조회 실패·미발표·비공개·호출 제한·명시적 0을 구분한다. 빠진 월을 0이나 직전 월 값으로 채우지 않는다.
8. 연간 공식치와 12개월 합계는 개정 등에 따라 다를 수 있다. 연간과 YTD를 구분하고, 전년 동월·전년 동기간 비교만 같은 범위에서 수행한다.
9. 물량이 없고 금액만 있으면 금액 분석만 제공한다. 금액으로 물량을 역산하지 않는다.
10. Top3 의존도·거래 상대 다변화·집중도는 커버리지를 함께 제공한다. 무역 통계만으로 기업별 실제 조달 경로까지 추론하지 않는다.

## 6. 먼저 고칠 부분과 실행 순서

P0 — 정확성 계약/회귀 테스트:

- `data.js`의 copper=HS7403과 `priority_universe.py`의 copper=HS2603을 다른 상품 ID로 분리한다.
- gas=HS2711과 lng=HS271111은 같은 상품으로 연월 비교하지 않는다. 기타 넓은 HS의 상품명도 분류 사전으로 재확인한다.
- `mineral_trade_stage2/fetchers.py`의 `exports or imports`를 두 방향을 모두 보존하는 구조로 변경한다.
- 중량 null→0 처리 제거, World 총계 별도 보존, 추정치/원 단위/잘림·부분성 보존을 검증한다.
- 양측 신고 중 큰 USD를 택하는 현행 로직을 새 데이터에 적용하지 않는다.

P1 — 작은 검증 세트:

- 브라질 공개 원자료의 국가 코드 보존 및 수입 확장.
- 노르웨이 08799로 원유 등 소수 품목·한 달·소수 상대국 테스트.
- 한국 nitemtrade는 키 연결 후 HS2709·상대국 SA·202606으로 XML 및 kg/USD 검증.
- 미국 EIA 원산국별 원유를 별도 배럴 관측치로 연결.
- Comtrade의 기존 광물 상대국 수집을 두 방향·연속 월 패널로 일반화.

P2 — 전체 우선국 확장/연월 공급망 분석:

- 국가×상품×방향×월 완료 manifest 및 재시도/백필 체크포인트 운영.
- 쿼터 소진 시 중단 위치 보존, 실패로 기존 정상 자료를 덮지 않기.
- 필요한 데이터만 재수집하고 원본 관측/정규화/화면 산출을 구분.
- 데이터 검증 후 별도 UI 담당자에게 연결 계약 전달. PR·검증 뒤 배포하며 이번 검토에서 배포하지 않는다.

## 7. 품목별 RSS/공식 발행물 추천

'RSS 확인'은 공식 페이지가 피드를 안내함을 뜻한다. 현재 수집기 파싱/최신 기사/상업적 재게시 권한까지 모두 검증한 것은 아니다.

| 기관 | 추천 상품/용도 | 연결 방식과 주의 |
| --- | --- | --- |
| 미국 정부 EIA | 원유·석유제품·가스·석탄의 공급/재고/무역 해설 | [공식 RSS 목록](https://www.eia.gov/tools/rssfeeds/), Today in Energy RSS 확인. 기존 official_reports 설정에도 등록되어 있어 중복 수집보다 품목 태깅 재사용 |
| 미국 정부 USGS Mineral Resources Program | 구리·니켈·리튬·희토류 등 광물 공급/자원 발표 | [공식 뉴스](https://www.usgs.gov/programs/mineral-resources-program/news)에 Minerals News RSS 안내 확인. 탐사/지질 기사와 무역 관련 기사 구분 |
| CME Group 거래소 | 에너지·농산물·금속 선물 관련 공지 | [공식 RSS 목록](https://www.cmegroup.com/rss.html): Agriculture/Energy, Clearing Advisories 등. 일반 IT 공지는 상품 카드에서 제외. 웹 재게시 이용조건 사전 확인 |
| FAO FAPDA 국제기구 | 곡물·유지작물의 수출 제한/관세/정책 | [현재 서비스](https://fapda.apps.fao.org/)의 국가·상품 필터 활용 후보. 2026-06-12 개편 이후 현재 RSS 경로는 미확인. 과거 가이드의 RSS를 그대로 연결하지 않음 |
| OPEC 국제기구 | 원유 수급·생산·재고·전망의 배경 설명 | [월간 보고서](https://www.opec.org/monthly-oil-market-report.html) 발행 감지 후보. 이번에 RSS는 확인하지 못함. 양국 간 월별 물량의 대체 원천으로 취급하지 않음 |
| 일본 JOGMEC | 금속광물의 광산·정책·공급 이슈 | [현행 금속 정보](https://journal.jogmec.go.jp/metal/index.html). 과거 MRIC 주소는 이 페이지로 이동. 현재 RSS 미확인, 공식 페이지 감지 후보 |

RSS는 통계값에 합산하지 않고 관련 소식으로 연결한다. commodity_id, 언급 국가, 사건 발생일, 게시일, 발행기관, 원문 URL을 보존한다.
FAO 요약은 정부 원문 그 자체가 아니므로 연결된 원 정책문서가 있으면 함께 제공한다.
원문 전체 복제 대신 허용 범위의 제목·짧은 요약·링크를 사용하고 기관별 조건을 확인한다.

## 8. 인증 단계 중단 및 사용자 요청

이번 로컬 프로세스에는 다음 환경변수들이 설정되어 있지 않음을 값 노출 없이 확인했다:
`KOREA_CUSTOMS_SERVICE_KEY`, `COMTRADE_SUBSCRIPTION_KEY`, `COMTRADE_API_KEY`, `EIA_API_KEY`.
이는 Cloudflare에 저장된 키가 없거나 무효라는 뜻이 아니다. 실행 환경이 서로 다르다.

우선 필요한 조치:

1. 이미 발급받은 `KOREA_CUSTOMS_SERVICE_KEY`를 실제 수집 실행환경에 안전하게 연결하고 nitemtrade 활용 승인을 확인한다.
2. Comtrade 인증 대량 수집을 사용할 경우 기존 `COMTRADE_API_KEY` 또는 스크립트 별칭 `COMTRADE_SUBSCRIPTION_KEY` 연결 여부를 확인한다. 신규 유료 구독이 반드시 필요하다는 결론은 아니다.
3. EIA 공개 시계열 확인에는 키가 필요하지 않았다. EIA 인증 API 방식으로 전환할 때만 `EIA_API_KEY`를 요청한다.

키를 대화/문서/공개 JSON에 붙여 넣지 않는다. 위 인증이 필요한 실제 조회는 여기서 진행하지 않았다.
