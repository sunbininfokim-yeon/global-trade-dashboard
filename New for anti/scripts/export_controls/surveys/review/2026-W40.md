# 수출통제 주간 확인 2026-W40

입력: 2026-10-02 카탈로그 20행. 기한 2건, 링크 확인 20건, 최근 8일 공고 중 원자재 후보 0건(기술·제재 공고 9건은 제외).
카탈로그 JSON 은 이 PR 에서 고치지 않았다. 아래 「바꿀 내용」을 모듈 파일에 그대로 넣으면 된다.

## 요약
- 바꿀 행 2건 · 새 행 1건 · 그대로 18건 · 판단 보류 8건

## 보류와 이유

링크는 2026-10-02 에 한 번씩 열었다. 404·410 은 없다. 아래는 403 이라 자동 확인 불가고, 정부 원문으로 바꾸지 못했다.

- `ind-wheat`: Bloomberg 403. DGFT 밀 해제 고시 URL 을 이번 주에 못 찾음.
- `rus-wheat`: Bloomberg 403. government.ru 곡물 수출세 중단 결정문 URL 을 못 찾음.
- `ukr-soybeans`: USDA FAS PDF 403. 우크라이나 내각 원문 미확인. 기존 high 는 유지(이번 주에 내리지 않음).
- `idn-bauxite`: berkas.dpr.go.id 403.
- `chl-lithium`: UNCTAD 403.
- `idn-coal-single-gate`, `idn-ferroalloys-single-gate`: Lexology 403. 무역부·Danantara 원문 미확인.

- 중국 제품유 10월 선적 중단: 로이터 2026-10-01 은 정유사가 홍콩·마카오 밖 수출을 당국 승인 전까지 멈췄고 페트로차이나가 휘발유·항공유 선적 일부를 취소했다고 전한다. NDRC·상무부 원문을 찾지 못했다. 국경절(10월 7일) 이후인지도 원문에 없다. 금지 행으로 만들지 않는다.

최근 8일 수출통제 보드 공고 9건(미국: 베네수엘라 면허, TSRA 보고, UAE·시리아 완화, 대중 반도체 허가, 총기, 벨라루스 항공)은 원자재 품목이 아니라 후보에서 뺐다.

## 열린 질문 갱신

- 닫힘: 러시아 결의 1097. 생산자 경유 예외는 2026-10-01 에 시작. 일반 금지는 2027-01-31.
- 갱신: 인도 설탕은 Restricted 로 반영하되 dgft.gov.in 현행 수출정책표로 한 번 더 확인.
- 유지: 중국 인산비료는 9월 재개 보도가 갈린다. 해관·MOFCOM 원문 전까지 restricted 유지.
- 유지: 감시 30개국 대부분의 품목 쌍은 행이 없다. 행이 없음은 통제 없음이 아니다.

## 감시 목록 (카탈로그 행 아님)

재수출 허브 다섯 나라 중 통제의 주체인 두 나라만 고정 관찰에 넣는다. 네덜란드·스위스·홍콩은 넣지 않는다. 행은 만들지 않는다.

`New for anti/scripts/export_controls/universe.py` 의 `PINNED` 와 `universe.json` 의 `pinned_outside_role` 끝에 추가:

  }

## 배포 전에 볼 화면

- 인도 설탕이 금지에서 제한으로 바뀌면, 인도에 다른 농산물 금지가 없으므로 작황·수출통제 지도의 인도는 노랑이 된다. 밀 해제는 목록에만 남는다.
- 러시아 석유제품은 금지 그대로다. 지도 색은 유지되고, 문구만 생산자 예외(10월 1일~)가 들어간다.
- 중국 제품유는 제한(쿼터)이다. 에너지 지도의 중국은 노랑이고, 금지(빨강)로 칠하지 않는다.
- 반영 후 `cd "New for anti/scripts" && python3 -m export_controls.validate`
