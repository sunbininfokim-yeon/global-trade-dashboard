# 호르무즈 미포착 흐름 — 무료 자료 역산 검토

검토일: 2026-10-01. **설계 검토이며 미포착 배럴 산출·위성 선박 탐지 모델이 구현된 상태는 아니다.**

## 지금 공개 데이터에 연결한 것

- EIA가 공개한 호르무즈 및 수에즈 에너지 통계의 분기별 일평균. 석유 전체, 원유+콘덴세이트, 제품, LNG를 원단위와 범위로 분리한다.
- IEA 공식 주제 페이지에서 공개 commentary를 발견하고, 개별 문서에 CC BY 4.0이 명시된 경우에만 지원되는 완료 월 석유 전체 일평균 문장을 수집한다. 2026-09-18 발표의 2026-08 월평균은 760만 배럴/일이다. 이는 월간 기관 추정치이지 오늘의 원유 실측이나 AIS 미포착 보정값이 아니다.
- IMO가 연결하는 공식 경보 원문 링크. 통항 성공확률이나 보험 인수 여부를 계산한 자료가 아니다.
- 기존 PortWatch 일별 선종 추정 교역량. 탱커 톤을 원유 배럴로 일괄 환산하지 않는다.

각 값의 발표일·대상 기간·출처·상류 자료 제공자·갱신 상태를 보존한다. 공식 발표를 실제량의 수학적 상한/완전한 ground truth로 간주하지 않는다. 여러 기관이 동일한 상류 자료를 사용할 수 있으므로 기관 수를 독립 표본 수로 세지 않는다.

## Antigravity 핸드오프의 판정

|---|---|---|

| STS·셔틀과 도착항 자료 확인 | 방향은 유효하나 같은 화물 중복과 시차를 제거해야 함 | 다음 단계의 증거 대조 설계로 채택 |
| 파이프라인 정격 용량 차감 | 실제 수출·유량과 다름 | 현재 우회항 실제 선적량이 있을 때만 사용 |
| SAR은 유료만 가능 | 무료 Sentinel-1 영상 목록 확인 가능 | 무료 탐지 보조자료 후보로 수정 |
| 보험·유가·용선료로 통항량 추정 | 다른 원인이 섞여 단독 역산 불가 | 맥락·외부 검증용, 배럴 산출식 입력에서 제외 |
| 2026 1분기 EIA 1,460만 배럴/일 | 현재 공식 표의 석유 전체는 1,490만 | 수동 시드 대신 실제 표 파싱 |

선박 수 비율 `p`가 검증되더라도, 미포착/포착 선박의 평균 화물량 비율 `r`이 없으면 화물량은 식별되지 않는다. 설명용 식은 `Q_total = Q_visible × (1 + p × r / (1 − p))`이다. 현재 p와 r을 알 수 없으며 이 식은 운영 코드에 연결하지 않았다.

## 역산 후보 A: 오만만 통제 구역의 질량수지

아래는 자체 설계 제안이다. 통제 구역은 오만만 **해상 영역**으로 정하고 육상 탱크는 제외한다. 동일 품목·방향·기간·경계에서 모든 항을 **기간 누적 배럴**로 맞춘다. 월간 자료를 일별로 복제하지 않는다.

```text
호르무즈 유입 + 현지 항만 선적(우회분 제외) + 우회항 선적 + 다른 해상 유입
  = 외해 출항 + 현지 하역/소비 + 구역 내 재고 증가

호르무즈 유입 추정
  = 외해 출항 + 현지 하역/소비 + 재고 증가
    − 현지 선적(우회분 제외) − 우회항 선적 − 다른 해상 유입

미설명 물량 = 호르무즈 유입 추정 − 같은 경계·기간·품목의 확인된 통과 화물
```

- 재고는 구역 내 선박 적재 화물이다. 장기 정박 선박의 화물도 재고이지 새 통과량이 아니다. 육상 탱크를 포함하는 경계로 바꾸면 항만 선적/하역은 내부 이전이 되므로 산식도 별도로 바꿔야 한다.
- 현지 선적과 우회항 선적은 서로 겹치지 않게 분할한다. 파이프라인 유량과 그 화물의 항만 선적을 동시에 유입으로 더하지 않는다.
- 구역 안 STS는 내부 이전이다. 셔틀의 통과와 수취 선박의 출항을 동시에 신규 물량으로 더하지 않는다.
- Fujairah·Oman 등 현지 선적은 모두 호르무즈를 지난 물량이 아니다. Yanbu는 오만만 경계 밖이므로 이 구역 수지에 임의로 넣지 않는다.
- 잔차는 누락된 수출·재고·기간/품목 오차를 포함한다. **미설명 물량 ≠ 입증된 AIS 미송신 화물**이다. 음수 잔차도 0으로 감추지 않고 경계/자료 불일치로 보류한다.
- 각 항의 검증된 상·하한이 있으면 방향에 맞춰 합성한 범위를 표시할 수 있다. 임의 ±20%나 근거 없는 95% 신뢰구간을 붙이지 않는다. 중요한 항이 없으면 범위도 null이다.

Kpler의 공개 [정의 설명](https://www.kpler.com/blog/explainer-the-nuances-of-reading-hormuz-oil-flows-data)은 해협 통과, 오만만 환적 잔여, 직접 우회항 선적을 구분하고 중복을 상계한다. 최근 관측은 사후 확인에 따라 수정될 수 있다. 이를 경계·중복·시차 검토의 참고로 삼았으며, 유료 원자료·발표 수치·보정 배수를 수집하거나 재배포하지 않는다. [이용 조건](https://www.kpler.com/company/terms-of-use)을 확인했으며 공개 글이 자동 재배포 허가를 뜻한다고 판단하지 않는다.

## 역산 후보 B: 도착항/수입국의 지연 확인

1. 공식 월간 수입 통계에서 원산지·품목·순중량/물량을 수집한다. 금액만 있는 행을 배럴로 환산하지 않는다.
2. 생산국의 홍해·Fujairah·Jask 등 호르무즈 비통과 수출과, 육상·항공 운송을 구분한다. 원산지만으로 통과 해협을 확정할 수 없다.
3. 가능하면 항만 입항·하역 공지와 항차 증거를 연결한다. 통관일, 하역일, 선적일, 통과일을 다른 필드로 보존한다.
4. 도착 월 전체를 그 달 호르무즈 통과량으로 세지 않는다. 증거 기반 항해 시차가 없으면 월간 외부 검증값으로만 쓴다.
5. 동일 화물/항차를 여러 국가 통계와 환적 항구에서 중복 집계하지 않는다. 원산지 세탁·제재 회피·재수출 때문에 불확실한 자료는 별도 부분 커버리지로 남긴다.

무료 월간 외부 검증부터 시작하는 것이 현실적이다. 정확한 일별 역산에는 항차·적재 화물·재고 자료가 더 필요하다. 현재 데이터로 일별 미포착 원유 숫자를 만들지는 않는다.

JODI 7월 원유 수출 `TOTEXPSB/KBD`를 확인했을 때 Saudi Arabia와 Kuwait는 수치가 있지만 AE/IQ/IR/QA/BH/OM은 `-`이다. 이를 0으로 채워 합계를 호르무즈 수출로 발표하지 않는다. Saudi/Kuwait 수치도 국가 전체이며 해협 전용이 아니다. 무료 다운로드와 자동 재배포 조건은 별도 검토하고, 신규 공개 수집기를 만들 때 명시적 출처·조건을 기록한다.

위성 조회의 재현 조건: `sentinel-1-grd`, bbox `[55.8,25.9,57.4,27.0]`, 2026-09-01~30, 최신순 limit=5. 실제 반환은 5개이며 next 페이지가 있다. 9/30, 9/27, 9/25 영상 metadata가 포함되지만 전체 장면 수·해협 전 구간 커버리지·통항 선박 수를 뜻하지 않는다. 한 촬영일의 연속 두 장면을 독립 두 날 관측으로 세지 않는다.

[ESA 설명](https://www.esa.int/Applications/Observing_the_Earth/Copernicus/Sentinel-1/Tracking_maritime_traffic)에 따르면 SAR과 AIS 대조는 미송신 선박 탐지에 쓰일 수 있다. 하지만 항만 시설·해상 잡음·다른 선종 오탐을 검증해야 하며, PortWatch 집계만으로 개별 선박 AIS 대조는 불가능하다. 영상 탐지가 배럴 추정 모델의 검증을 대신하지 않는다.

## 다음 구현 순서 / 공개 판정

1. 이번 공식 참고 bundle PR → Claude의 기간·품목·범위별 UI 연결. 기존 일별 그래프는 계속 별도 표시.
2. 월간 수입국/원산지의 무료 물량 자료와 국가별 우회 수출 자료를 작은 표본으로 대조. 기존 Comtrade 수집기를 재사용하고 중복 collector를 만들지 않음.
3. 질량수지의 각 항에 데이터 존재 여부·범위·단위·권리·지연을 기록. 입력 불완전이면 `hold/null`, 모델 범위는 발표하지 않음.
4. 무료 위성 영상은 촬영 커버리지와 검증 표본을 먼저 확보. CDSE 실제 영상 다운로드는 [등록/인증 또는 S3 credentials](https://documentation.dataspace.copernicus.eu/APIs/S3.html)가 필요할 수 있다. 사용자가 보유한 Copernicus **CDS** 기후 키와 CDSE 영상 자격증명은 다른 서비스다. 현재 metadata 확인에는 새 키가 필요 없었음.
5. 기간이 맞는 무료 입력으로 식별이 가능해졌을 때만 ‘미설명 물량 추정 범위’를 추가. 실측 원유량, 실제 통항 가능성, 선박별 현재 위치로 표시하지 않음.
