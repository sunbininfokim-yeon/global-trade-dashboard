# South Africa Macro Kit (`za_macro_v1`)

자원 수출 · EM 자본 변동성 · **전력/물류 인프라**가 금융지표를 압도하는 구조.

## 구조 (6탭)

| 탭 | 핵심 |
|----|------|
| 재정·유동성 | **재정수지·부채/GDP**(Eskom/Transnet) · SARB자산 · M3 |
| 금리·신용 | Repo · **SAGB 10Y** · 5Y CDS |
| 환율·원자재 | **USD/ZAR** · 금/백금/석탄 · 무역수지 |
| 주식 | JSE Top40 · 외국인 국채비중·주식수급 |
| 성장 | **Load Shedding(최중요)** · GDP · Absa PMI · 실업(30%+) |
| 물가 | CPI · Core · 타겟밴드 3–6% |

## 헤드라인

Load Shedding · 부채/GDP · Repo · USD/ZAR · SAGB 10Y · CPI

## 한계

1. 원자재↑ ≠ 성장 (Transnet 병목)  
2. Load Shedding은 거시모델 밖 외생변수  
3. M3↑ ≠ 투자·수요견인 (실업·정책불확실)
